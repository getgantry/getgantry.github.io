La GUI nativa de macOS para Apple container
y Docker: toda tu flota en un solo panel.

Gantry es una app gratuita y de código abierto para Mac para la herramienta container de Apple y para Docker, en local y por SSH. Ejecuta contenedores, clústeres de Kubernetes, máquinas y proyectos Compose en apple/container desde una sola ventana, junto a tus hosts Docker. Una alternativa a Docker Desktop y OrbStack gratuita para Mac. Sin Electron. Sin suscripción. Sin límites.

Descargar para macOS
$ brew install --cask getgantry/tap/gantry

Novedades de la 0.27.0

Kubernetes, Apple Intelligence y el resto de macOS

Gantry 0.27.0 añade un navegador de Kubernetes, explica con Apple Intelligence por qué han fallado los contenedores y funciona con Spotlight, Siri, los widgets y el Centro de control. Es compatible con apple/container 1.7.1 y tiene un diseño nuevo que sigue las Human Interface Guidelines de Apple.

Navegador de Kubernetes

Explora Pods, Deployments, StatefulSets, DaemonSets, servicios, Ingress, ConfigMaps, secretos, nodos y eventos de cualquier contexto de kubeconfig. Sigue los logs de los pods, abre un shell, reenvía un puerto, escala, reinicia un despliegue y aplica YAML. Gantry se comunica directamente con la API de Kubernetes, así que un clúster creado con container cluster create está listo para explorar sin instalar nada más: sin kubectl.

Explicar fallo con Apple Intelligence

Elige Explicar fallo… en un contenedor que se ha caído o en una operación fallida. Gantry envía los logs recientes y los detalles al modelo del dispositivo, sin los valores de entorno ni el texto que parece un secreto, y muestra la causa probable, las evidencias y los siguientes pasos. Los logs largos pueden ir a Private Cloud Compute (macOS 27). El panel muestra exactamente lo que se ha enviado.

Parte de macOS

Notificaciones con Reiniciar, Ver logs y Copiar como prompt. Spotlight encuentra contenedores, proyectos Compose y hosts. Acciones de Siri y Atajos, un widget del estado de la flota, controles del Centro de control para los servicios de apple/container o un contenedor favorito, y enlaces gantry:// para scripts.

Paleta de comandos

Pulsa ⌘K y escribe. Una sola búsqueda abarca contenedores, proyectos Compose, imágenes, volúmenes, redes, máquinas, clústeres y hosts, con acciones como Iniciar, Mostrar logs y Abrir shell.

Varios a la vez

Selecciona varios contenedores, imágenes, volúmenes o redes e inícialos, detenlos, reinícialos o elimínalos en un solo paso, con el progreso y un informe de cada elemento.

Pega un docker run

Pega un comando docker run, podman run o container run y Gantry rellena el formulario Nuevo contenedor, con una lista de los parámetros que no puede usar. Copia cualquier contenedor de vuelta como comando o guárdalo como receta. Cómo funciona

Contenedores en un disco externo

Mueve todos los datos de apple/container a un disco externo, guarda los volúmenes en el disco que elijas y recibe un aviso claro cuando ese disco no está conectado. Leer la guía

Terminal exec integrado

Emulación de terminal completa en cualquier contenedor en ejecución, local o remoto, con temas de color (Sistema, Solarized, Dracula, Nord).

Hosts remotos por SSH

Túneles exactamente como docker -H ssh:// mediante dial-stdio: bastiones ProxyJump, autenticación con varias claves, reconexión automática. No hay que instalar nada en el servidor y los secretos van al llavero. Importación con un clic desde ~/.ssh/config y docker context ls.

Explorador de archivos con arrastrar y soltar

Explora el sistema de archivos de un contenedor, mete y saca archivos, y suelta carpetas enteras directamente desde el Finder, tanto en hosts Docker como apple/container.

Abrir en el navegador y reenviar

Un clic abre un puerto publicado. Los puertos SSH se tunelizan a localhost automáticamente y, si el puerto está ocupado, Gantry elige uno libre que puedes editar.

Compartir en Internet

Un clic expone un puerto publicado mediante un Cloudflare Tunnel. Gantry instala cloudflared por ti y te da un túnel rápido (sin cuenta, con una URL *.trycloudflare.com) o un túnel con nombre en tu propio dominio: ideal para una vista previa de desarrollo, un webhook o para que un agente de IA llegue a un contenedor de tu Mac.

Compose en cualquier host

Los contenedores se agrupan por proyecto Compose. Levanta un archivo Compose en cualquier host (Docker local, SSH o apple/container) con un editor YAML integrado; el ejecutor se adapta a cada motor.

Registros privados, automáticamente

Las descargas usan el docker login que ya hiciste: Gantry obtiene las credenciales de ~/.docker/config.json, de los helpers y del llavero, tanto al crear como en Ejecución rápida y en Compose.

Compilar y descargar imágenes

Suelta un Dockerfile en la ventana para compilarlo con un log en directo, o descarga por referencia con el progreso de cada capa. Añade tags, purga y consulta el historial de capas. Una insignia marca las imágenes compiladas para una arquitectura de CPU distinta de la del host.

Recuperar espacio

Un panel muestra qué ocupa espacio (imágenes huérfanas, contenedores detenidos, volúmenes sin usar, caché de compilación) con sus tamaños, y purga cada elemento o todo a la vez. En apple/container también ejecuta Compactar disco.

Touch ID para acciones destructivas

Si lo activas, Gantry pide Touch ID (o tu contraseña de inicio de sesión) antes de eliminar un contenedor o un host. Los secretos ya se guardan en el llavero.

Temas del terminal

Viste el shell integrado con Sistema, Solarized Dark, Dracula o Nord: una paleta completa de primer plano, fondo y 16 colores ANSI, aplicada al instante.

GUI para apple/container

La GUI nativa de macOS para Apple container

La herramienta container de Apple ejecuta contenedores Linux como máquinas virtuales ligeras en chips de Apple, pero solo se distribuye como herramienta de línea de comandos. Gantry es su app de escritorio: lo que Docker Desktop es para Docker, Gantry lo es para container. Es compatible con todas las CLI container, de la 1.0 a la 1.7.1 recomendada, y activa cada función solo cuando la CLI instalada la admite.

Contenedores, logs, estadísticas y exec

Crea, inicia, detén, fuerza el cierre y purga; logs en directo, estadísticas, un terminal exec, top y exportación a tar, en la misma interfaz que tus hosts Docker.

Clústeres de Kubernetes

Crea un clúster de Kubernetes con container cluster: define por separado el tamaño del plano de control y de los workers, elige la CNI y consulta los nodos, la versión de Kubernetes y el contexto de kubeconfig. Los nodos del clúster están protegidos contra detenciones y eliminaciones accidentales. Más información

Imágenes locales en el clúster

En la CLI 1.7, activa Usar imágenes locales (--shared-image-store) y los pods ejecutan las imágenes que compilas o descargas, sin registro. En las CLI 1.5 y 1.6, haz clic derecho en una imagen y elige Cargar en el clúster.

Avisos claros cuando la instalación está rota

Si los servicios de clúster no responden, Gantry te dice por qué. Con una versión de Homebrew sin los servicios de clúster, muestra un enlace al instalador firmado; en cualquier otro caso, un botón Reiniciar servicios.

Máquinas de container en VS Code

Crea, inicia y detén entornos Linux con container machine, ajusta las CPU y la memoria, abre un shell o abre la máquina en VS Code por Remote-SSH.

Virtualización anidada y kernels personalizados

Arranca una máquina con virtualización anidada (M3 o posterior) o con tu propio kernel. Arranca contenedores desde un kernel personalizado con argumentos de arranque adicionales.

Compose para Apple container

apple/container no tiene compose. Gantry ejecuta tu docker-compose.yml: compila, crea la red y los volúmenes, e inicia los servicios en el orden de depends_on. Los nombres de servicio se resuelven mediante alias DNS de red.

Alias DNS de red

Alias de contenedor, alias de subárbol como .gateway y nombres cortos cuando hay un dominio DNS predeterminado. Cada contenedor recibe una IP enrutable y un nombre de host name.domain.

Gestión del builder de imágenes

Consulta el estado, la imagen, la CPU, la memoria y la IP del builder. Inícialo con opciones de CPU, memoria y DNS, detenlo o elimínalo. Cuando la imagen del builder está desactualizada, Gantry ofrece volver a crearla.

Sesiones en registros

Lista, añade y quita sesiones de container registry. La contraseña llega a la CLI solo por stdin, y Gantry no guarda ninguna copia.

Instalación del kernel

Instala el kernel recomendado, un archivo de kernel o un archivo tar, con el progreso en directo. Gantry te avisa cuando no hay ningún kernel predeterminado instalado.

Servicios y logs de servicios

Inicia, detén y reinicia los servicios de container, compara las versiones del cliente y del servidor, y sigue en directo los logs de servicios filtrados por nivel, servicio y texto.

Editor de propiedades del sistema

Edita las propiedades del sistema de container en config.toml. Gantry marca los cambios que necesitan un reinicio y reinicia los servicios por ti. En la CLI 1.7 también edita los valores predeterminados de [container.dns]: servidores de nombres, dominios de búsqueda y opciones.

Guardar como imagen y Compactar disco

Guarda un contenedor como imagen (container commit) y recupera espacio en disco con Compactar disco (container clean), también desde el panel Recuperar espacio.

Explorador de archivos: subida y descarga

Explora los archivos de un contenedor, descárgalos o arrástralos al Finder (container copy), y suelta dentro archivos o carpetas enteras.

Ejecución rápida y Finder

Elige una imagen, comparte una carpeta, asigna puertos, elige un dominio y ejecuta. Haz clic derecho en un archivo Compose en el Finder y ábrelo con Gantry.

Etiquetas que contienen =

La CLI container rechaza valores de etiqueta con =. Gantry los codifica al crear y los decodifica al leer, así que un valor como a=b se conserva intacto.

Una flota, dos runtimes

Los hosts apple/container conviven con tus hosts Docker locales y SSH en un mismo panel, con los mismos minigráficos, el mismo estado de salud y las mismas notificaciones de fallos.

Herramientas MCP para agentes

El servidor MCP incluido da a los agentes el mismo alcance: contenedores, máquinas, clústeres y las herramientas de sistema apple_* para servicios, builder, registros, propiedades, logs y kernels.

Preguntas frecuentes

Tus preguntas, respondidas

Todo lo que quizá quieras saber antes de instalar Gantry.

¿Cuál es la mejor GUI para Apple container?

Gantry es una GUI nativa de macOS, gratuita y de código abierto, creada para la herramienta container de Apple (apple/container). Cubre el ciclo de vida de los contenedores, los logs, las estadísticas y un terminal exec, además de las partes de la CLI a las que no llegan otras GUI: clústeres de Kubernetes (container cluster), máquinas de container, el builder de imágenes, las sesiones en registros, los kernels, los logs de servicios y las propiedades del sistema. Es compatible con las CLI 1.0 a 1.7.1 y activa cada función solo cuando tu CLI la admite. Consulta la guía de apple/container.

¿Qué es Apple container (apple/container)?

apple/container es la herramienta de código abierto de Apple para ejecutar contenedores Linux en un Mac. Cada contenedor se ejecuta en su propia máquina virtual ligera, basada en el framework Virtualization de Apple. Requiere un Mac con chip de Apple y se distribuye como una herramienta de línea de comandos llamada container, sin app de escritorio. Gantry aporta esa app de escritorio.

¿Gantry es compatible con container cluster y Kubernetes?

Sí. En un host apple/container, Gantry crea y elimina clústeres de Kubernetes con container cluster (CLI 1.6.1 y 1.7; las CLI 1.5.0 a 1.6.0 usan container k8s). Eliges el nombre, los workers, la CPU y la memoria del plano de control y de los workers (1.7), la imagen de nodo, la CNI y si los nodos usan tus imágenes locales (1.7). Gantry muestra los nodos, escribe el kubeconfig y abre el clúster en su navegador de Kubernetes. Consulta Kubernetes en apple/container.

¿Se puede usar docker compose con Apple container?

Sí. apple/container no tiene comando compose, así que Gantry se encarga de la orquestación con la CLI container: compila los servicios con build:, crea la red del proyecto y los volúmenes con nombre, e inicia cada servicio en el orden de depends_on con las etiquetas estándar de Compose. Los nombres de servicio se resuelven mediante alias DNS de red. Abre un docker-compose.yml desde el Finder, desde el menú Archivo o soltándolo en la ventana.

¿Cómo abro una máquina de container en VS Code?

Inicia la máquina en Gantry y haz clic en Abrir en VS Code. Gantry abre la máquina en VS Code por Remote-SSH, como en el ejemplo container-machine-vscode de Apple. La imagen de la máquina debe ejecutar sshd, y VS Code debe estar instalado con la extensión Remote-SSH.

¿Qué versiones de apple/container admite Gantry?

Gantry necesita la CLI container 1.0 o posterior y recomienda la 1.7.1. Lee la versión instalada y solo muestra las funciones que esa versión admite, por ejemplo el tamaño de los workers y el almacén de imágenes compartido (1.7), guardar como imagen (1.6) y Compactar disco (1.4). Si la CLI falta o es antigua, Gantry ofrece una configuración guiada.

¿Gantry puede explorar un clúster de Kubernetes?

Sí. La sección Kubernetes lista Pods, Deployments, StatefulSets, DaemonSets, servicios, Ingress, ConfigMaps, secretos, nodos y eventos de cada contexto de kubeconfig, y ofrece logs de pods, un shell en el pod, reenvío de puertos, escalado, reinicio del despliegue, eliminación y Aplicar YAML. Gantry se comunica directamente con la API de Kubernetes, así que no necesitas kubectl. Consulta Ejecutar Kubernetes en un Mac.

¿Qué envía Explicar fallo a Apple Intelligence?

Los logs recientes y los detalles del contenedor, sin los valores de entorno ni el texto que parece un secreto. Las solicitudes pequeñas se ejecutan en el modelo del dispositivo. Con el ajuste para logs largos activado (macOS 27), los logs largos van a Private Cloud Compute. El panel muestra lo que se ha enviado. Un comando sugerido se abre en Terminal, pero no se ejecuta hasta que pulsas Retorno. Sin Apple Intelligence, Gantry ofrece un prompt para copiarlo en otro asistente de IA.

¿Puedo pegar un comando docker run en Gantry?

Sí. En la hoja Nuevo contenedor, elige Pegar comando…. Gantry lee docker run, docker create, podman run y container run, rellena el formulario y lista cada parámetro que no puede usar, con el motivo. Consulta Crear un contenedor a partir de un comando docker run.

¿Puede Gantry gestionar el builder, los registros y el kernel de apple/container?

Sí. La sección Sistema de un host apple/container inicia, detiene y elimina el builder de imágenes con opciones de CPU, memoria y DNS; lista, añade y quita sesiones en registros (la contraseña llega a la CLI solo por stdin); instala el kernel recomendado, un archivo de kernel o un archivo tar; muestra en directo los logs de servicios, y edita las propiedades del sistema en config.toml.

¿Es Gantry una alternativa a Docker Desktop, OrbStack o Podman Desktop?

Como GUI, sí. Gantry es una app nativa de macOS y gratuita para gestionar contenedores, imágenes, volúmenes, redes, logs y estadísticas. Es un cliente, no un motor: usa el daemon de Docker que ya tienes en marcha (Docker Desktop, OrbStack, Colima) o la herramienta container de Apple, y añade una vista multihost, hosts SSH y un servidor MCP. Consulta la comparativa.

¿Gantry es gratis?

Sí. Gantry es gratuito y de código abierto, con licencia MIT. Sin suscripción, sin cuenta y sin límite de hosts ni de contenedores.

¿Qué necesito para usar Gantry?

macOS 26 o posterior en un Mac con chip de Apple o Intel, más un daemon de Docker (Docker Desktop, OrbStack, Colima o similar) o la herramienta container de Apple. apple/container en sí requiere chip de Apple, así que en un Mac con Intel Gantry solo gestiona hosts Docker.

¿Gantry funciona con OrbStack, Colima y Docker Desktop?

Sí. Gantry se comunica directamente con la API de Docker Engine a través del socket Unix, así que funciona con cualquier daemon que la exponga, incluidos OrbStack, Colima y Docker Desktop.

¿Puede Gantry gestionar hosts Docker remotos?

Sí. Gantry se conecta a daemons remotos por SSH, igual que docker -H ssh://, con bastiones ProxyJump, autenticación con varias claves y reconexión automática. No hay que instalar nada en el servidor, y los secretos se guardan en el llavero de macOS.

¿Gantry avisa cuando falla un contenedor?

Sí. Gantry envía una notificación nativa de macOS cuando un contenedor falla, se queda sin memoria o no supera su comprobación de estado en cualquier host: local, SSH o apple/container. Haz clic en ella para ir al contenedor. Las detenciones y los reinicios que lanzas desde Gantry no se notifican, y puedes desactivar los avisos en Ajustes.

¿Puede Gantry descargar imágenes de registros privados?

Sí. En los hosts Docker, Gantry lee las credenciales de tu ~/.docker/config.json (el mismo docker login que ya hiciste), incluidas la autenticación inline, los credential helpers y el llavero de macOS. En los hosts apple/container, gestiona las sesiones de container registry.

¿Puede Gantry exponer un contenedor local a Internet?

Sí. Un clic en un puerto publicado lo comparte mediante un Cloudflare Tunnel. Gantry instala cloudflared si hace falta y luego inicia un túnel rápido (sin cuenta de Cloudflare, con una URL temporal de trycloudflare.com) o un túnel con nombre en tu propio nombre de host. La URL pública aparece bajo el puerto, con controles para abrirla, copiarla y detenerla.

¿Gantry es una app Electron?

No. Gantry es una app nativa creada con SwiftUI y Swift 6. La interfaz está disponible en 28 idiomas: inglés, chino simplificado y 26 idiomas europeos, por ejemplo el serbio en alfabeto cirílico y latino. Sigue el idioma del sistema de macOS.

¿Cómo instalo Gantry?

Ejecuta brew install --cask getgantry/tap/gantry, o descarga la última versión desde GitHub y arrastra Gantry.app a Aplicaciones.

¿Pueden los agentes de IA controlar Gantry?

Sí. Gantry incluye un servidor MCP y App Intents de macOS, así que Claude, Atajos, Siri y los scripts llegan a lo mismo que la GUI en cada host, también en los hosts SSH: contenedores, imágenes, volúmenes, redes, Compose, máquinas de apple/container, clústeres de Kubernetes, herramientas de sistema apple_* (servicios, builder, registros, propiedades, logs, kernel) y compartición de puertos. En macOS 26 y posterior, Explicar fallo… también pregunta a Apple Intelligence por qué ha fallado un contenedor. Añade el servidor MCP con claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp.
