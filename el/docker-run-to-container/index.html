Gantry/Από docker run

Δημιουργία κοντέινερ από εντολή docker run

Τα περισσότερα README δίνουν μια γραμμή docker run. Το Gantry διαβάζει αυτή τη γραμμή και συμπληρώνει τη φόρμα «Νέο κοντέινερ», για host Docker ή για το εργαλείο container της Apple. Αυτός ο οδηγός δείχνει πώς, και πώς να μετατρέψετε την εντολή με το χέρι.

Με λίγα λόγια. Στο Gantry, ανοίξτε το Νέο κοντέινερ, επιλέξτε Επικόλληση εντολής…, επικολλήστε τη γραμμή docker run και κάντε κλικ στη Συμπλήρωση φόρμας. Το Gantry εμφανίζει κάθε σημαία που δεν μπορεί να χρησιμοποιήσει, με την αιτία. Για το CLI, οι περισσότερες σημαίες είναι ίδιες: αντικαταστήστε το docker run με container run και αφαιρέστε το --restart.

Επικόλληση της εντολής στο Gantry

  1. Επιλέξτε έναν host: host Docker ή host apple/container.
  2. Ανοίξτε τα Κοντέινερ και κάντε κλικ στο Νέο κοντέινερ.
  3. Κάντε κλικ στην Επικόλληση εντολής… και επικολλήστε τη γραμμή. Οι αλλαγές γραμμής με \, τα εισαγωγικά, ένα prompt $ και το sudo δεν είναι πρόβλημα.
  4. Διαβάστε την προεπισκόπηση: την εικόνα, τις σημαίες που δεν μπορεί να χρησιμοποιήσει το Gantry, σημειώσεις και προειδοποιήσεις για αυτόν τον host.
  5. Κάντε κλικ στη Συμπλήρωση φόρμας, ελέγξτε τις τιμές και δημιουργήστε το κοντέινερ.

Το Gantry διαβάζει docker run, docker container run, docker create, podman run και container run. Το κείμενο μετά από &&, ||, ; ή | αγνοείται, με σημείωση.

Ποιες σημαίες συμπληρώνουν τη φόρμα

Περίπου 80 ακόμη σημαίες του Docker είναι γνωστές: το Gantry παραλείπει σωστά τις τιμές τους και τις εμφανίζει ως μη χρησιμοποιούμενες, οπότε τίποτα δεν χάνεται χωρίς σημείωση.

Προειδοποιήσεις για host apple/container

Ορισμένες επιλογές του Docker δεν υπάρχουν στο apple/container. Το Gantry προειδοποιεί γι' αυτές και τις αφήνει εκτός του αιτήματος δημιουργίας:

  • πολιτικές επανεκκίνησης (--restart)·
  • κλάσματα CPU, όπως --cpus 0.5·
  • οι λειτουργίες δικτύου host, none και container:·
  • θύρες χωρίς θύρα host, όπως -p 80.

Σε host Docker, το Gantry προειδοποιεί για τις επιλογές του apple/container: τον τομέα DNS και τις επιλογές πυρήνα.

Μετατροπή του docker run σε container run με το χέρι

Για το CLI, οι περισσότερες σημαίες μένουν ίδιες. Ένα παράδειγμα με Redis:

Τερματικό
docker run -d --name cache --restart unless-stopped -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

γίνεται:

Τερματικό
container volume create redisdata
container run -d --name cache -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

Δημιουργήστε πρώτα τον ονομασμένο τόμο με container volume create. Αφαιρέστε το --restart και στρογγυλοποιήστε το --cpus σε ακέραιο αριθμό. Το --platform λειτουργεί όπως στο Docker.

Αντιγραφή κοντέινερ ως εντολής

Λειτουργεί και αντίστροφα. Κάντε δεξί κλικ σε ένα κοντέινερ ή χρησιμοποιήστε το μενού «Περισσότερα» και επιλέξτε Αντιγραφή ως εντολής: το Gantry γράφει μια γραμμή docker run ή container run. Παραλείπει τις προεπιλογές της εικόνας, όπως το περιβάλλον και την εντολή της, ώστε η γραμμή να μένει σύντομη. Λειτουργεί και για σταματημένα κοντέινερ.

Αποθήκευση ως συνταγής

Στο φύλλο «Νέο κοντέινερ», ανοίξτε τις Συνταγές και επιλέξτε Αποθήκευση ως συνταγής…. Την επόμενη φορά, η Συμπλήρωση από συνταγή δίνει την ίδια φόρμα σε οποιονδήποτε host. Οι συνταγές βρίσκονται στο ~/Library/Application Support/Gantry/recipes.json, ώστε να μπορείτε να τις αντιγράψετε για ασφάλεια ή να τις μοιραστείτε.

Περιορισμοί

  • Το Gantry κρατά τη διαδρομή του --env-file, αλλά δεν διαβάζει το αρχείο, και δεν διαβάζει το shell σας για -e KEY χωρίς τιμή.
  • Οι προσαρτήσεις tmpfs και οι ανώνυμοι τόμοι από το --mount εμφανίζονται ως μη υποστηριζόμενοι.
  • Δύο θύρες για την ίδια θύρα κοντέινερ (-p 8080:80 -p 8081:80) συμπληρώνουν τη φόρμα, αλλά η φόρμα απορρίπτει μετά το διπλότυπο.

Ερωτήσεις και απαντήσεις

Πώς μετατρέπω το docker run σε container run;

Αντικαταστήστε το docker run με container run. Τα -d, -p, -e, -v, --name, --rm, -it, -w και --entrypoint μένουν ίδια. Αφαιρέστε το --restart και χρησιμοποιήστε ακέραιες CPU. Ή επικολλήστε τη γραμμή στο Gantry και αφήστε το να συμπληρώσει τη φόρμα.

Μπορεί το Gantry να εισαγάγει μια εντολή docker run;

Ναι. Η Επικόλληση εντολής… στο φύλλο «Νέο κοντέινερ» διαβάζει docker run, docker create, podman run και container run και συμπληρώνει τη φόρμα.

Τι γίνεται με τις σημαίες που δεν υποστηρίζει το Gantry;

Εμφανίζονται στην προεπισκόπηση με την αιτία και μένουν στη φόρμα, στην ενότητα «Από την επικολλημένη εντολή», ώστε να μπορείτε να τις ελέγξετε αργότερα.

Μπορώ να μετατρέψω ένα κοντέινερ σε εκτέλεση πίσω σε εντολή docker run;

Ναι. Η Αντιγραφή ως εντολής στο μενού του κοντέινερ γράφει μια γραμμή docker run ή container run για αυτό το κοντέινερ.
