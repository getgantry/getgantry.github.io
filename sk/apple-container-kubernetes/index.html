Gantry/Kubernetes na apple/container

Kubernetes na Apple container

apple/container dokáže spustiť klaster Kubernetes, ktorého uzly sú kontajnery na vašom Macu. Gantry je preň GUI: vytvorte klaster, sledujte, ako sa uzly rozbiehajú, pripojte kubectl a načítajte lokálne obrazy – bez dlhých príkazov container cluster.

V skratke. Na hostiteľovi apple/container vytvára a maže sekcia Klastre v Gantry klastre Kubernetes pomocou container cluster (CLI 1.6.1) alebo container k8s (CLI 1.5.0 až 1.6.0). Podporuje viac pracovných uzlov, vlastné CNI, zobrazenie uzlov, kubeconfig a kontext kubectl a Načítať do klastra pre lokálne obrazy.

Požiadavky

  • Mac s Apple silicon, macOS 26 a Gantry (brew install --cask getgantry/tap/gantry).
  • CLI container 1.5.0 alebo novšie; odporúča sa 1.6.1. Pracovné uzly a CNI Žiadne vyžadujú 1.6.0 alebo novšie.
  • kubectl, ak chcete klaster používať z terminálu.

Vytvorenie klastra

  1. Vyberte hostiteľa apple/container a v bočnom paneli otvorte Klastre.
  2. Založte nový klaster a vyplňte možnosti nižšie.
  3. Vytvorte ho. Zoznam zobrazí nový klaster s priebehom v reálnom čase. Zrušiť vytváranie zastaví a vymaže uzly, ktoré už vznikli.
MožnosťPríznak CLIPoznámky
Názov--nameZároveň názov kontextu v kubeconfig
Pracovné uzly--workersPočet pracovných uzlov. CLI 1.6.0+
CPU--cpusNa uzol
Pamäť--memoryNa uzol, napríklad 4G
Obraz uzla--node-imagePrázdne pole ponechá predvolenú hodnotu CLI
CNI--cniPredvolené (vstavaný kindnet), Žiadne (NONE, CLI 1.6.0+) alebo cesta k vlastnému manifestu

Rovnaký príkaz v CLI:

Shell
container cluster create --name dev --workers 2 --cpus 2 --memory 4G

Uzly a podrobnosti klastra

Zoznam klastrov zobrazuje každý klaster s jeho uzlami: rolu, stav a adresu. Podrobné zobrazenie obsahuje Prehľad (kontext kubectl, server API, pracovné uzly, sieť uzlov), tabuľku Uzly, kartu Preskúmať so surovými údajmi uzlov a akcie Zapísať kubeconfig, Kopírovať príkaz kubectl na nastavenie kontextu a Vymazať.

Pripojenie kubectl

Pri vytváraní klastra pridá CLI do ~/.kube/config kontext pomenovaný podľa klastra. Použite v Gantry Kopírovať príkaz kubectl na nastavenie kontextu, alebo ho napíšte ručne:

Shell
kubectl --context dev get nodes

Ak chcete mať klaster v samostatnom súbore, použite Zapísať kubeconfig. Gantry spustí container cluster write-config; predvolená cesta je ~/.kube/<name>.kubeconfig.

Načítanie lokálnych obrazov do klastra

Zostavte alebo stiahnite obraz na hostiteľovi apple/container, potom naň v sekcii Obrazy kliknite pravým tlačidlom a vyberte Načítať do klastra. Gantry spustí container cluster load-image, ktorý skopíruje obraz do containerd každého uzla. Na lokálny vývoj nepotrebujete register.

Shell
container cluster load-image --name dev myapp:dev

Výber CNI

Predvolený je vstavaný manifest kindnet. Vyberte Vlastný manifest a nainštalujte vlastné CNI zo súboru, napríklad Calico alebo Cilium. Vyberte Žiadne, ak chcete CNI nainštalovať sami neskôr; dovtedy zostanú uzly v stave NotReady.

Klastre z AI agentov

Server MCP Gantry ponúka list_clusters, create_cluster a delete_cluster, takže agent ako Claude Code si môže vytvoriť dočasný klaster na test a potom ho odstrániť.

Pridanie servera MCP Gantry
claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp

Viac o apple/container

Prečítajte si sprievodcu apple/container s každým príkazom container a jeho funkciou v Gantry, alebo si pozrite, ako Gantry obstojí v porovnaní s Docker Desktop, OrbStack a Podman Desktop.

Otázky a odpovede

Podporuje Apple container Kubernetes?

Áno. CLI container vytvára klastre Kubernetes, ktorých uzly bežia ako kontajnery: container cluster v CLI 1.6.1, container k8s v CLI 1.5.0 až 1.6.0. Gantry k tomu pridáva GUI.

Podporuje Gantry container cluster?

Áno. Gantry vypisuje, vytvára a maže klastre na hostiteľoch apple/container, zobrazuje ich uzly, zapisuje kubeconfig, kopíruje príkaz na nastavenie kontextu kubectl a načítava lokálne obrazy do klastra. Podľa verzie vášho CLI použije cluster alebo k8s.

Ako používať kubectl s klastrom apple/container?

Keď CLI vytvorí klaster, pridá do ~/.kube/config kontext kubeconfig pomenovaný podľa klastra. Spustite kubectl --context <name> get nodes. Ak chcete mať samostatný súbor, použite v Gantry Zapísať kubeconfig; predvolená cesta je ~/.kube/<name>.kubeconfig.

Ako dostať lokálny obraz do klastra bez registra?

V Gantry kliknite pravým tlačidlom na obraz v sekcii Obrazy a vyberte Načítať do klastra. Gantry spustí container cluster load-image, ktorý skopíruje obraz do containerd každého uzla.

Dá sa vytvoriť klaster s viacerými uzlami?

Áno. Počet pracovných uzlov nastavte v hárku na vytvorenie. Pracovné uzly vyžadujú CLI 1.6.0 alebo novšie.

Môžem použiť vlastné CNI, napríklad Calico alebo Cilium?

Áno. Vyberte Vlastný manifest a zvoľte súbor manifestu, alebo vyberte Žiadne a CNI nasaďte sami po spustení klastra. Kým CNI nebeží, uzly zostávajú v stave NotReady. Žiadne vyžaduje CLI 1.6.0 alebo novšie. Predvolené CNI je vstavaný manifest kindnet.
