Gantry/Tõmmiste skannimine

Konteineritõmmiste turvaaukude skannimine Macis

Trivy ja Grype on tasuta avatud lähtekoodiga skannerid, mis võrdlevad tõmmise pakette teadaolevate turvaaukude andmebaasidega. Dockeri tõmmiseid loevad nad otse. Apple'i container-tööriistal pole skannimiskäsku ega Dockeri soklit, seega tuleb tõmmis kõigepealt salvestada. See juhend näitab mõlemat viisi, kuidas leide lugeda, kuidas SBOM-i kirjutada ja kuidas Gantryst skannida.

Lühidalt. Käivitage brew install trivy grype. Dockeris käivitage trivy image app:dev. Apple containeris salvestage tõmmis käsuga container image save --platform linux/arm64 -o app.tar app:dev, pakkige see lahti käsuga tar -xf app.tar -C app-img ja skannige kausta: trivy image --input app-img või grype oci-dir:app-img. Tar-faili ennast kumbki tööriist vastu ei võta.

Skanneri installimine

Installige Homebrew'ga üks skanner või mõlemad. Kumbki laadib esimesel skannimisel alla oma turvaaukude andmebaasi, mis võtab umbes minuti.

Terminal
brew install trivy grype

Kontrollisime selle juhendi käske versioonidega Trivy 0.76.2, Grype 0.121.3 ja container 1.7.1. Gantry vajab Trivy 0.50.0 või Grype 0.74.0 või uuemat versiooni.

Dockeri tõmmise skannimine

Dockeri mootoriga (Docker Desktop, OrbStack või Colima) loevad mõlemad tööriistad kohalikku tõmmist nime järgi Dockeri sokli kaudu:

Terminal
trivy image app:dev
grype app:dev

Apple containeri tõmmise skannimine

Salvestage tõmmis OCI-arhiivi ja pakkige see kausta lahti. Andke lipp --platform: kui tõmmisehoidlas on tõmmisest ainult mõned platvormid, nurjub container image save ilma selleta.

Terminal
container image pull python:3.11-slim
container image save --platform linux/arm64 -o python.tar python:3.11-slim
mkdir python-img && tar -xf python.tar -C python-img

Seejärel skannige kausta. Trivy loeb seda lipuga --input, Grype eesliitega oci-dir::

Terminal
trivy image --input python-img --severity HIGH,CRITICAL
grype oci-dir:python-img
Tähelepanu
Ärge andke .tar-faili. Käsu container image save arhiiv algab kirjega ./: Trivy teatab „file manifest.json not found in tar“ ja Grype lükkab selle tagasi kui „potential path traversal attack“. Lahtipakitud kaust töötab mõlemaga.

Tulemuste lugemine

  • Raskusaste: Critical, High, Medium, Low või Unknown. Alustage Critical- ja High-leidudest. --severity HIGH,CRITICAL piirab Trivy väljundit.
  • Installitud ja parandatud versioon: kui parandatud versioon on olemas, uuendage baastõmmist või paketti ja koostage uuesti. trivy --ignore-unfixed ja grype --only-fixed peidavad leiud, millel parandust pole.
  • „won't fix“: distributsioon otsustas paketti selles väljalaskes mitte parandada. Kasutage uuemat baastõmmist või aktsepteerige riski.
  • Kaks tööriista, kaks andmebaasi: Trivy ja Grype annavad sageli erineva arvu leide. Kumbki ei eksi – nad kasutavad eri allikaid.

SBOM-i eksport

Tarkvara koostisosade loend (SBOM) loetleb kõik tõmmise paketid. Trivy kirjutab CycloneDX-i ja SPDX-i; Grype'i kaaslane Syft kirjutab samuti mõlemat.

Terminal
trivy image --input python-img --format cyclonedx -o sbom.cdx.json
trivy image --input python-img --format spdx-json -o sbom.spdx.json

Koostamise nurjamine tõsiste leidude korral

Laske skriptis väljumiskood määrata skanneril. Grype väljub nullist erineva koodiga, kui leidub antud või kõrgema raskusastmega leid; Trivyga kasutage --exit-code 1 --severity HIGH,CRITICAL.

Terminal
grype oci-dir:python-img --fail-on high
echo $?

Skannimine Gantryst

Gantry 0.29.0 teeb need sammud teie eest. Valige tõmmise menüüs või tõmmise üksikasjade tööriistaribal Skanni turvaauke….

  • Gantry leiab Trivy või Grype'i muutujast GANTRY_TRIVY või GANTRY_GRYPE, PATH-ist või kaustadest /opt/homebrew/bin ja /usr/local/bin. Kui mõlemad on installitud, on vaikimisi Trivy. Kui skannerit pole, näitab aken Homebrew käske.
  • apple/containeris salvestab Gantry tõmmise lipuga --platform, pakib selle lahti ja skannib kausta. Kohalikus Dockeris skannib see salvestatud arhiivi. SSH kaudu ühendatud Dockeris skannib see sildi registris olevat koopiat.
  • Leiud on rühmitatud raskusastme järgi, sümboli ja sõnaga, mitte ainult värviga. Igal real on lingiga ID, pakett, installitud versioon ja parandatud versioon. Filter leiab paketi või ID.
  • Ekspordi SBOM kirjutab CycloneDX-i (mõlemad tööriistad) või SPDX-i (Trivy).
  • Nupp Peata või akna sulgemine peatab skanneri ja eemaldab ajutised failid.

Küsimused ja vastused

Kuidas skannida Apple containeri tõmmist turvaaukude suhtes?

Salvestage see käsuga container image save --platform linux/arm64 -o app.tar app:dev, pakkige lahti käsuga tar -xf app.tar -C app-img ja käivitage siis trivy image --input app-img või grype oci-dir:app-img. Gantry teeb need sammud käsuga Skanni turvaauke….

Miks Trivy või Grype nurjub container image save'i arhiiviga?

Arhiiv algab kirjega ./. Trivy ei leia sealt faili manifest.json ega index.json ning Grype peab seda kirjet teekonna läbimise rünnakuks (path traversal). Pakkige arhiiv lahti ja skannige kausta.

Trivy või Grype: kumba kasutada?

Mõlemad on tasuta ja avatud lähtekoodiga. Trivy leiab ka saladusi ja väärkonfiguratsioone ning kirjutab SPDX-i; Grype on väike ja keskendub pakettidele. Nad kasutavad eri andmebaase, seega leiab mõlema käivitamine rohkem. Kui mõlemad on installitud, kasutab Gantry Trivyt.

Kas Gantry installib skannerid?

Ei. Installige need käsuga brew install trivy grype. Gantry otsib neid PATH-ist, kaustadest /opt/homebrew/bin ja /usr/local/bin või muutujatest GANTRY_TRIVY ja GANTRY_GRYPE.

Kas tõmmiste skannimiseks on vaja Docker Scouti või Dockeri kontot?

Ei. Trivy ja Grype töötavad ilma kontota nii Dockeri kui ka Apple containeri tõmmistega.
