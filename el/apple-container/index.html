Gantry/Οδηγός apple/container

Apple container σε Mac: ο πλήρης οδηγός και GUI

Το apple/container εκτελεί κοντέινερ Linux στο Mac σας, το καθένα στη δική του ελαφριά εικονική μηχανή. Διατίθεται ως εργαλείο γραμμής εντολών. Το Gantry είναι ένα εγγενές GUI του macOS γι’ αυτό. Ο οδηγός εξηγεί το εργαλείο, πώς να το ρυθμίσετε και ποια λειτουργία του Gantry καλύπτει κάθε εντολή container.

Με λίγα λόγια. Το Gantry είναι μια δωρεάν εφαρμογή macOS ανοιχτού κώδικα (MIT) που διαχειρίζεται το εργαλείο container της Apple και το Docker από ένα παράθυρο. Υποστηρίζει CLI container 1.0 έως 1.6.1 (συνιστώμενη) και εμφανίζει μόνο τις λειτουργίες που υποστηρίζει η έκδοση του CLI σας. Εγκαταστήστε το με brew install --cask getgantry/tap/gantry.

Τι είναι το apple/container;

Το apple/container είναι ένα εργαλείο ανοιχτού κώδικα της Apple, γραμμένο σε Swift, που δημιουργεί και εκτελεί κοντέινερ Linux σε Mac. Το Docker Desktop εκτελεί όλα τα κοντέινερ σε μία κοινή εικονική μηχανή Linux· το apple/container εκτελεί κάθε κοντέινερ στη δική του ελαφριά εικονική μηχανή, πάνω στο Virtualization framework της Apple. Χρησιμοποιεί τυπικές εικόνες OCI, οπότε κάνει pull και push στα ίδια μητρώα με το Docker.

  • Υλικό: Mac με Apple silicon.
  • macOS: η Apple το υποστηρίζει στο macOS 26.
  • Περιβάλλον χρήσης: μόνο το CLI container. Δεν υπάρχει εφαρμογή γραφικού περιβάλλοντος ούτε εντολή compose.
  • Δικτύωση: κάθε κοντέινερ παίρνει δική του διεύθυνση IP στο Mac σας, και οι τοπικοί τομείς DNS δίνουν στα κοντέινερ ονόματα όπως web.test.

Γιατί GUI για το apple/container;

Το CLI είναι πλήρες, αλλά η καθημερινή δουλειά σημαίνει πολλές εντολές: container list, logs, stats, exec, και μετά system, builder, registry, machine και cluster για τα υπόλοιπα. Το Gantry τα συγκεντρώνει σε ένα παράθυρο με ζωντανές ενημερώσεις, ώστε να βλέπετε την κατάσταση αντί να τη ρωτάτε ξανά και ξανά. Προσθέτει επίσης ό,τι δεν έχει το CLI: αρχεία Compose, γνωστοποιήσεις αποτυχίας, προβολή στόλου μαζί με τους host Docker σας και διακομιστή MCP για πράκτορες AI.

Ρύθμιση του apple/container με το Gantry

  1. Εγκαταστήστε το Gantry: brew install --cask getgantry/tap/gantry και μετά αφαιρέστε τη σήμανση καραντίνας (δείτε Εγκατάσταση).
  2. Εγκαταστήστε το CLI container από το υπογεγραμμένο .pkg στη σελίδα εκδόσεων του apple/container. Αν λείπει ή είναι παλαιότερο από το 1.0, το Gantry εμφανίζει ένα φύλλο ρύθμισης με τα βήματα.
  3. Στο Gantry, επιλέξτε Προσθήκη host… και προσθέστε έναν host Apple Container. Η σύνδεση ξεκινά τις υπηρεσίες του container αν είναι σταματημένες.
  4. Αν δεν υπάρχει εγκατεστημένος προεπιλεγμένος πυρήνας, η επισκόπηση του host εμφανίζει ένα banner. Κάντε κλικ σε αυτό για να εγκαταστήσετε τον συνιστώμενο πυρήνα.
Προσοχή
Χρησιμοποιήστε το υπογεγραμμένο πακέτο εγκατάστασης, όχι την έκδοση του Homebrew. Η έκδοση του Homebrew δεν περιλαμβάνει το backend μηχανημάτων, οπότε το container machine δεν μπορεί να εκτελεστεί.

Κάθε εντολή container και η λειτουργία της στο Gantry

Ο πίνακας αντιστοιχίζει το CLI container στο Gantry. Η τελευταία στήλη δείχνει την έκδοση CLI που χρειάζεται το Gantry για τη λειτουργία. Οποιαδήποτε σημαίνει κάθε υποστηριζόμενο CLI, 1.0 ή νεότερο. Το Gantry διαβάζει την εγκατεστημένη έκδοσή σας και κρύβει τις λειτουργίες που δεν υποστηρίζει.

Τι προσθέτει το Gantry στο apple/container

Cluster Kubernetes

Δημιουργήστε cluster Kubernetes με πολλά worker μέσω του container cluster, επιλέξτε CNI, δείτε κάθε κόμβο, γράψτε το kubeconfig και φορτώστε τοπικές εικόνες στο cluster. Δείτε το Kubernetes στο apple/container.

Μηχανήματα container και VS Code

Τα μηχανήματα είναι μακρόβια περιβάλλοντα Linux από το container machine. Το Gantry τα δημιουργεί, τα ξεκινά, τα σταματά και τα διαγράφει, ορίζει το προεπιλεγμένο μηχάνημα, αλλάζει CPU και μνήμη και ανοίγει shell. Με CLI 1.1 ή νεότερο, ένα μηχάνημα μπορεί να εκκινήσει με ένθετη εικονικοποίηση (Apple silicon M3 ή νεότερο) και προσαρμοσμένο πυρήνα. Το Άνοιγμα στο VS Code συνδέεται σε μηχάνημα σε εκτέλεση μέσω Remote-SSH· η εικόνα του μηχανήματος πρέπει να εκτελεί sshd.

Docker Compose στο apple/container

Ανοίξτε ένα docker-compose.yml από το Finder (Άνοιγμα με ▸ Gantry ή Γρήγορες ενέργειες ▸ Compose Up στο apple/container), από το Αρχείο ▸ Άνοιγμα αρχείου Compose… ή σύροντάς το στο παράθυρο. Το Gantry δομεί τις υπηρεσίες build:, δημιουργεί το δίκτυο του έργου και τους ονομασμένους τόμους και ξεκινά κάθε υπηρεσία με τη σειρά του depends_on, με τις τυπικές ετικέτες com.docker.compose.*. Με ορισμένο προεπιλεγμένο τομέα DNS, οι υπηρεσίες βρίσκουν η μία την άλλη με το όνομα υπηρεσίας μέσω ψευδωνύμων δικτύου.

Ψευδώνυμα DNS δικτύου και τοπικοί τομείς

Το Gantry περνά τα ψευδώνυμα δικτύου στο container ως --network <name>,alias=…. Χωρίς προεπιλεγμένο τομέα DNS, περνούν μόνο πλήρως προσδιορισμένα ονόματα, και ένα ψευδώνυμο υποδέντρου (με αρχική τελεία, όπως .gateway) περνά μόνο ως το ακριβές ψευδώνυμό του. Με προεπιλεγμένο τομέα λειτουργούν και τα σύντομα ονόματα. Το Gantry δημιουργεί και διαγράφει τοπικούς τομείς DNS, ορίζει τον προεπιλεγμένο τομέα και δίνει στα νέα κοντέινερ hostname name.domain. Δείτε Τοπικά ονόματα DNS.

Σύστημα: υπηρεσίες, builder, μητρώα, πυρήνας, αρχεία καταγραφής, ιδιότητες

Κάθε host apple/container έχει μια ενότητα Σύστημα. Λειτουργεί και όταν ο host είναι αποσυνδεδεμένος, ώστε να μπορείτε να ξεκινήσετε από εκεί σταματημένες υπηρεσίες.

  • Κατάσταση και έκδοση: εκδόσεις πελάτη και διακομιστή, με προειδοποίηση όταν διαφέρουν· έναρξη, διακοπή και επανεκκίνηση των υπηρεσιών· στοιχεία και διαδρομές του host.
  • Builder εικόνων: κατάσταση, εικόνα, CPU, μνήμη και IP· έναρξη με επιλογές CPU, μνήμης και DNS· διακοπή· διαγραφή.
  • Συνδέσεις σε μητρώα: λίστα, σύνδεση και αποσύνδεση. Ο κωδικός πρόσβασης περνά στο CLI μόνο μέσω stdin (--password-stdin) και το Gantry δεν κρατά αντίγραφο.
  • Πυρήνας: εγκατάσταση του συνιστώμενου πυρήνα, αρχείου πυρήνα ή αρχείου tar, με ζωντανή πρόοδο.
  • Αρχεία καταγραφής υπηρεσιών: ζωντανά ή εφάπαξ, για διάστημα από 5 λεπτά έως 1 ημέρα, με φίλτρο επιπέδου, υπηρεσίας και κειμένου.
  • Ιδιότητες συστήματος: οι αλλαγές γράφονται στο ~/.config/container/config.toml, με ένδειξη εκκρεμούς επανεκκίνησης και κουμπί Επανεκκίνηση υπηρεσιών.

Commit, περικοπή δίσκου και αρχεία

Το Commit σε εικόνα χρησιμοποιεί το container commit (CLI 1.6). Η Περικοπή δίσκου χρησιμοποιεί το container clean (CLI 1.4) και εμφανίζεται επίσης ως γραμμή στην «Ανάκτηση χώρου». Η καρτέλα «Αρχεία» κατεβάζει αρχεία και σας αφήνει να τα σύρετε στο Finder με το container copy (το κοντέινερ πρέπει να έχει ξεκινήσει), και ανεβάζει αρχεία και φακέλους.

Ετικέτες που περιέχουν =

Το container create απορρίπτει τιμή ετικέτας που περιέχει =, και στο CLI 1.6.1. Το Gantry κωδικοποιεί τέτοιες τιμές όταν δημιουργεί το κοντέινερ και τις αποκωδικοποιεί όταν τις διαβάζει, ώστε οι ετικέτες που ορίζετε να είναι αυτές που βλέπετε.

Διακομιστής MCP και Συντομεύσεις

Ο ενσωματωμένος διακομιστής gantry-mcp δίνει στους πράκτορες AI τις ίδιες δυνατότητες στους host apple/container: κοντέινερ, εικόνες, τόμους, δίκτυα, Compose, μηχανήματα (list_machines, create_machine κ.ά.), cluster (list_clusters, create_cluster, delete_cluster) και τα εργαλεία συστήματος apple_* για υπηρεσίες, builder, μητρώα (χωρίς εργαλείο σύνδεσης), ιδιότητες, αρχεία καταγραφής και εγκατάσταση πυρήνα. Τα App Intents προσθέτουν ενέργειες για τις Συντομεύσεις και τη Siri. Δείτε Πράκτορες AI και MCP.

Προσθήκη του διακομιστή MCP του Gantry
claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp

Το apple/container δίπλα στο Docker

Το Gantry διαχειρίζεται host apple/container, τον τοπικό daemon του Docker (Docker Desktop, OrbStack, Colima) και απομακρυσμένους host Docker μέσω SSH σε μία πλαϊνή στήλη και έναν πίνακα ελέγχου στόλου. Δεν χρειάζεται να διαλέξετε ένα runtime. Για σύγκριση των εργαλείων λειτουργία προς λειτουργία, δείτε Gantry έναντι Docker Desktop, OrbStack και Podman Desktop.

Ερωτήσεις και απαντήσεις

Ποιο είναι το καλύτερο GUI για το Apple container;

Το Gantry είναι ένα δωρεάν, ανοιχτού κώδικα, εγγενές GUI του macOS φτιαγμένο για το apple/container. Μεταφέρει το CLI container σε μια εφαρμογή γραφικού περιβάλλοντος: κοντέινερ, αρχεία καταγραφής, στατιστικά και exec, καθώς και cluster Kubernetes, μηχανήματα, τον builder εικόνων, συνδέσεις σε μητρώα, πυρήνες, αρχεία καταγραφής υπηρεσιών και ιδιότητες συστήματος. Ο πίνακας σε αυτή τη σελίδα δείχνει κάθε εντολή και τη λειτουργία του Gantry που τη χρησιμοποιεί.

Έχει το Apple container γραφικό περιβάλλον;

Η Apple διαθέτει το container μόνο ως εργαλείο γραμμής εντολών. Το Gantry είναι μια ξεχωριστή εφαρμογή ανοιχτού κώδικα που του δίνει GUI, δίπλα στους host Docker σας.

Μπορώ να χρησιμοποιήσω docker compose με το Apple container;

Το apple/container δεν έχει εντολή compose. Το Gantry διαβάζει ένα docker-compose.yml, δομεί τις υπηρεσίες build:, δημιουργεί το δίκτυο και τους ονομασμένους τόμους και ξεκινά τις υπηρεσίες με τη σειρά του depends_on. Τα ονόματα υπηρεσιών επιλύονται μέσω ψευδωνύμων DNS δικτύου.

Πώς ανοίγω ένα μηχάνημα container στο VS Code;

Ξεκινήστε το μηχάνημα στο Gantry και κάντε κλικ στο Άνοιγμα στο VS Code. Το Gantry το ανοίγει μέσω Remote-SSH, όπως στο παράδειγμα container-machine-vscode της Apple. Η εικόνα του μηχανήματος πρέπει να εκτελεί sshd.

Λειτουργεί το Apple container σε Mac με Intel;

Όχι. Το apple/container απαιτεί Mac με Apple silicon. Το Gantry λειτουργεί και σε Mac με Intel, αλλά εκεί διαχειρίζεται μόνο host Docker.

Ποια έκδοση του CLI container να εγκαταστήσω;

Το Gantry απαιτεί 1.0 ή νεότερη και έχει δοκιμαστεί με την 1.6.1. Εγκαταστήστε την με το υπογεγραμμένο πακέτο εγκατάστασης από τη σελίδα εκδόσεων του apple/container. Η έκδοση του Homebrew δεν περιλαμβάνει το backend μηχανημάτων, οπότε το container machine δεν λειτουργεί με αυτή.
