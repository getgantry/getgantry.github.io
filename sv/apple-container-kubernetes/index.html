Gantry/Kubernetes på apple/container

Kubernetes på Apple container

apple/container kan köra ett Kubernetes-kluster vars noder är containrar på din Mac. Gantry är ett GUI för det: skapa ett kluster, se noderna starta, anslut kubectl och läs in dina lokala images, utan långa kommandorader med container cluster.

Kort sagt. På en apple/container-värd skapar och raderar avsnittet Kluster i Gantry Kubernetes-kluster med container cluster (CLI 1.6.1) eller container k8s (CLI 1.5.0 till 1.6.0). Det stöder flera workers, en anpassad CNI, en vy över noderna, kubeconfig och kubectl-kontext samt Läs in i kluster för lokala images.

Krav

  • En Mac med Apple-chip, macOS 26 och Gantry (brew install --cask getgantry/tap/gantry).
  • container-CLI 1.5.0 eller senare; 1.6.1 rekommenderas. Workers och CNI-valet Ingen kräver 1.6.0 eller senare.
  • kubectl, om du vill använda klustret från terminalen.

Skapa ett kluster

  1. Välj din apple/container-värd och öppna Kluster i sidofältet.
  2. Starta ett nytt kluster och fyll i alternativen nedan.
  3. Skapa det. Listan visar det nya klustret och förloppet live. Avbryt stoppar skapandet och raderar de noder som redan har skapats.
AlternativCLI-flaggaKommentar
Namn--nameÄven namnet på kubeconfig-kontexten
Workers--workersAntal worker-noder. CLI 1.6.0+
CPU:er--cpusPer nod
Minne--memoryPer nod, till exempel 4G
Nodimage--node-imageTomt behåller CLI:ets standard
CNI--cniStandard (medföljande kindnet), Ingen (NONE, CLI 1.6.0+) eller sökväg till ett anpassat manifest

Samma kommando i CLI:et:

Skal
container cluster create --name dev --workers 2 --cpus 2 --memory 4G

Noder och klusterdetaljer

Klusterlistan visar varje kluster med dess noder: roll, status och adress. Detaljvyn har Översikt (kubectl-kontext, API-server, workers, nodnätverk), en tabell Noder, Granska för rådata om noderna och åtgärderna Skriv kubeconfig, Kopiera kubectl-kontextkommando och Radera.

Anslut kubectl

CLI:et lägger till en kontext med klustrets namn i ~/.kube/config när det skapar klustret. Använd Kopiera kubectl-kontextkommando i Gantry, eller skriv det själv:

Skal
kubectl --context dev get nodes

Om du vill ha klustret i en egen fil använder du Skriv kubeconfig. Gantry kör container cluster write-config; standardsökvägen är ~/.kube/<name>.kubeconfig.

Läs in lokala images i klustret

Bygg eller hämta en image på apple/container-värden, högerklicka sedan på den under Images och välj Läs in i kluster. Gantry kör container cluster load-image, som kopierar imagen till containerd på varje nod. Du behöver inget register för lokal utveckling.

Skal
container cluster load-image --name dev myapp:dev

Välj en CNI

Standard är det medföljande kindnet-manifestet. Välj Anpassat manifest för att installera en egen CNI, till exempel Calico eller Cilium, från en fil. Välj Ingen om du vill installera en CNI själv senare; tills dess förblir noderna NotReady.

Kluster från AI-agenter

Gantrys MCP-server har list_clusters, create_cluster och delete_cluster, så en agent som Claude Code kan skapa ett tillfälligt kluster för ett test och ta bort det efteråt.

Lägg till Gantrys MCP-server
claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp

Frågor och svar

Stöder Apple container Kubernetes?

Ja. container-CLI:et skapar Kubernetes-kluster vars noder körs som containrar: container cluster i CLI 1.6.1, container k8s i CLI 1.5.0 till 1.6.0. Gantry ger det ett GUI.

Stöder Gantry container cluster?

Ja. Gantry listar, skapar och raderar kluster på apple/container-värdar, visar deras noder, skriver kubeconfig, kopierar kommandot för kubectl-kontexten och läser in lokala images i ett kluster. Den använder cluster eller k8s beroende på din CLI-version.

Hur använder jag kubectl med ett kluster i apple/container?

När CLI:et skapar ett kluster lägger det till en kubeconfig-kontext med klustrets namn i ~/.kube/config. Kör kubectl --context <name> get nodes. Om du vill ha en separat fil använder du Skriv kubeconfig i Gantry; standardsökvägen är ~/.kube/<name>.kubeconfig.

Hur får jag in en lokal image i klustret utan register?

Högerklicka på imagen under Images i Gantry och välj Läs in i kluster. Gantry kör container cluster load-image, som kopierar imagen till containerd på varje nod.

Kan jag skapa ett kluster med flera noder?

Ja. Ange antalet workers i arket för att skapa klustret. Workers kräver CLI 1.6.0 eller senare.

Kan jag använda en egen CNI som Calico eller Cilium?

Ja. Välj Anpassat manifest och välj manifestfilen, eller välj Ingen och installera en CNI själv när klustret har startat. Noderna förblir NotReady tills en CNI körs. Ingen kräver CLI 1.6.0 eller senare. Standard-CNI:n är det medföljande kindnet-manifestet.
