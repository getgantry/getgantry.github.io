Gantry/apple/containeri juhend

Apple container Macis: täielik juhend ja GUI

apple/container käitab Linuxi konteinereid teie Macis, igaüht oma kerges virtuaalmasinas. See tuleb käsureatööriistana. Gantry on selle jaoks natiivne macOS-i GUI. See juhend selgitab tööriista, selle seadistamist ja seda, milline Gantry funktsioon katab iga container käsu.

Lühidalt. Gantry on tasuta avatud lähtekoodiga (MIT) macOS-i rakendus, mis haldab Apple'i container-tööriista ja Dockerit ühest aknast. See toetab container CLI versioone 1.0 kuni 1.7.1 (soovitatud) ja näitab ainult neid funktsioone, mida teie CLI versioon toetab. Installige see käsuga brew install --cask getgantry/tap/gantry.

Mis on apple/container?

apple/container on Apple'i Swiftis kirjutatud avatud lähtekoodiga tööriist, mis loob ja käitab Linuxi konteinereid Macis. Docker Desktop käitab kõiki konteinereid ühes jagatud Linuxi virtuaalmasinas; apple/container käitab iga konteinerit oma kerges virtuaalmasinas, mis põhineb Apple'i raamistikul Virtualization. See kasutab standardseid OCI-tõmmiseid, seega tõmbab samadest registritest ja lükkab samadesse registritesse nagu Docker.

  • Riistvara: Apple'i kiibiga Mac.
  • macOS: Apple toetab seda macOS 26-s.
  • Liides: ainult container CLI. Töölauarakendust ega käsku compose pole.
  • Võrk: iga konteiner saab teie Macis oma IP-aadressi ning kohalikud DNS-domeenid annavad konteineritele nimed nagu web.test.

Miks kasutada apple/containeri jaoks GUI-d?

CLI on täielik, kuid igapäevane töö tähendab palju käske: container list, logs, stats, exec ning ülejäänu jaoks system, builder, registry, machine ja cluster. Gantry koondab need ühte aknasse, mis uueneb reaalajas, nii et näete olekut, ilma et peaksite seda pidevalt pärima. Lisaks toob see selle, mida CLI-s pole: Compose'i failid, tõrketeavitused, ühise vaate koos Dockeri hostidega ja MCP-serveri AI-agentidele.

apple/containeri seadistamine Gantryga

  1. Installige Gantry: brew install --cask getgantry/tap/gantry, seejärel eemaldage karantiinilipp (vt Installimine).
  2. Installige container CLI allkirjastatud .pkg-paketist apple/containeri väljalasete lehelt. Kui see puudub või on vanem kui 1.0, näitab Gantry seadistuslehte koos sammudega.
  3. Valige Gantrys Lisa host… ja lisage Apple Containeri host. Ühendamine käivitab container teenused, kui need on peatatud.
  4. Kui vaikimisi tuuma pole installitud, kuvatakse hosti ülevaates teaderiba. Klõpsake sellel, et installida soovitatud tuum.
Tähelepanu
Kasutage allkirjastatud installipaketti, mitte Homebrew-versiooni. Homebrew-versioonis pole masinate taustasüsteemi ega versioonis 1.7.1 klastriteenuseid, seega container machine ja container cluster ei saa töötada.

Mida Gantry apple/containerile lisab

Kubernetese klastrid

Looge Kubernetese klastreid käsuga container cluster, määrake töösõlmede suurus, laske podidel kasutada teie kohalikke tõmmiseid, valige CNI ja vaadake iga sõlme. Seejärel sirvige klastrit Gantry Kubernetese brauseris. Vaadake lehte Kubernetes apple/containeris ja samm-sammulist juhendit Kubernetes Macis.

Konteinermasinad ja VS Code

Masinad on pikaealised Linuxi keskkonnad, mis luuakse käsuga container machine. Gantry loob, käivitab, peatab ja kustutab neid, määrab vaikimisi masina, muudab CPU-sid ja mälu ning avab shelli. CLI 1.1 või uuemaga saab masina buutida pesastatud virtualiseerimisega (Apple'i kiip M3 või uuem) ja kohandatud tuumaga. Ava VS Code'is ühendub töötava masinaga Remote-SSH kaudu; masina tõmmises peab töötama sshd.

Docker Compose apple/containeris

Avage docker-compose.yml Finderist (Ava rakendusega ▸ Gantry või Kiirtoimingud ▸ Compose Up apple/containeris), menüüst Fail ▸ Ava Compose'i fail… või lohistades selle aknasse. Gantry koostab build:-teenused, loob projekti võrgu ja nimega köited ning käivitab teenused depends_on järjekorras standardsiltidega com.docker.compose.*. Kui vaikimisi DNS-domeen on määratud, jõuavad teenused üksteiseni teenuse nime kaudu võrgu aliaste abil.

Võrgu DNS-aliased ja kohalikud domeenid

Gantry edastab võrgu aliased container-ile kujul --network <name>,alias=…. Ilma vaikimisi DNS-domeenita lähevad läbi ainult täielikud nimed ning alampuualias (algab punktiga, nt .gateway) läheb läbi ainult täpse aliasena. Vaikimisi domeeniga töötavad ka lühinimed. Gantry loob ja kustutab kohalikke DNS-domeene, määrab vaikimisi domeeni ja annab uutele konteineritele hostinime name.domain. Vt Kohalikud DNS-nimed.

Süsteem: teenused, koostaja, registrid, tuum, logid, atribuudid

Igal apple/containeri hostil on jaotis Süsteem. See töötab ka siis, kui host pole ühendatud, nii et peatatud teenused saab käivitada sealt.

  • Olek ja versioon: kliendi ja serveri versioonid ning hoiatus, kui need erinevad; teenuste käivitamine, peatamine ja taaskäivitamine; hosti andmed ja teed.
  • Tõmmisekoostaja: olek, tõmmis, CPU-d, mälu ja IP; käivitamine CPU, mälu ja DNS-i valikutega; peatamine; kustutamine. Kaart annab teada, kui koostaja tõmmis on aegunud, ja loob selle uuesti.
  • Registritesse sisselogimised: loend, sisse- ja väljalogimine. Parool läheb CLI-le ainult stdin-i kaudu (--password-stdin) ja Gantry ei hoia sellest koopiat.
  • Tuum: soovitatud tuuma, tuumafaili või tar-arhiivi installimine, edenemine reaalajas.
  • Teenuste logid: reaalajas või ühekordselt, 5 minuti kuni 1 päeva kohta, filtreerimine taseme, teenuse ja teksti järgi.
  • Süsteemiatribuudid: muudatused lähevad faili ~/.config/container/config.toml, ootel taaskäivituse märgi ja nupuga Taaskäivita teenused. CLI 1.7-s on [container.dns] nimeserverite, otsingudomeenide ja valikute jaoks loendiredaktor.

Tõmmisena salvestamine, Kärbi ketast ja failid

Salvesta tõmmisena kasutab käsku container commit (CLI 1.6). Kärbi ketast kasutab käsku container clean (CLI 1.4) ja on ka reana paneelis Vabasta ruumi. Vahekaart Failid laadib faile alla ja laseb neid käsuga container copy Finderisse lohistada (konteiner peab olema käivitatud) ning laadib üles faile ja kaustu.

Sildid, mis sisaldavad =

container create lükkab tagasi sildiväärtuse, milles on =, ka CLI 1.6.1-s. Gantry kodeerib sellised väärtused konteineri loomisel ja dekodeerib need tagasi lugemisel, nii et näete just neid silte, mille määrasite.

MCP-server ja Otseteed

Kaasasolev gantry-mcp server annab AI-agentidele apple/containeri hostides sama ulatuse: konteinerid, tõmmised, köited, võrgud, Compose, masinad (list_machines, create_machine jt), klastrid (list_clusters, create_cluster, delete_cluster) ja apple_* süsteemitööriistad teenuste, koostaja, registrite (sisselogimise tööriista pole), atribuutide, logide ja tuuma installimise jaoks. App Intents lisab Otseteede ja Siri toimingud. Vt AI-agendid & MCP.

Gantry MCP-serveri lisamine
claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp

apple/container Dockeri kõrval

Gantry haldab apple/containeri hoste, kohalikku Dockeri deemonit (Docker Desktop, OrbStack, Colima) ja SSH kaudu ühendatud kaug-Dockeri hoste ühes külgribas ja ühel taristu töölaual. Te ei pea valima ühte käituskeskkonda. Tööriistade funktsioonipõhise võrdluse leiate lehelt Gantry vs Docker Desktop, OrbStack ja Podman Desktop. Oma töö üleviimiseks lugege juhendit Docker Desktopilt Apple containerile.

Küsimused ja vastused

Milline on parim GUI Apple containerile?

Gantry on tasuta avatud lähtekoodiga natiivne macOS-i GUI, mis on loodud apple/containeri jaoks. See viib container CLI töölauarakendusse: konteinerid, logid, statistika ja exec ning lisaks Kubernetese klastrid, masinad, tõmmisekoostaja, registritesse sisselogimised, tuumad, teenuste logid ja süsteemiatribuudid. Selle lehe tabel loetleb iga käsu ja seda kasutava Gantry funktsiooni.

Kas Apple containeril on graafiline kasutajaliides (GUI)?

Apple tarnib container-i ainult käsureatööriistana. Gantry on eraldi avatud lähtekoodiga rakendus, mis annab sellele GUI teie Dockeri hostide kõrval.

Kas docker compose'i saab kasutada Apple containeriga?

apple/containeril pole käsku compose. Gantry loeb faili docker-compose.yml, koostab build:-teenused, loob võrgu ja nimega köited ning käivitab teenused depends_on järjekorras. Teenuste nimed lahendatakse võrgu DNS-aliaste kaudu.

Kuidas avada konteinermasin VS Code'is?

Käivitage masin Gantrys ja klõpsake Ava VS Code'is. Gantry avab selle Remote-SSH kaudu, nagu Apple'i näites container-machine-vscode. Masina tõmmises peab töötama sshd.

Kas Apple container töötab Inteliga Macis?

Ei. apple/container vajab Apple'i kiibiga Maci. Gantry töötab ka Inteliga Macides, kuid seal haldab see ainult Dockeri hoste.

Millise container CLI versiooni peaks installima?

Gantry vajab versiooni 1.0 või uuemat ja soovitab versiooni 1.7.1. Installige see allkirjastatud installipaketiga apple/containeri väljalasete lehelt. Homebrew-versioonis pole masinate taustasüsteemi ega versioonis 1.7.1 klastriteenuseid, seega container machine ja container cluster sellega ei tööta.
