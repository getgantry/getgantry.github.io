Gantry/Ulkoinen levy

Kontit ja taltiot ulkoisella levyllä

Levykuvat, kontit ja taltiot täyttävät pienen sisäisen levyn nopeasti. Applen container-työkalulla voit pitää nämä tiedot ulkoisella SSD-levyllä: sijoita yksittäisiä kansioita sinne sidosliitoksilla tai siirrä koko datan juurikansio. Tämä opas näyttää molemmat tavat ja sen, miten levyn voi irrottaa vahingoittamatta mitään.

Lyhyesti. Alusta levy APFS-muotoon. Yhtä projektia varten liitä kansio sidosliitoksella: -v /Volumes/Fast/pg:/data. Kaikkea varten pysäytä palvelut, kopioi ~/Library/Application Support/com.apple.container levylle komennolla cp -Rp ja käynnistä palvelut joka kerta komennolla container system start --app-root /Volumes/Fast/container.

Missä tiedot ovat nyt

apple/container säilyttää kaikki tietonsa yhdessä kansiossa, sovelluksen juurikansiossa (app root). Oletuksena se on ~/Library/Application Support/com.apple.container, ja siinä on kansiot konteille, levykuvien sisällölle, tilannevedoksille, taltioille, ytimille ja verkoille. Tarkista polku ja käytetty tila:

Pääte
container system status | grep appRoot
container system df

Valitse ja alusta levy

  • Käytä USB-C- tai Thunderbolt-liitäntäistä SSD-levyä. Kiintolevykin toimii, mutta kontit käynnistyvät hitaammin.
  • Alusta se APFS-muotoon (myös Mac OS laajennettu toimii). Älä käytä exFAT-, FAT- tai NTFS-muotoa: taltiot ovat harvoja levykuvia, eikä näissä tiedostojärjestelmissä ole harvoja tiedostoja eikä Unix-oikeuksia.
  • Älä käytä verkkolevyä sovelluksen juurikansiona.
  • Anna levylle lyhyt nimi ilman välilyöntejä, esimerkiksi Fast. Polku on silloin /Volumes/Fast.

Vaihtoehto 1: projektin tiedot levylle sidosliitoksilla

Sidosliitos jakaa Macisi kansion kontille, ja kansio voi olla millä tahansa levyllä. Näin suuret tiedot, kuten tietokannan tai mallitiedostot, on helppo pitää poissa sisäiseltä levyltä:

Pääte
mkdir -p /Volumes/Fast/site
container run -d --name web -p 8080:80 \
  -v /Volumes/Fast/site:/usr/share/nginx/html:ro nginx:alpine

Levyn on oltava kytkettynä ennen kuin kontti käynnistyy. Levykuvat ja itse kontti pysyvät sisäisellä levyllä.

Vaihtoehto 2: kaikki apple/containerin tiedot levylle

Tämä siirtää levykuvat, kontit, tilannevedokset ja taltiot. Pysäytä ensin palvelut, jotta mikään tiedosto ei muutu kopioinnin aikana:

Pääte
container system stop
cp -Rp ~/Library/Application\ Support/com.apple.container /Volumes/Fast/container
container system start --app-root /Volumes/Fast/container
container system status | grep appRoot
container ls -a && container image ls && container volume ls

Käytä komentoa cp -Rp. Testissämme macOS 27:llä (APFS:stä APFS:ään USB:n kautta) se säilytti taltioiden levykuvat harvoina ja säilytti laajennetut määritteet. ditto kirjoitti jokaisen harvan levykuvan täysikokoisena, mikä voi täyttää levyn. Säilytä vanha kansio, kunnes olet tarkistanut, että konttisi, levykuvasi ja taltiosi näkyvät luetteloissa.

Huomio
CLI ei muista valintaa --app-root. Jokainen container system start ilman sitä käyttää taas sisäistä kansiota. Käytä valintaa joka kerta, esimerkiksi komentotulkin aliaksessa, ja tarkista paths.appRoot komennon container system status tulosteesta.

Gantry 0.27.0 käynnistää palvelut ilman valintaa --app-root, kun se yhdistää isäntään, jonka palvelut on pysäytetty. Käynnistä palvelut ensin päätteestä valinnan kanssa; Gantry käyttää sitten käynnissä olevia palveluja. Gantryn tuki siirretylle datan juurikansiolle on kehitteillä.

Arkistoi levykuvat levylle

Jos haluat vapauttaa tilaa menettämättä levykuvaa, tallenna se ulkoiselle levylle ja poista se. Lataa se uudelleen, kun tarvitset sitä:

Pääte
mkdir -p /Volumes/Fast/images
container image save -o /Volumes/Fast/images/myapp.tar myapp:dev
container image delete myapp:dev
container image load -i /Volumes/Fast/images/myapp.tar

Irrota levy turvallisesti

  1. Pysäytä kontit, jotka käyttävät levyä: container stop <name>.
  2. Jos sovelluksen juurikansio on levyllä, pysäytä palvelut: container system stop.
  3. Poista levy käytöstä Finderissa ja irrota se sitten.

Jos levy katoaa, kun sillä olevat kontit ovat käynnissä, kontit kaatuvat ja kesken olevat kirjoitukset voivat kadota. Kun kytket levyn uudelleen, käynnistä palvelut valinnalla --app-root ja käynnistä sitten kontit.

Ulkoiset levyt Gantryssa

Gantry ajaa jo nyt sidosliitoksia miltä tahansa levyltä: lisää Uusi kontti -ikkunassa taltio, valitse kansio ulkoiselta levyltä ja polku kontissa. Gantryn tuki datan juurikansion siirrolle, taltioille ulkoisella levyllä ja varoitukselle, kun levy ei ole kytkettynä, on kehitteillä.

Docker Desktop ja OrbStack

Docker Desktop siirtää levykuvansa kohdassa Settings ▸ Resources ▸ Advanced ▸ Disk image location. OrbStack lisäsi datan sijainnin asetuksen versiossa 0.13.0. Katso vertailu.

Kysymyksiä ja vastauksia

Voiko Apple containerin levykuvat tallentaa ulkoiselle levylle?

Kyllä. Käynnistä palvelut komennolla container system start --app-root /Volumes/Disk/container. Kaikki levykuvat, kontit, tilannevedokset ja taltiot ovat sen jälkeen tässä kansiossa.

Mitä tiedostojärjestelmää ulkoisella levyllä pitäisi käyttää?

APFS:ää. Taltiot ovat harvoja levykuvia, ja kontit tarvitsevat Unix-oikeuksia, joita exFAT:ssa, FAT:ssa ja NTFS:ssä ei ole.

Miten konttien tiedot kopioidaan niin, ettei levy täyty?

Käytä komentoa cp -Rp, joka testissämme piti harvat taltioiden levykuvat pieninä. ditto kopioi jokaisen harvan levykuvan täysikokoisena.

Mitä tapahtuu, jos irrotan levyn konttien ollessa käynnissä?

Levyä käyttävät kontit kaatuvat, ja tiedot, joita ei vielä ollut kirjoitettu, voivat kadota. Pysäytä kontit ja, jos sovelluksen juurikansio on levyllä, myös palvelut ennen levyn poistamista käytöstä.

Muistaako container-CLI uuden sijainnin?

Ei. Anna valinta --app-root jokaiselle container system start -komennolle. container system status näyttää käytössä olevan juurikansion kohdassa paths.appRoot.
