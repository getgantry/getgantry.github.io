Gantry/A partir de docker run

Criar um contentor a partir de um comando docker run

A maioria dos README indica uma linha docker run. O Gantry lê essa linha e preenche o formulário Novo contentor, para um host Docker ou para a ferramenta container da Apple. Este guia mostra como, e como converter o comando à mão.

Em resumo. No Gantry, abra Novo contentor, escolha Colar comando…, cole a linha docker run e clique em Preencher formulário. O Gantry lista cada flag que não consegue usar, com o motivo. Na CLI, a maioria das flags é igual: substitua docker run por container run e remova --restart.

Colar o comando no Gantry

  1. Selecione um host: um host Docker ou um host apple/container.
  2. Abra Contentores e clique em Novo contentor.
  3. Clique em Colar comando… e cole a linha. Finais de linha com \, aspas, um prompt $ e sudo não causam problemas.
  4. Leia a pré-visualização: a imagem, as flags que o Gantry não consegue usar, as notas e os avisos para este host.
  5. Clique em Preencher formulário, verifique os valores e crie o contentor.

O Gantry lê docker run, docker container run, docker create, podman run e container run. O texto depois de &&, ||, ; ou | é ignorado, com uma nota.

São reconhecidas cerca de 80 outras flags do Docker: o Gantry ignora corretamente os respetivos valores e lista-as como não utilizadas, por isso nada se perde sem uma nota.

    Avisos para hosts apple/container

Algumas opções do Docker não existem no apple/container. O Gantry avisa sobre elas e deixa-as fora do pedido de criação:

  • políticas de reinício (--restart);
  • frações de CPU, como --cpus 0.5;
  • os modos de rede host, none e container:;
  • portas sem porta do host, como -p 80.

Num host Docker, o Gantry avisa sobre as opções do apple/container: o domínio DNS e as opções do kernel.

    Converter docker run em container run à mão

Na CLI, a maioria das flags mantém-se. Um exemplo com o Redis:

Terminal
docker run -d --name cache --restart unless-stopped -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

fica:

Terminal
container volume create redisdata
container run -d --name cache -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

Crie primeiro o volume com nome com container volume create. Remova --restart e arredonde --cpus para um número inteiro. --platform funciona como no Docker.

    Copiar um contentor como comando

O sentido inverso também funciona. Clique com o botão direito num contentor, ou use o menu Mais, e escolha Copiar como comando: o Gantry escreve uma linha docker run ou container run. Deixa de fora as predefinições da imagem, como o ambiente e o comando, para que a linha fique curta. Também funciona com contentores parados.

    Guardar como receita

Na folha Novo contentor, abra Receitas e escolha Guardar como receita…. Da próxima vez, Preencher a partir de receita dá o mesmo formulário em qualquer host. As receitas ficam em ~/Library/Application Support/Gantry/recipes.json, por isso pode fazer cópias de segurança ou partilhá-las.

    Limitações
  • O Gantry mantém o caminho de --env-file, mas não lê o ficheiro, e não lê a sua shell para -e KEY sem valor.
  • As montagens tmpfs e os volumes anónimos de --mount aparecem como não suportados.
  • Duas portas para a mesma porta do contentor (-p 8080:80 -p 8081:80) preenchem o formulário, mas o formulário recusa depois a duplicada.

Perguntas e respostas

Como converter docker run em container run?

Substitua docker run por container run. -d, -p, -e, -v, --name, --rm, -it, -w e --entrypoint mantêm-se. Remova --restart e use CPU inteiras. Ou cole a linha no Gantry e deixe-o preencher o formulário.

O Gantry consegue importar um comando docker run?

Sim. Colar comando… na folha Novo contentor lê docker run, docker create, podman run e container run e preenche o formulário.

O que acontece às flags que o Gantry não suporta?

São listadas na pré-visualização com o motivo e ficam no formulário, na secção Do comando colado, para as poder verificar mais tarde.

Posso transformar um contentor em execução de volta num comando docker run?

Sim. Copiar como comando no menu do contentor escreve uma linha docker run ou container run para esse contentor.
