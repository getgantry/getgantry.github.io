Gantry/Проверка образов

Проверка образов контейнеров на уязвимости на Mac

Trivy и Grype — бесплатные сканеры с открытым кодом, которые сравнивают пакеты в образе с базами известных уязвимостей. Образы Docker они читают напрямую. У инструмента container от Apple нет команды проверки и сокета Docker, поэтому образ сначала нужно сохранить. В руководстве показаны оба способа, а также как читать результаты, как записать SBOM и как проверять образы из Gantry.

Коротко. Выполните brew install trivy grype. На Docker выполните trivy image app:dev. На Apple container сохраните образ командой container image save --platform linux/arm64 -o app.tar app:dev, распакуйте его командой tar -xf app.tar -C app-img и проверьте папку: trivy image --input app-img или grype oci-dir:app-img. Сам tar-файл оба инструмента не принимают.

Установка сканера

Установите один сканер или оба через Homebrew. При первой проверке каждый из них скачивает свою базу уязвимостей, это занимает около минуты.

Терминал
brew install trivy grype

Мы проверили команды из этого руководства с Trivy 0.76.2, Grype 0.121.3 и container 1.7.1. Gantry нужен Trivy 0.50.0 или Grype 0.74.0 или новее.

Проверка образа Docker

С движком Docker (Docker Desktop, OrbStack или Colima) оба инструмента читают локальный образ по имени через сокет Docker:

Терминал
trivy image app:dev
grype app:dev

Проверка образа Apple container

Сохраните образ в OCI-архив и распакуйте его в папку. Укажите --platform: если в хранилище образов есть только часть платформ образа, container image save без этого флага завершается с ошибкой.

Терминал
container image pull python:3.11-slim
container image save --platform linux/arm64 -o python.tar python:3.11-slim
mkdir python-img && tar -xf python.tar -C python-img

Затем проверьте папку. Trivy читает её с флагом --input, Grype — с префиксом oci-dir::

Терминал
trivy image --input python-img --severity HIGH,CRITICAL
grype oci-dir:python-img
Внимание
Не передавайте файл .tar. Архив container image save начинается с записи ./: Trivy сообщает «file manifest.json not found in tar», а Grype отклоняет его как «potential path traversal attack». Распакованная папка работает с обоими.

Чтение результатов

  • Степень опасности: Critical, High, Medium, Low или Unknown. Начните с Critical и High. --severity HIGH,CRITICAL ограничивает вывод Trivy.
  • Установленная и исправленная версия: если исправленная версия есть, обновите базовый образ или пакет и соберите заново. trivy --ignore-unfixed и grype --only-fixed скрывают находки без исправления.
  • «won't fix»: дистрибутив решил не исправлять пакет в этом выпуске. Используйте более новый базовый образ или примите риск.
  • Два инструмента, две базы: Trivy и Grype часто показывают разное число находок. Ни один не ошибается: у них разные источники.

Экспорт SBOM

Перечень компонентов ПО (SBOM) содержит все пакеты образа. Trivy записывает CycloneDX и SPDX; Syft, спутник Grype, тоже записывает оба формата.

Терминал
trivy image --input python-img --format cyclonedx -o sbom.cdx.json
trivy image --input python-img --format spdx-json -o sbom.spdx.json

Остановка сборки при серьёзных находках

В скрипте пусть код выхода задаёт сканер. Grype завершается с ненулевым кодом, если есть находка заданной степени опасности или выше; с Trivy используйте --exit-code 1 --severity HIGH,CRITICAL.

Терминал
grype oci-dir:python-img --fail-on high
echo $?

Проверка из Gantry

Gantry 0.29.0 выполняет эти шаги за вас. Выберите Проверить на уязвимости… в меню образа или на панели инструментов подробностей образа.

  • Gantry ищет Trivy или Grype в GANTRY_TRIVY или GANTRY_GRYPE, в PATH либо в /opt/homebrew/bin и /usr/local/bin. Если установлены оба, по умолчанию используется Trivy. Если сканера нет, окно показывает команды Homebrew.
  • На apple/container Gantry сохраняет образ с --platform, распаковывает его и проверяет папку. На локальном Docker он проверяет сохранённый архив. На Docker по SSH он проверяет копию тега в реестре.
  • Результаты сгруппированы по степени опасности, с символом и словом, а не только цветом. В каждой строке — ID со ссылкой, пакет, установленная версия и версия с исправлением. Фильтр находит пакет или ID.
  • Экспортировать SBOM записывает CycloneDX (оба инструмента) или SPDX (Trivy).
  • Кнопка Остановить или закрытие окна останавливает сканер и удаляет временные файлы.

Вопросы и ответы

Как проверить образ Apple container на уязвимости?

Сохраните его командой container image save --platform linux/arm64 -o app.tar app:dev, распакуйте командой tar -xf app.tar -C app-img, затем выполните trivy image --input app-img или grype oci-dir:app-img. В Gantry эти шаги выполняет Проверить на уязвимости….

Почему Trivy или Grype не принимает архив из container image save?

Архив начинается с записи ./. Trivy не находит в нём manifest.json или index.json, а Grype считает эту запись обходом пути (path traversal). Распакуйте архив и проверьте папку.

Trivy или Grype: что выбрать?

Оба бесплатны и с открытым кодом. Trivy также находит секреты и ошибки конфигурации и записывает SPDX; Grype компактнее и сосредоточен на пакетах. Базы у них разные, поэтому вместе они находят больше. Если установлены оба, Gantry использует Trivy.

Устанавливает ли Gantry сканеры?

Нет. Установите их командой brew install trivy grype. Gantry ищет их в PATH, /opt/homebrew/bin и /usr/local/bin или в GANTRY_TRIVY и GANTRY_GRYPE.

Нужен ли Docker Scout или аккаунт Docker, чтобы проверять образы?

Нет. Trivy и Grype работают без аккаунта — и с образами Docker, и с образами Apple container.
