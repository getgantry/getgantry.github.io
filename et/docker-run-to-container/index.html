Gantry/docker run käsust

Konteineri loomine docker run käsust

Enamik README-faile annab rea docker run. Gantry loeb selle rea ja täidab vormi Uus konteiner, kas Dockeri hosti või Apple'i container-tööriista jaoks. See juhend näitab, kuidas, ja kuidas käsku käsitsi teisendada.

Lühidalt. Avage Gantrys Uus konteiner, valige Kleebi käsk…, kleepige rida docker run ja klõpsake Täida vorm. Gantry loetleb põhjusega iga lipu, mida see kasutada ei saa. CLI puhul on enamik lippe samad: asendage docker run käsuga container run ja eemaldage --restart.

Käsu kleepimine Gantrysse

  1. Valige host: Dockeri host või apple/containeri host.
  2. Avage Konteinerid ja klõpsake Uus konteiner.
  3. Klõpsake Kleebi käsk… ja kleepige rida. Reaotsad märgiga \, jutumärgid, viip $ ja sudo ei sega.
  4. Lugege eelvaadet: tõmmis, lipud, mida Gantry kasutada ei saa, märkused ja selle hosti hoiatused.
  5. Klõpsake Täida vorm, kontrollige väärtusi ja looge konteiner.

Gantry loeb käske docker run, docker container run, docker create, podman run ja container run. Tekst pärast märke &&, ||, ; või | jäetakse märkusega kõrvale.

Tuntud on veel umbes 80 Dockeri lippu: Gantry jätab nende väärtused õigesti vahele ja loetleb need kasutamata lippudena, nii et midagi ei kao ilma märkuseta.

Hoiatused apple/containeri hostidele

Mõnda Dockeri valikut apple/containeris pole. Gantry hoiatab nende eest ja jätab need loomispäringust välja:

  • taaskäivituspoliitikad (--restart);
  • CPU murdosad, näiteks --cpus 0.5;
  • võrgurežiimid host, none ja container:;
  • pordid ilma hosti pordita, näiteks -p 80.

Dockeri hostis hoiatab Gantry apple/containeri valikute eest: DNS-domeen ja tuuma valikud.

docker run teisendamine container run käsuks käsitsi

CLI puhul jääb enamik lippe samaks. Redise näide:

Terminal
docker run -d --name cache --restart unless-stopped -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

muutub selleks:

Terminal
container volume create redisdata
container run -d --name cache -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

Looge nimega köide kõigepealt käsuga container volume create. Eemaldage --restart ja ümardage --cpus täisarvuks. --platform töötab nagu Dockeris.

Konteineri kopeerimine käsuna

Ka vastupidi saab. Paremklõpsake konteinerit või kasutage menüüd Veel ja valige Kopeeri käsuna: Gantry kirjutab rea docker run või container run. See jätab välja tõmmise vaikeväärtused, nagu selle keskkonna ja käsu, nii et rida jääb lühikeseks. See töötab ka peatatud konteineritega.

Salvestamine retseptina

Avage lehel Uus konteiner Retseptid ja valige Salvesta retseptina…. Järgmisel korral annab Täida retseptist sama vormi mis tahes hostis. Retseptid on failis ~/Library/Application Support/Gantry/recipes.json, nii et saate neid varundada või jagada.

Piirangud

  • Gantry säilitab lipu --env-file tee, kuid ei loe faili, ega loe väärtuseta -e KEY jaoks teie shelli.
  • Lipu --mount tmpfs-haakimised ja anonüümsed köited loetletakse toetamata valikutena.
  • Kaks porti sama konteineri pordi jaoks (-p 8080:80 -p 8081:80) täidavad vormi, kuid vorm lükkab seejärel duplikaadi tagasi.

Küsimused ja vastused

Kuidas teisendada docker run käsk container run käsuks?

Asendage docker run käsuga container run. -d, -p, -e, -v, --name, --rm, -it, -w ja --entrypoint jäävad samaks. Eemaldage --restart ja kasutage täisarv CPU-sid. Või kleepige rida Gantrysse ja laske sellel vorm täita.

Kas Gantry saab docker run käsku importida?

Jah. Kleebi käsk… lehel Uus konteiner loeb käske docker run, docker create, podman run ja container run ning täidab vormi.

Mis juhtub lippudega, mida Gantry ei toeta?

Need loetletakse eelvaates koos põhjusega ja jäävad vormi jaotisse Kleebitud käsust, nii et saate neid hiljem kontrollida.

Kas töötava konteineri saab muuta tagasi docker run käsuks?

Jah. Konteineri menüü toiming Kopeeri käsuna kirjutab selle konteineri jaoks rea docker run või container run.
