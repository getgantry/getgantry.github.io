Gantry/No docker run

Konteinera izveide no docker run komandas

Lielākajā daļā README failu ir dota docker run rinda. Gantry nolasa šo rindu un aizpilda jauna konteinera veidlapu Docker resursdatoram vai Apple rīkam container. Šis ceļvedis parāda, kā tas notiek un kā komandu pārveidot pašam.

Īsumā. Lietotnē Gantry atveriet Jauns konteiners, izvēlieties Ielīmēt komandu…, ielīmējiet docker run rindu un noklikšķiniet uz Aizpildīt veidlapu. Gantry uzskaita katru karodziņu, ko tā nevar izmantot, ar iemeslu. CLI lielākā daļa karodziņu ir tādi paši: aizstājiet docker run ar container run un noņemiet --restart.

Komandas ielīmēšana lietotnē Gantry

  1. Atlasiet resursdatoru: Docker resursdatoru vai apple/container resursdatoru.
  2. Atveriet Konteineri un noklikšķiniet uz Jauns konteiners.
  3. Noklikšķiniet uz Ielīmēt komandu… un ielīmējiet rindu. Rindu beigas ar \, pēdiņas, $ uzvedne un sudo netraucē.
  4. Izlasiet priekšskatījumu: attēls, karodziņi, ko Gantry nevar izmantot, piezīmes un brīdinājumi šim resursdatoram.
  5. Noklikšķiniet uz Aizpildīt veidlapu, pārbaudiet vērtības un izveidojiet konteineru.

Gantry nolasa docker run, docker container run, docker create, podman run un container run. Teksts aiz &&, ||, ; vai | tiek ignorēts, un par to tiek parādīta piezīme.

Gantry pazīst vēl aptuveni 80 citus Docker karodziņus: tā pareizi izlaiž to vērtības un uzskaita tos kā neizmantotus, tāpēc nekas nepazūd bez piezīmes.

    Brīdinājumi apple/container resursdatoriem

Dažu Docker opciju apple/container vidē nav. Gantry par tām brīdina un neiekļauj tās izveides pieprasījumā:

  • restartēšanas politikas (--restart);
  • CPU daļas, piemēram, --cpus 0.5;
  • tīkla režīmi host, none un container:;
  • porti bez resursdatora porta, piemēram, -p 80.

Docker resursdatorā Gantry brīdina par apple/container opcijām: DNS domēnu un kodola opcijām.

    docker run pārveidošana uz container run pašam

CLI lielākā daļa karodziņu paliek tādi paši. Redis piemērs:

Terminālis
docker run -d --name cache --restart unless-stopped -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

kļūst par:

Terminālis
container volume create redisdata
container run -d --name cache -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

Vispirms izveidojiet nosaukto sējumu ar container volume create. Noņemiet --restart un noapaļojiet --cpus līdz veselam skaitlim. --platform darbojas tāpat kā Docker.

    Konteinera kopēšana kā komandas

Darbojas arī otrādi. Ar peles labo pogu noklikšķiniet uz konteinera vai izmantojiet izvēlni „Vairāk” un izvēlieties Kopēt kā komandu: Gantry uzraksta docker run vai container run rindu. Tā neiekļauj attēla noklusējumus, piemēram, tā vidi un komandu, tāpēc rinda paliek īsa. Tas darbojas arī apturētiem konteineriem.

    Saglabāšana kā recepte

Jauna konteinera logā atveriet Receptes un izvēlieties Saglabāt kā recepti…. Nākamreiz Aizpildīt no receptes dod to pašu veidlapu jebkurā resursdatorā. Receptes glabājas failā ~/Library/Application Support/Gantry/recipes.json, tāpēc tās var dublēt vai kopīgot.

    Ierobežojumi
  • Gantry saglabā --env-file ceļu, bet nenolasa failu, un -e KEY bez vērtības gadījumā nenolasa jūsu čaulas vidi.
  • tmpfs montējumi un anonīmie sējumi no --mount tiek uzskaitīti kā neatbalstīti.
  • Divi porti vienam un tam pašam konteinera portam (-p 8080:80 -p 8081:80) aizpilda veidlapu, bet veidlapa pēc tam dublikātu nepieņem.

Jautājumi un atbildes

Kā pārveidot docker run uz container run?

Aizstājiet docker run ar container run. -d, -p, -e, -v, --name, --rm, -it, -w un --entrypoint paliek tādi paši. Noņemiet --restart un izmantojiet veselus CPU. Vai arī ielīmējiet rindu lietotnē Gantry un ļaujiet tai aizpildīt veidlapu.

Vai Gantry var importēt docker run komandu?

Jā. Ielīmēt komandu… jauna konteinera logā nolasa docker run, docker create, podman run un container run un aizpilda veidlapu.

Kas notiek ar karodziņiem, ko Gantry neatbalsta?

Tie ir uzskaitīti priekšskatījumā ar iemeslu un paliek veidlapā sadaļā „No ielīmētās komandas”, lai tos varētu pārbaudīt vēlāk.

Vai darbojošos konteineru var pārvērst atpakaļ par docker run komandu?

Jā. Kopēt kā komandu konteinera izvēlnē uzraksta šim konteineram docker run vai container run rindu.
