Gantry/Skenování imagů

Skenování imagů kontejnerů na zranitelnosti na Macu

Trivy a Grype jsou bezplatné open-source skenery, které porovnávají balíčky v image s databázemi známých zranitelností. Image Dockeru čtou přímo. Nástroj container od Applu nemá příkaz pro skenování ani socket Dockeru, takže image nejprve uložíte. Tento průvodce ukazuje oba postupy, jak číst nálezy, jak zapsat SBOM a jak skenovat z Gantry.

Ve zkratce. Spusťte brew install trivy grype. Na Dockeru spusťte trivy image app:dev. Na Apple container uložte image příkazem container image save --platform linux/arm64 -o app.tar app:dev, rozbalte ho příkazem tar -xf app.tar -C app-img a naskenujte složku: trivy image --input app-img nebo grype oci-dir:app-img. Samotný soubor tar oba nástroje odmítají.

Instalace skeneru

Nainstalujte jeden skener nebo oba přes Homebrew. Každý si při prvním skenu stáhne databázi zranitelností, což trvá asi minutu.

Terminál
brew install trivy grype

Příkazy v tomto průvodci jsme ověřili s Trivy 0.76.2, Grype 0.121.3 a container 1.7.1. Gantry vyžaduje Trivy 0.50.0 nebo Grype 0.74.0 či novější.

Sken image Dockeru

S Docker enginem (Docker Desktop, OrbStack nebo Colima) oba nástroje čtou lokální image podle názvu přes socket Dockeru:

Terminál
trivy image app:dev
grype app:dev

Sken image Apple container

Uložte image do archivu OCI a rozbalte ho do složky. Zadejte --platform: když úložiště imagů obsahuje jen některé platformy image, container image save bez něj selže.

Terminál
container image pull python:3.11-slim
container image save --platform linux/arm64 -o python.tar python:3.11-slim
mkdir python-img && tar -xf python.tar -C python-img

Potom naskenujte složku. Trivy ji čte s --input, Grype s předponou oci-dir::

Terminál
trivy image --input python-img --severity HIGH,CRITICAL
grype oci-dir:python-img
Pozor
Nepředávejte soubor .tar. Archiv z container image save začíná položkou ./: Trivy hlásí „file manifest.json not found in tar“ a Grype ho odmítne jako „potential path traversal attack“. Rozbalená složka funguje s oběma.

Čtení výsledků

  • Závažnost: Critical, High, Medium, Low nebo Unknown. Začněte s Critical a High. --severity HIGH,CRITICAL omezí výstup Trivy.
  • Nainstalovaná a opravená verze: pokud opravená verze existuje, aktualizujte základní image nebo balíček a sestavte znovu. trivy --ignore-unfixed a grype --only-fixed skryjí nálezy bez opravy.
  • „won't fix“: distribuce se rozhodla balíček v tomto vydání neopravit. Použijte novější základní image, nebo riziko přijměte.
  • Dva nástroje, dvě databáze: Trivy a Grype často hlásí různé počty. Ani jeden se nemýlí; používají různé zdroje.

Export SBOM

Soupis softwarových komponent (SBOM) uvádí každý balíček v image. Trivy zapisuje CycloneDX i SPDX; doprovodný nástroj Grype, Syft, zapisuje také oba formáty.

Terminál
trivy image --input python-img --format cyclonedx -o sbom.cdx.json
trivy image --input python-img --format spdx-json -o sbom.spdx.json

Selhání sestavení při vážných nálezech

Ve skriptu nechte návratový kód nastavit skener. Grype skončí s nenulovým kódem, když existuje nález zadané nebo vyšší závažnosti; s Trivy použijte --exit-code 1 --severity HIGH,CRITICAL.

Terminál
grype oci-dir:python-img --fail-on high
echo $?

Skenování z Gantry

Gantry 0.29.0 tyto kroky provede za vás. Zvolte Zkontrolovat zranitelnosti… v nabídce image nebo na panelu nástrojů detailu image.

  • Gantry najde Trivy nebo Grype v GANTRY_TRIVY nebo GANTRY_GRYPE, v PATH nebo v /opt/homebrew/bin a /usr/local/bin. Když jsou nainstalované oba, výchozí je Trivy. Bez skeneru list zobrazí příkazy Homebrew.
  • Na apple/container Gantry uloží image s --platform, rozbalí ho a naskenuje složku. Na lokálním Dockeru skenuje uložený archiv. U Dockeru přes SSH skenuje kopii tagu v registru.
  • Nálezy jsou seskupené podle závažnosti, se symbolem a slovem, nejen barvou. Každý řádek obsahuje ID s odkazem, balíček, nainstalovanou verzi a opravenou verzi. Filtr najde balíček nebo ID.
  • Exportovat SBOM zapíše CycloneDX (oba nástroje) nebo SPDX (Trivy).
  • Zastavit nebo zavření listu zastaví skener a odstraní dočasné soubory.

Otázky a odpovědi

Jak naskenovat image Apple container na zranitelnosti?

Uložte ho příkazem container image save --platform linux/arm64 -o app.tar app:dev, rozbalte příkazem tar -xf app.tar -C app-img a pak spusťte trivy image --input app-img nebo grype oci-dir:app-img. Gantry tyto kroky provede přes Zkontrolovat zranitelnosti….

Proč Trivy nebo Grype selhává na archivu z container image save?

Archiv začíná položkou ./. Trivy v něm nenajde manifest.json ani index.json a Grype tuto položku považuje za path traversal. Archiv rozbalte a naskenujte složku.

Trivy, nebo Grype: který použít?

Oba jsou bezplatné a open source. Trivy navíc najde tajné údaje a chybné konfigurace a zapisuje SPDX; Grype je malý a zaměřený na balíčky. Používají různé databáze, takže spuštění obou najde víc. Gantry použije Trivy, když jsou nainstalované oba.

Instaluje Gantry skenery?

Ne. Nainstalujte je příkazem brew install trivy grype. Gantry je hledá v PATH, /opt/homebrew/bin a /usr/local/bin, nebo v GANTRY_TRIVY a GANTRY_GRYPE.

Potřebuji ke skenování imagů Docker Scout nebo účet Docker?

Ne. Trivy a Grype fungují bez účtu, na imagích Dockeru i na imagích Apple container.
