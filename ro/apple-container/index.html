Gantry/Ghid apple/container

Apple container pe Mac: ghidul complet și GUI-ul

apple/container rulează containere Linux pe Mac, fiecare în propria mașină virtuală ușoară. Vine ca instrument de linie de comandă. Gantry este un GUI nativ macOS pentru el. Acest ghid explică instrumentul, cum îl configurați și ce funcție Gantry acoperă fiecare comandă container.

Pe scurt. Gantry este o aplicație macOS gratuită și open source (MIT) care gestionează instrumentul container de la Apple și Docker dintr-o singură fereastră. Acceptă CLI-ul container 1.0–1.7.1 (recomandat) și afișează doar funcțiile acceptate de versiunea CLI-ului dvs. Instalați-o cu brew install --cask getgantry/tap/gantry.

Ce este apple/container?

apple/container este un instrument open source de la Apple, scris în Swift, care creează și rulează containere Linux pe Mac. Docker Desktop rulează toate containerele într-o singură VM Linux partajată; apple/container rulează fiecare container în propria mașină virtuală ușoară, construită pe framework-ul Virtualization de la Apple. Folosește imagini OCI standard, așa că descarcă din aceleași registre ca Docker și trimite în ele.

  • Hardware: un Mac cu Apple silicon.
  • macOS: Apple îl acceptă pe macOS 26.
  • Interfață: doar CLI-ul container. Nu există aplicație desktop și nici comanda compose.
  • Rețea: fiecare container primește propria adresă IP pe Mac, iar domeniile DNS locale le dau containerelor nume precum web.test.

De ce un GUI pentru apple/container?

CLI-ul este complet, dar munca de zi cu zi înseamnă multe comenzi: container list, logs, stats, exec, apoi system, builder, registry, machine și cluster pentru rest. Gantry le adună într-o singură fereastră cu actualizări în timp real, așa că vedeți starea în loc să o tot interogați. Adaugă și ce nu are CLI-ul: fișiere Compose, notificări de eroare, o vizualizare de flotă cu gazdele Docker și un server MCP pentru agenți AI.

Configurarea apple/container cu Gantry

  1. Instalați Gantry: brew install --cask getgantry/tap/gantry, apoi eliminați atributul de carantină (vedeți Instalare).
  2. Instalați CLI-ul container din pachetul .pkg semnat de pe pagina de versiuni apple/container. Dacă lipsește sau este mai vechi de 1.0, Gantry afișează o foaie de configurare cu pașii.
  3. În Gantry, alegeți Adaugă gazdă… și adăugați o gazdă Apple Container. La conectare, serviciile container pornesc dacă sunt oprite.
  4. Dacă nu este instalat niciun kernel implicit, prezentarea generală a gazdei afișează un banner. Faceți clic pe el pentru a instala kernelul recomandat.
Atenție
Folosiți pachetul de instalare semnat, nu versiunea Homebrew. Versiunea Homebrew nu include backendul pentru mașini și, în 1.7.1, nici serviciile clusterului, așa că container machine și container cluster nu pot rula.

Ce adaugă Gantry pe apple/container

Clustere Kubernetes

Creați clustere Kubernetes cu container cluster, dimensionați workerii, permiteți pod-urilor să folosească imaginile dvs. locale, alegeți CNI-ul și vedeți fiecare nod. Apoi răsfoiți clusterul în browserul Kubernetes din Gantry. Vedeți Kubernetes pe apple/container și ghidul pas cu pas Rulați Kubernetes pe Mac.

Mașini container și VS Code

Mașinile sunt medii Linux de lungă durată create cu container machine. Gantry le creează, le pornește, le oprește și le șterge, setează mașina implicită, editează CPU-urile și memoria și deschide un shell. Pe CLI 1.1 sau mai nou, o mașină poate porni cu virtualizare imbricată (Apple silicon M3 sau mai nou) și cu un kernel personalizat. Deschide în VS Code se conectează la o mașină care rulează prin Remote-SSH; imaginea mașinii trebuie să ruleze sshd.

Docker Compose pe apple/container

Deschideți un docker-compose.yml din Finder (Deschide cu ▸ Gantry sau Acțiuni rapide ▸ Compose Up în apple/container), din Fișier ▸ Deschide un fișier Compose… sau trăgându-l în fereastră. Gantry construiește serviciile cu build:, creează rețeaua proiectului și volumele cu nume și pornește fiecare serviciu în ordinea din depends_on, cu etichetele standard com.docker.compose.*. Cu un domeniu DNS implicit setat, serviciile se găsesc unele pe altele după numele serviciului, prin aliasuri de rețea.

Aliasuri DNS de rețea și domenii locale

Gantry transmite aliasurile de rețea către container ca --network <name>,alias=…. Fără un domeniu DNS implicit, trec doar numele complet calificate, iar un alias de subarbore (cu punct la început, precum .gateway) trece doar ca alias exact. Cu un domeniu implicit, funcționează și numele scurte. Gantry creează și șterge domenii DNS locale, setează domeniul implicit și le dă containerelor noi un hostname name.domain. Vedeți Nume DNS locale.

Sistem: servicii, builder, registre, kernel, jurnale, proprietăți

Fiecare gazdă apple/container are o secțiune Sistem. Aceasta funcționează și când gazda este deconectată, așa că de acolo puteți porni serviciile oprite.

  • Stare și versiune: versiunile clientului și serverului, cu un avertisment când diferă; pornirea, oprirea și repornirea serviciilor; date și căi ale gazdei.
  • Builder de imagini: stare, imagine, CPU-uri, memorie și IP; pornire cu opțiuni de CPU, memorie și DNS; oprire; ștergere. Un card vă anunță când imaginea builderului este învechită și o recreează.
  • Autentificări la registre: listare, autentificare și deconectare. Parola ajunge la CLI doar prin stdin (--password-stdin), iar Gantry nu păstrează nicio copie.
  • Kernel: instalarea kernelului recomandat, a unui fișier kernel sau a unei arhive tar, cu progres în timp real.
  • Jurnalele serviciilor: în timp real sau o singură dată, pe un interval de la 5 minute la 1 zi, filtrate după nivel, serviciu și text.
  • Proprietăți de sistem: modificările ajung în ~/.config/container/config.toml, cu un indicator de repornire în așteptare și un buton Repornește serviciile. Pe CLI 1.7, serverele de nume, domeniile de căutare și opțiunile [container.dns] au un editor de liste.

Salvare ca imagine, Compactează discul și fișiere

Salvează ca imagine folosește container commit (CLI 1.6). Compactează discul folosește container clean (CLI 1.4) și apare și ca rând în Recuperează spațiu. Fila Fișiere descarcă fișiere și vă permite să le trageți în Finder cu container copy (containerul trebuie să fie pornit) și încarcă fișiere și dosare.

Etichete care conțin =

container create respinge o valoare de etichetă care conține =, inclusiv pe CLI 1.6.1. Gantry codifică astfel de valori când creează containerul și le decodifică atunci când îl citește, așa că etichetele pe care le setați sunt etichetele pe care le vedeți.

Server MCP și Scurtături

Serverul gantry-mcp inclus le oferă agenților AI aceeași acoperire pe gazdele apple/container: containere, imagini, volume, rețele, Compose, mașini (list_machines, create_machine și altele), clustere (list_clusters, create_cluster, delete_cluster) și instrumentele de sistem apple_* pentru servicii, builder, registre (fără instrument de autentificare), proprietăți, jurnale și instalarea kernelului. App Intents adaugă acțiuni pentru Scurtături și Siri. Vedeți Agenți AI și MCP.

Adăugați serverul MCP Gantry
claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp

apple/container lângă Docker

Gantry gestionează gazde apple/container, daemonul Docker local (Docker Desktop, OrbStack, Colima) și gazde Docker la distanță prin SSH într-o singură bară laterală și un singur panou de flotă. Nu trebuie să alegeți un singur runtime. Pentru o comparație funcție cu funcție a instrumentelor, vedeți Gantry vs Docker Desktop, OrbStack și Podman Desktop. Pentru a vă muta munca, citiți Treceți de la Docker Desktop la Apple container.

Întrebări și răspunsuri

Care este cel mai bun GUI pentru Apple container?

Gantry este un GUI nativ macOS, gratuit și open source, creat pentru apple/container. Transpune CLI-ul container într-o aplicație desktop: containere, jurnale, statistici și exec, plus clustere Kubernetes, mașini, builderul de imagini, autentificări la registre, kerneluri, jurnalele serviciilor și proprietăți de sistem. Tabelul de pe această pagină listează fiecare comandă și funcția Gantry care o folosește.

Are Apple container o interfață grafică?

Apple livrează container doar ca instrument de linie de comandă. Gantry este o aplicație open source separată care îi oferă un GUI, lângă gazdele Docker.

Pot folosi docker compose cu Apple container?

apple/container nu are comanda compose. Gantry citește un docker-compose.yml, construiește serviciile cu build:, creează rețeaua și volumele cu nume și pornește serviciile în ordinea din depends_on. Numele serviciilor se rezolvă prin aliasuri DNS de rețea.

Cum deschid o mașină container în VS Code?

Porniți mașina în Gantry și faceți clic pe Deschide în VS Code. Gantry o deschide prin Remote-SSH, ca în exemplul container-machine-vscode de la Apple. Imaginea mașinii trebuie să ruleze sshd.

Funcționează Apple container pe Mac cu Intel?

Nu. apple/container necesită un Mac cu Apple silicon. Gantry rulează și pe Mac-uri cu Intel, dar acolo gestionează doar gazde Docker.

Ce versiune a CLI-ului container să instalez?

Gantry necesită 1.0 sau o versiune ulterioară și recomandă 1.7.1. Instalați-l cu pachetul de instalare semnat de pe pagina de versiuni apple/container. Versiunea Homebrew nu include backendul pentru mașini și, în 1.7.1, nici serviciile clusterului, așa că container machine și container cluster nu funcționează cu ea.
