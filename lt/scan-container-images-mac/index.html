Gantry/Atvaizdų tikrinimas

Konteinerių atvaizdų pažeidžiamumų paieška Mac kompiuteryje

Trivy ir Grype – nemokami atvirojo kodo skeneriai, kurie palygina atvaizdo paketus su žinomų pažeidžiamumų duomenų bazėmis. Docker atvaizdus jie skaito tiesiogiai. Apple container įrankis neturi tikrinimo komandos ir Docker lizdo, todėl atvaizdą pirmiausia reikia įrašyti. Šiame vadove parodyti abu būdai, kaip skaityti radinius, kaip įrašyti SBOM ir kaip tikrinti iš Gantry.

Trumpai. Paleiskite brew install trivy grype. Su Docker paleiskite trivy image app:dev. Su Apple container įrašykite atvaizdą komanda container image save --platform linux/arm64 -o app.tar app:dev, išpakuokite jį komanda tar -xf app.tar -C app-img ir patikrinkite aplanką: trivy image --input app-img arba grype oci-dir:app-img. Paties tar failo abu įrankiai nepriima.

Skenerio įdiegimas

Įdiekite vieną skenerį arba abu per Homebrew. Per pirmą tikrinimą kiekvienas atsisiunčia savo pažeidžiamumų duomenų bazę, tai užtrunka apie minutę.

Terminalas
brew install trivy grype

Šio vadovo komandas patikrinome su Trivy 0.76.2, Grype 0.121.3 ir container 1.7.1. Gantry reikia Trivy 0.50.0 arba Grype 0.74.0 ar naujesnės versijos.

Docker atvaizdo tikrinimas

Su Docker varikliu (Docker Desktop, OrbStack ar Colima) abu įrankiai skaito vietinį atvaizdą pagal pavadinimą per Docker lizdą:

Terminalas
trivy image app:dev
grype app:dev

Apple container atvaizdo tikrinimas

Įrašykite atvaizdą į OCI archyvą ir išpakuokite jį į aplanką. Nurodykite --platform: kai atvaizdų saugykloje yra tik dalis atvaizdo platformų, container image save be šios vėliavėlės nepavyksta.

Terminalas
container image pull python:3.11-slim
container image save --platform linux/arm64 -o python.tar python:3.11-slim
mkdir python-img && tar -xf python.tar -C python-img

Tada patikrinkite aplanką. Trivy jį skaito su --input, Grype – su priešdėliu oci-dir::

Terminalas
trivy image --input python-img --severity HIGH,CRITICAL
grype oci-dir:python-img
Dėmesio
Neperduokite .tar failo. container image save archyvas prasideda įrašu ./: Trivy praneša „file manifest.json not found in tar“, o Grype jį atmeta kaip „potential path traversal attack“. Išpakuotas aplankas veikia su abiem.

Rezultatų skaitymas

  • Pavojingumo lygis: Critical, High, Medium, Low arba Unknown. Pradėkite nuo Critical ir High. --severity HIGH,CRITICAL apriboja Trivy išvestį.
  • Įdiegta ir pataisyta versija: jei pataisyta versija yra, atnaujinkite bazinį atvaizdą arba paketą ir sukurkite iš naujo. trivy --ignore-unfixed ir grype --only-fixed paslepia radinius be pataisos.
  • „won't fix“: distribucija nusprendė šiame leidime paketo netaisyti. Naudokite naujesnį bazinį atvaizdą arba prisiimkite riziką.
  • Du įrankiai, dvi duomenų bazės: Trivy ir Grype dažnai praneša skirtingą radinių skaičių. Nė vienas neklysta – jie naudoja skirtingus šaltinius.

SBOM eksportas

Programinės įrangos komponentų sąrašas (SBOM) išvardija visus atvaizdo paketus. Trivy rašo CycloneDX ir SPDX; Grype palydovas Syft taip pat rašo abu formatus.

Terminalas
trivy image --input python-img --format cyclonedx -o sbom.cdx.json
trivy image --input python-img --format spdx-json -o sbom.spdx.json

Kūrimo sustabdymas dėl rimtų radinių

Scenarijuje leiskite išėjimo kodą nustatyti skeneriui. Grype baigia darbą su nenuliniu kodu, kai yra nurodyto ar aukštesnio pavojingumo lygio radinys; su Trivy naudokite --exit-code 1 --severity HIGH,CRITICAL.

Terminalas
grype oci-dir:python-img --fail-on high
echo $?

Tikrinimas iš Gantry

Gantry 0.29.0 atlieka šiuos veiksmus už jus. Atvaizdo meniu arba atvaizdo informacijos įrankių juostoje pasirinkite Ieškoti pažeidžiamumų….

  • Gantry randa Trivy arba Grype pagal GANTRY_TRIVY ar GANTRY_GRYPE, PATH arba aplankuose /opt/homebrew/bin ir /usr/local/bin. Kai įdiegti abu, numatytasis yra Trivy. Jei skenerio nėra, lange rodomos Homebrew komandos.
  • apple/container serveryje Gantry įrašo atvaizdą su --platform, išpakuoja jį ir tikrina aplanką. Vietiniame Docker ji tikrina įrašytą archyvą. Docker per SSH atveju ji tikrina žymės kopiją registre.
  • Radiniai sugrupuoti pagal pavojingumo lygį, su simboliu ir žodžiu, ne tik spalva. Kiekvienoje eilutėje yra ID su nuoroda, paketas, įdiegta versija ir pataisyta versija. Filtras randa paketą arba ID.
  • Eksportuoti SBOM įrašo CycloneDX (abu įrankiai) arba SPDX (Trivy).
  • Mygtukas Sustabdyti arba lango uždarymas sustabdo skenerį ir pašalina laikinuosius failus.

Susiję vadovai

  • Perėjimas nuo Docker Desktop prie Apple container: komandos, Compose, tomai ir trūkumai
  • Konteinerių ir tomų laikymas išoriniame diske Mac kompiuteryje
  • Konteinerio kūrimas iš docker run komandos Mac kompiuteryje (docker run į container run)
  • Apple container GUI, skirta Mac: išsamus apple/container vadovas
  • Kubernetes su Apple container: container cluster GUI ir Kubernetes naršyklė
  • Gantry, Docker Desktop, OrbStack ir Podman Desktop palyginimas Mac kompiuteryje (2026)

Klausimai ir atsakymai

Kaip ieškoti pažeidžiamumų Apple container atvaizde?

Įrašykite jį komanda container image save --platform linux/arm64 -o app.tar app:dev, išpakuokite komanda tar -xf app.tar -C app-img, tada paleiskite trivy image --input app-img arba grype oci-dir:app-img. Gantry šiuos veiksmus atlieka per Ieškoti pažeidžiamumų….

Kodėl Trivy ar Grype nepavyksta su container image save archyvu?

Archyvas prasideda įrašu ./. Trivy neranda jame manifest.json ar index.json, o Grype laiko šį įrašą kelio apėjimu (path traversal). Išpakuokite archyvą ir tikrinkite aplanką.

Trivy ar Grype: kurį naudoti?

Abu nemokami ir atvirojo kodo. Trivy dar randa slaptuosius duomenis ir konfigūracijos klaidas bei rašo SPDX; Grype mažas ir sutelktas į paketus. Jie naudoja skirtingas duomenų bazes, todėl abu kartu randa daugiau. Kai įdiegti abu, Gantry naudoja Trivy.

Ar Gantry įdiegia skenerius?

Ne. Įdiekite juos komanda brew install trivy grype. Gantry ieško PATH, /opt/homebrew/bin ir /usr/local/bin arba GANTRY_TRIVY ir GANTRY_GRYPE.

Ar atvaizdams tikrinti reikia Docker Scout arba Docker paskyros?

Ne. Trivy ir Grype veikia be paskyros – su Docker atvaizdais ir su Apple container atvaizdais.
