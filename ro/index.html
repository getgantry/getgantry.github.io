Aplicația Mac pentru Apple container și Docker

Gantry este o aplicație Mac gratuită și open source pentru instrumentul container de la Apple și pentru Docker, local și prin SSH. Rulați containere, clustere Kubernetes, mașini și proiecte Compose pe apple/container dintr-o singură fereastră, alături de gazdele Docker. O alternativă gratuită la Docker Desktop și OrbStack pentru Mac.

Descarcă pentru macOS
$ brew install --cask getgantry/tap/gantry

Gantry 0.29.0 · macOS 26+ · Apple silicon și Intel · Licență MIT · 28 de limbi · Server MCP inclus

Instrumentul container de la Apple și Docker sunt instrumente în linia de comandă. Fiecare comandă din acest tabel are un control în Gantry.

GUI-ul nativ macOS pentru Apple container

Instrumentul container de la Apple rulează containere Linux ca mașini virtuale ușoare pe Apple silicon, dar vine doar ca instrument de linie de comandă. Gantry este aplicația desktop pentru el: ce este Docker Desktop pentru Docker este Gantry pentru container. Acceptă fiecare CLI container de la 1.0 până la versiunea recomandată 1.7.1 și activează fiecare funcție doar când CLI-ul instalat o acceptă.

Instalare

Descărcați aplicația sau instalați-o cu Homebrew. Nu aveți nevoie de cont.

  • brew install --cask getgantry/tap/gantry
Descarcă pentru macOS
  1. InstalațiRulați cask-ul Homebrew sau luați fișierul .zip din Versiuni și trageți Gantry.app în Aplicații.
  2. Prima lansareÎncă nu este notarizată — faceți clic dreapta și alegeți Deschide sau eliminați carantina cu xattr -dr com.apple.quarantine /Applications/Gantry.app
  3. Adăugați o gazdăDocker local apare singur. Pentru Apple container, adăugați o gazdă Apple Container; Gantry se oferă să configureze CLI-ul container. Agenți: claude mcp add gantry.

Întrebări

Gantry este gratuit?

Da. Gantry este gratuit și open source, sub licența MIT. Fără abonament, fără cont și fără limită de gazde sau de containere.

De ce am nevoie ca să rulez Gantry?

macOS 26 sau o versiune ulterioară pe Apple silicon sau Intel, plus un daemon Docker (Docker Desktop, OrbStack, Colima sau similar) ori instrumentul container de la Apple. apple/container în sine necesită Apple silicon, așa că pe un Mac cu Intel Gantry gestionează doar gazde Docker.

Care este cel mai bun GUI pentru Apple container?

Gantry este un GUI nativ macOS, gratuit și open source, creat pentru instrumentul container de la Apple (apple/container). Acoperă ciclul de viață al containerelor, jurnalele, statisticile și un terminal exec, plus părțile CLI-ului la care alte GUI-uri nu ajung: clustere Kubernetes (container cluster), mașini container, builderul de imagini, autentificările la registre, kerneluri, jurnalele serviciilor și proprietățile de sistem. Acceptă CLI 1.0–1.7.1 și activează fiecare funcție doar când CLI-ul dvs. o acceptă. Vedeți ghidul apple/container.

Ce este Apple container (apple/container)?

apple/container este instrumentul open source de la Apple pentru rularea containerelor Linux pe Mac. Fiecare container rulează în propria mașină virtuală ușoară, construită pe framework-ul Virtualization de la Apple. Necesită un Mac cu Apple silicon și vine ca instrument de linie de comandă numit container, fără aplicație desktop. Gantry adaugă această aplicație desktop.

Pot folosi docker compose cu Apple container?

Da. apple/container nu are comanda compose, așa că Gantry face orchestrarea prin CLI-ul container: construiește serviciile cu build:, creează rețeaua proiectului și volumele cu nume și pornește fiecare serviciu în ordinea din depends_on, cu etichetele Compose standard. Numele serviciilor se rezolvă prin aliasuri DNS de rețea. Deschideți un docker-compose.yml din Finder, din meniul Fișier sau trăgându-l în fereastră.

Este Gantry o alternativă la Docker Desktop, OrbStack sau Podman Desktop?

Ca GUI, da. Gantry este o aplicație nativă macOS gratuită pentru gestionarea containerelor, imaginilor, volumelor, rețelelor, jurnalelor și statisticilor. Este un client, nu un motor: folosește daemonul Docker pe care îl rulați deja (Docker Desktop, OrbStack, Colima) sau instrumentul container de la Apple și adaugă o vizualizare pentru mai multe gazde, gazde SSH și un server MCP. Consultați comparația.

Cum instalez Gantry?

Rulați brew install --cask getgantry/tap/gantry sau descărcați cea mai recentă versiune de pe GitHub și trageți Gantry.app în Aplicații.

Pot agenții AI să controleze Gantry?

Da. Gantry include un server MCP și App Intents macOS, astfel încât Claude, Scurtături, Siri și scripturile au aceleași posibilități ca GUI-ul pe fiecare gazdă, inclusiv pe gazdele SSH: containere, imagini, volume, rețele, Compose, mașini apple/container, clustere Kubernetes, instrumentele de sistem apple_* (servicii, builder, registre, proprietăți, jurnale, kernel) și partajarea porturilor. Pe macOS 26 și versiunile ulterioare, Explică eșecul… întreabă și Apple Intelligence de ce a eșuat un container. Adăugați serverul MCP cu claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp.
