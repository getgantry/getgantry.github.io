Gantry — безплатна програма для Mac з відкритим кодом для інструмента container від Apple і для Docker, локально й через SSH. Контейнери, кластери Kubernetes, машини й проєкти Compose на apple/container — в одному вікні, поруч із вашими хостами Docker. Нативна альтернатива Docker Desktop для Mac. Без Electron. Без підписки. Без обмежень.

Вбудований термінал exec

Повноцінна емуляція термінала в будь-якому запущеному контейнері, локальному чи віддаленому, — з колірними темами (System, Solarized, Dracula, Nord).

Віддалені хости через SSH

Тунель точно як у docker -H ssh:// через dial-stdio: бастіони ProxyJump, автентифікація кількома ключами, автоматичне перепід’єднання. На сервер нічого не треба інсталювати, секрети — у В’язці ключів. Імпорт одним клацанням із ~/.ssh/config і docker context ls.

Файловий браузер із перетягуванням

Переглядайте файлову систему контейнера, переносьте файли туди й назад і перетягуйте цілі папки просто з Finder — на хостах Docker і apple/container.

Відкрити в браузері й переадресувати

Одне клацання відкриває опублікований порт. Порти SSH-хостів автоматично переадресовуються на localhost, а якщо порт зайнятий, Gantry вибере вільний, який можна змінити.

Опублікувати в інтернеті

Одне клацання — і опублікований порт доступний через Cloudflare Tunnel. Gantry сам інсталює cloudflared, а потім дасть швидкий тунель (без облікового запису, URL-адреса *.trycloudflare.com) або іменований тунель на вашому домені. Зручно для попереднього перегляду під час розробки, вебхука або щоб ШІ-агент дістався до контейнера на вашому Mac.

Compose будь-де

Контейнери групуються за проєктами Compose. Запускайте файл compose на будь-якому хості — у локальному Docker, через SSH чи в apple/container — із вбудованим редактором YAML; запуск підлаштовується під рушій.

Приватні реєстри — автоматично

Під час отримання образів використовується docker login, який ви вже виконали: Gantry бере облікові дані з ~/.docker/config.json, помічників облікових даних і В’язки ключів — під час створення контейнера, у «Швидкому запуску» та в Compose.

Збірка й отримання образів

Перетягніть Dockerfile у вікно, щоб зібрати образ із живим журналом, або отримайте образ за назвою з відображенням перебігу для кожного шару. Додавайте теги, вилучайте невикористані образи, переглядайте історію шарів. Позначка вказує на образи, зібрані для іншої архітектури CPU, ніж у хоста.

Звільнити місце

Одна панель показує, що займає місце, — образи без тегів, зупинені контейнери, невикористані томи, кеш збірки — із розмірами, і вилучає кожну категорію або все одразу. На apple/container вона також виконує «Стиснути диск».

Touch ID для небезпечних дій

Увімкніть цю функцію, і Gantry запитуватиме Touch ID або пароль входу перед вилученням контейнера чи видаленням хоста. Секрети й так зберігаються у В’язці ключів.

Теми термінала

Оформіть вбудовану оболонку в стилі System, Solarized Dark, Dracula або Nord: повна палітра переднього плану, тла й 16 кольорів ANSI застосовується одразу.

GUI для apple/container

Нативний GUI для Apple container на macOS

Інструмент container від Apple запускає Linux-контейнери як легкі віртуальні машини на Apple silicon, але постачається лише як утиліта командного рядка. Gantry — графічна програма для нього: для container це те саме, що Docker Desktop для Docker. Gantry підтримує будь-який CLI container від 1.0 до рекомендованої версії 1.6.1 і вмикає кожну можливість, лише якщо її підтримує інстальований CLI.

Контейнери, журнали, статистика й exec

Створення, запуск, зупинка, примусове завершення й очищення; журнали та статистика в реальному часі, термінал exec, top і експорт у tar — у тому самому інтерфейсі, що й для хостів Docker.

Кластери Kubernetes

Імпорт локальних образів у кластер

Клацніть образ правою кнопкою й виберіть Імпортувати в кластер — образ потрапить на кожен вузол без надсилання в реєстр.

Машини container у VS Code

Створюйте, запускайте й зупиняйте Linux-середовища container machine, задавайте CPU і пам’ять, відкривайте оболонку або саму машину у VS Code через Remote-SSH.

Вкладена віртуалізація та власні ядра

Завантажуйте машину з вкладеною віртуалізацією (M3 або новіший) чи з власним ядром. Запускайте контейнери з власним ядром і додатковими параметрами завантаження.

Compose для Apple container

В apple/container немає compose. Gantry запускає ваш docker-compose.yml: збирає образи, створює мережу й томи та запускає служби в порядку depends_on. Імена служб розв’язуються через мережеві DNS-псевдоніми.

Мережеві DNS-псевдоніми

Псевдоніми контейнерів, псевдоніми піддерев на кшталт .gateway і короткі імена, якщо задано типовий DNS-домен. Кожен контейнер отримує маршрутизовану IP-адресу та ім’я хоста name.domain.

Керування збирачем образів

Стан збирача, образ, CPU, пам’ять і IP. Запуск із параметрами CPU, пам’яті та DNS, зупинка й видалення.

Входи в реєстри

Перегляд, додавання й вилучення входів container registry. Пароль передається в CLI лише через stdin, і Gantry не зберігає його копії.

Інсталяція ядра

Інсталяція рекомендованого ядра, файлу ядра або tar-архіву з відображенням перебігу в реальному часі. Gantry попередить, якщо типове ядро не інстальовано.

Служби та журнали служб

Запускайте, зупиняйте й перезапускайте служби container, порівнюйте версії клієнта й сервера та переглядайте журнали служб у реальному часі з фільтром за рівнем, службою й текстом.

Редактор системних властивостей

Редагуйте системні властивості container у config.toml. Gantry позначає зміни, яким потрібен перезапуск, і сам перезапускає служби.

Зберегти як образ і стиснути диск

Збережіть контейнер як образ (container commit) і звільніть місце на диску командою Стиснути диск (container clean) — вона є й на панелі «Звільнити місце».

Файловий браузер: вивантаження й завантаження

Переглядайте файли контейнера, завантажуйте їх або перетягуйте у Finder (container copy), а файли й цілі папки перетягуйте всередину.

Швидкий запуск і Finder

Виберіть образ, надайте доступ до папки, переадресуйте порти, виберіть домен — і запускайте. У Finder клацніть файл compose правою кнопкою й відкрийте його в Gantry.

Мітки, що містять =

CLI container відхиляє значення міток із =. Gantry кодує їх під час створення й декодує під час читання, тож значення на кшталт a=b лишається цілим.

Один парк, два середовища виконання

Хости apple/container стоять поруч із локальним Docker і SSH-хостами на одній панелі — з тими самими спарклайнами, станом і сповіщеннями про збої.

Інструменти MCP для агентів

Вбудований сервер MCP дає агентам ті самі можливості: контейнери, машини, кластери та системні інструменти apple_* для служб, збирача, реєстрів, властивостей, журналів і ядер.

FAQ

Відповіді на запитання

Усе, що варто знати перед інсталяцією Gantry.

Який GUI для Apple container найкращий?

Gantry — безплатний нативний GUI для macOS з відкритим кодом, створений для інструмента container від Apple (apple/container). Він охоплює життєвий цикл контейнерів, журнали, статистику й термінал exec, а також ті частини CLI, до яких не дістаються інші GUI: кластери Kubernetes (container cluster), машини container, збирач образів, входи в реєстри, ядра, журнали служб і системні властивості. Gantry підтримує CLI від 1.0 до 1.6.1 і вмикає кожну можливість, лише якщо її підтримує ваш CLI. Див. посібник з apple/container.

Що таке Apple container (apple/container)?

apple/container — інструмент Apple з відкритим кодом для запуску Linux-контейнерів на Mac. Кожен контейнер працює у власній легкій віртуальній машині на основі фреймворку Virtualization від Apple. Йому потрібен Mac з Apple silicon, а постачається він як утиліта командного рядка container, без програми з графічним інтерфейсом. Таку програму додає Gantry.

Чи підтримує Gantry container cluster і Kubernetes?

Так. На хості apple/container Gantry створює й видаляє кластери Kubernetes командою container cluster (CLI 1.6.1; у CLI від 1.5.0 до 1.6.0 — container k8s). Ви вибираєте назву, кількість робочих вузлів, CPU, пам’ять, образ вузла та CNI (типовий, немає або власний маніфест). Gantry показує вузли, записує kubeconfig, копіює команду контексту kubectl та імпортує локальні образи в кластер. Див. Kubernetes на apple/container.

Чи можна використовувати docker compose з Apple container?

Так. В apple/container немає команди compose, тож оркестрацію поверх CLI container бере на себе Gantry: збирає служби з build:, створює мережу проєкту та іменовані томи й запускає кожну службу в порядку depends_on зі стандартними мітками Compose. Імена служб розв’язуються через мережеві DNS-псевдоніми. Відкрийте docker-compose.yml із Finder, через меню «Файл» або перетягніть його у вікно.

Як відкрити машину container у VS Code?

Запустіть машину в Gantry і натисніть Відкрити у VS Code. Gantry відкриє машину у VS Code через Remote-SSH, як у прикладі Apple container-machine-vscode. В образі машини має працювати sshd, а VS Code з розширенням Remote-SSH має бути інстальовано.

Які версії apple/container підтримує Gantry?

Gantry потрібен CLI container версії 1.0 або новішої, рекомендовано 1.6.1. Gantry визначає інстальовану версію й показує лише ті можливості, які вона підтримує, наприклад збереження як образ (1.6), «Стиснути диск» (1.4) і робочі вузли кластера (1.6). Якщо CLI немає або він застарів, Gantry запропонує покрокове налаштування.

Чи може Gantry керувати збирачем, реєстрами та ядром apple/container?

Так. Розділ «Система» хоста apple/container запускає, зупиняє й видаляє збирач образів із параметрами CPU, пам’яті та DNS; показує, додає й вилучає входи в реєстри (пароль передається в CLI лише через stdin); інсталює рекомендоване ядро, файл ядра або tar-архів; транслює журнали служб і редагує системні властивості в config.toml.

Чи є Gantry альтернативою Docker Desktop, OrbStack або Podman Desktop?

Як GUI — так. Gantry — безплатна нативна програма для macOS для керування контейнерами, образами, томами, мережами, журналами й статистикою. Це клієнт, а не рушій: він працює з демоном Docker, який у вас уже запущено (Docker Desktop, OrbStack, Colima), або з інструментом container від Apple і додає перегляд кількох хостів в одному вікні, SSH-хости та сервер MCP. Див. порівняння.

Gantry безплатний?

Так. Gantry безплатний, його код відкритий за ліцензією MIT. Немає підписки, облікового запису й обмежень на кількість хостів чи контейнерів.

Що потрібно для роботи Gantry?

macOS 26 або новіша на Apple silicon чи Intel, а також демон Docker (Docker Desktop, OrbStack, Colima або подібний) чи інструмент container від Apple. Самому apple/container потрібен Apple silicon, тож на Mac з Intel Gantry керує лише хостами Docker.

Чи працює Gantry з OrbStack, Colima і Docker Desktop?

Так. Gantry звертається безпосередньо до Docker Engine API через Unix-сокет, тож працює з будь-яким демоном, що його надає, зокрема з OrbStack, Colima і Docker Desktop.

Чи може Gantry керувати віддаленими хостами Docker?

Так. Gantry під’єднується до віддалених демонів через SSH так само, як docker -H ssh://, із бастіонами через ProxyJump, автентифікацією кількома ключами й автоматичним перепід’єднанням. На сервер нічого не треба інсталювати, а секрети зберігаються у В’язці ключів macOS.

Чи повідомить Gantry про збій контейнера?

Так. Gantry надсилає сповіщення macOS, коли контейнер на будь-якому хості — локальному, SSH чи apple/container — аварійно завершує роботу, вичерпує пам’ять або не проходить перевірку стану. Клацніть сповіщення, щоб перейти до контейнера. Про зупинки й перезапуски, які ви виконуєте в Gantry, сповіщень немає, а самі сповіщення можна вимкнути в параметрах.

Чи може Gantry отримувати образи з приватних реєстрів?

Так. На хостах Docker Gantry бере облікові дані з ~/.docker/config.json (той самий docker login, який ви вже виконали), зокрема вбудовані дані auth, помічники облікових даних (credential helpers) і В’язку ключів macOS. На хостах apple/container він керує входами container registry.

Чи може Gantry відкрити доступ до локального контейнера з інтернету?

Так. Клацніть опублікований порт — і він стане доступним через Cloudflare Tunnel. Gantry за потреби інсталює cloudflared, а потім запускає швидкий тунель (без облікового запису Cloudflare, тимчасова URL-адреса на trycloudflare.com) або іменований тунель із вашим власним іменем хоста. Публічна URL-адреса з’являється під портом із кнопками для відкриття, копіювання й зупинки.

Gantry написано на Electron?

Ні. Gantry — нативна програма на SwiftUI та Swift 6. Інтерфейс доступний англійською та спрощеною китайською й відповідає мові системи macOS.

Як інсталювати Gantry?

Виконайте brew install --cask getgantry/tap/gantry або завантажте останній реліз із GitHub і перетягніть Gantry.app у папку «Програми».

Чи можуть ШІ-агенти керувати Gantry?

Так. Gantry має вбудовані сервер MCP та App Intents macOS, тож Claude, «Швидкі команди», Siri і скрипти отримують ті самі можливості, що й GUI, на кожному хості, зокрема на SSH-хостах: контейнери, образи, томи, мережі, Compose, машини apple/container, кластери Kubernetes, системні інструменти apple_* (служби, збирач, реєстри, властивості, журнали, ядро) і публікацію портів. Додайте його командою claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp.

Інсталяція за хвилину

Без App Store і облікового запису. Завантажте й перетягніть — або один рядок у Homebrew.

Завантажити для macOS
$ brew install --cask getgantry/tap/gantry
1
Інсталяція

Інсталюйте cask через Homebrew або завантажте .zip зі сторінки релізів і перетягніть Gantry.app у папку «Програми».

2
Перший запуск

Програма ще не нотаризована: клацніть правою кнопкою й виберіть «Відкрити» або зніміть карантин командою xattr -dr com.apple.quarantine /Applications/Gantry.app

3
Додайте хост

Локальний Docker з’явиться сам. Для Apple container додайте хост Apple Container; Gantry запропонує налаштувати CLI container. Агенти: claude mcp add gantry.
