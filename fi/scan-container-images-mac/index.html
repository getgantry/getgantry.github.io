Gantry/Levykuvien skannaus

Konttien levykuvien haavoittuvuusskannaus Macilla

Trivy ja Grype ovat ilmaisia avoimen lähdekoodin skannereita, jotka vertaavat levykuvan paketteja tunnettujen haavoittuvuuksien tietokantoihin. Ne lukevat Dockerin levykuvat suoraan. Applen container-työkalussa ei ole skannauskomentoa eikä Docker-sokettia, joten levykuva tallennetaan ensin. Tämä opas näyttää molemmat tavat, miten löydökset luetaan, miten SBOM kirjoitetaan ja miten skannataan Gantrysta.

Lyhyesti. Aja brew install trivy grype. Dockerissa aja trivy image app:dev. Apple containerissa tallenna levykuva komennolla container image save --platform linux/arm64 -o app.tar app:dev, pura se komennolla tar -xf app.tar -C app-img ja skannaa kansio: trivy image --input app-img tai grype oci-dir:app-img. Kumpikaan työkalu ei hyväksy itse tar-tiedostoa.

Asenna skanneri

Asenna toinen skanneri tai molemmat Homebrew'lla. Kumpikin lataa haavoittuvuustietokantansa ensimmäisellä skannauskerralla, mikä vie minuutin.

Pääte
brew install trivy grype

Tarkistimme tämän oppaan komennot versioilla Trivy 0.76.2, Grype 0.121.3 ja container 1.7.1. Gantry vaatii Trivyn 0.50.0 tai Grypen 0.74.0 tai uudemman.

Skannaa Dockerin levykuva

Docker-moottorin kanssa (Docker Desktop, OrbStack tai Colima) molemmat työkalut lukevat paikallisen levykuvan nimen perusteella Docker-soketin kautta:

Pääte
trivy image app:dev
grype app:dev

Skannaa Apple container -levykuva

Tallenna levykuva OCI-arkistoon ja pura se kansioon. Anna valinta --platform: kun levykuvavarastossa on vain osa levykuvan alustoista, container image save epäonnistuu ilman sitä.

Pääte
container image pull python:3.11-slim
container image save --platform linux/arm64 -o python.tar python:3.11-slim
mkdir python-img && tar -xf python.tar -C python-img

Skannaa sitten kansio. Trivy lukee sen valinnalla --input, Grype etuliitteellä oci-dir::

Pääte
trivy image --input python-img --severity HIGH,CRITICAL
grype oci-dir:python-img
Huomio
Älä anna .tar-tiedostoa. Komennon container image save arkisto alkaa merkinnällä ./: Trivy ilmoittaa ”file manifest.json not found in tar”, ja Grype hylkää sen ”potential path traversal attack” -virheellä. Purettu kansio toimii molemmilla.

Lue tulokset

  • Vakavuus: Kriittinen, Korkea, Keskitaso, Matala tai Tuntematon. Aloita kriittisistä ja korkeista. --severity HIGH,CRITICAL rajaa Trivyn tulosteen.
  • Asennettu ja korjattu versio: jos korjattu versio on olemassa, päivitä pohjalevykuva tai paketti ja koosta uudelleen. trivy --ignore-unfixed ja grype --only-fixed piilottavat löydökset, joihin ei ole korjausta.
  • ”won't fix”: jakelu on päättänyt olla korjaamatta pakettia tässä julkaisussa. Käytä uudempaa pohjalevykuvaa tai hyväksy riski.
  • Kaksi työkalua, kaksi tietokantaa: Trivy ja Grype ilmoittavat usein eri määriä. Kumpikaan ei ole väärässä; ne käyttävät eri lähteitä.

Vie SBOM

Ohjelmiston osaluettelo (SBOM) luettelee levykuvan jokaisen paketin. Trivy kirjoittaa CycloneDX:n ja SPDX:n; Grypen sisartyökalu Syft kirjoittaa myös molemmat.

Pääte
trivy image --input python-img --format cyclonedx -o sbom.cdx.json
trivy image --input python-img --format spdx-json -o sbom.spdx.json

Hylkää koonti vakavien löydösten vuoksi

Anna skriptissä skannerin asettaa paluuarvo. Grype päättyy nollasta poikkeavaan paluuarvoon, kun löytyy annetun vakavuuden tai sitä vakavampi löydös; Trivyn kanssa käytä valintoja --exit-code 1 --severity HIGH,CRITICAL.

Pääte
grype oci-dir:python-img --fail-on high
echo $?

Skannaa Gantrysta

Gantry 0.29.0 tekee nämä vaiheet puolestasi. Valitse Tarkista haavoittuvuudet… levykuvan valikosta tai levykuvan tietojen työkalupalkista.

  • Gantry löytää Trivyn tai Grypen muuttujista GANTRY_TRIVY tai GANTRY_GRYPE, polusta PATH tai kansioista /opt/homebrew/bin ja /usr/local/bin. Trivy on oletus, kun molemmat on asennettu. Ilman skanneria ikkuna näyttää Homebrew-komennot.
  • apple/containerissa Gantry tallentaa levykuvan valinnalla --platform, purkaa sen ja skannaa kansion. Paikallisessa Dockerissa se skannaa tallennetun arkiston. SSH:n kautta käytetyssä Dockerissa se skannaa tagin rekisterikopion.
  • Löydökset ryhmitellään vakavuuden mukaan symbolin ja sanan avulla, ei pelkällä värillä. Jokaisella rivillä on tunniste linkkeineen, paketti, asennettu versio ja korjattu versio. Suodatin löytää paketin tai tunnisteen.
  • Vie SBOM kirjoittaa CycloneDX:n (molemmat työkalut) tai SPDX:n (Trivy).
  • Pysäytä tai ikkunan sulkeminen pysäyttää skannerin ja poistaa väliaikaiset tiedostot.

Aiheeseen liittyvät oppaat

  • Siirtyminen Docker Desktopista Apple containeriin: komennot, Compose, taltiot ja puutteet
  • Kontit ja taltiot ulkoisella levyllä Macissa
  • Kontin luonti docker run -komennosta Macilla (docker run container runiksi)
  • Apple container -GUI Macille: kattava apple/container-opas
  • Kubernetes Apple containerilla: GUI container clusterille ja Kubernetes-selain
  • Gantry vs. Docker Desktop vs. OrbStack vs. Podman Desktop Macilla (2026)

Kysymyksiä ja vastauksia

Miten skannaan Apple container -levykuvan haavoittuvuuksien varalta?

Tallenna se komennolla container image save --platform linux/arm64 -o app.tar app:dev, pura se komennolla tar -xf app.tar -C app-img ja aja sitten trivy image --input app-img tai grype oci-dir:app-img. Gantry tekee nämä vaiheet toiminnolla Tarkista haavoittuvuudet….

Miksi Trivy tai Grype epäonnistuu container image save -komennon arkistolla?

Arkisto alkaa merkinnällä ./. Trivy ei löydä siitä tiedostoa manifest.json tai index.json, ja Grype tulkitsee merkinnän polun läpikäynniksi (path traversal). Pura arkisto ja skannaa kansio.

Trivy vai Grype: kumpaa kannattaa käyttää?

Molemmat ovat ilmaisia ja avointa lähdekoodia. Trivy löytää myös salaisuuksia ja virheellisiä määrityksiä ja kirjoittaa SPDX:n; Grype on pieni ja keskittyy paketteihin. Ne käyttävät eri tietokantoja, joten molempia ajamalla löytyy enemmän. Gantry käyttää Trivyä, kun molemmat on asennettu.

Asentaako Gantry skannerit?

Ei. Asenna ne komennolla brew install trivy grype. Gantry etsii polusta PATH, kansioista /opt/homebrew/bin ja /usr/local/bin tai muuttujista GANTRY_TRIVY ja GANTRY_GRYPE.

Tarvitsenko Docker Scoutin tai Docker-tilin levykuvien skannaukseen?

Et. Trivy ja Grype toimivat ilman tiliä sekä Dockerin että Apple containerin levykuvilla.
