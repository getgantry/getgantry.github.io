The native macOS GUI for Apple container
and Docker — your whole fleet on one deck.

Gantry is a free, open-source Mac app for Apple's container tool and for Docker, locally and over SSH. Run containers, Kubernetes clusters, machines and Compose projects on apple/container from one window, next to your Docker hosts. A free Docker Desktop and OrbStack alternative for the Mac. No Electron. No subscription. No limits.

$ brew install --cask getgantry/tap/gantry

New in 0.27.0

Kubernetes, Apple Intelligence and the rest of macOS

Gantry 0.27.0 adds a Kubernetes browser, explains failed containers with Apple Intelligence, and works with Spotlight, Siri, widgets and Control Center. It supports apple/container 1.7.1 and has a new design that follows Apple's Human Interface Guidelines.

Kubernetes browser

Browse pods, deployments, stateful sets, daemon sets, services, ingresses, config maps, secrets, nodes and events of any kubeconfig context. Follow pod logs, open a shell, forward a port, scale, restart a rollout and apply YAML. Secret values stay masked until you reveal them. The browser uses kubectl; if it is missing, Gantry installs it with Homebrew.

Explain Failure with Apple Intelligence

Choose Explain Failure… on a crashed container or a failed operation. Gantry sends recent logs and details, with environment values and secret-like text removed, to the on-device model, and shows the likely cause, the evidence and next steps. Long logs can go to Private Cloud Compute (macOS 27). The panel shows exactly what was sent.

Part of macOS

Notifications with Restart, View Logs and Copy as Prompt. Spotlight finds containers, Compose projects and hosts. Siri and Shortcuts actions, a fleet health widget, Control Center controls for the apple/container services or a favorite container, and gantry:// links for scripts.

Command palette

Press ⌘K and type. One search covers containers, Compose projects, images, volumes, networks, machines, clusters and hosts, with actions such as Start, Show Logs and Open Shell.

Act on many at once

Select several containers, images, volumes or networks and start, stop, restart or remove them in one step, with progress and a report for each item.

Paste a docker run

Paste a docker run, podman run or container run command and Gantry fills the New Container form, with a list of the flags it cannot use. Copy any container back as a command, or save it as a recipe. How it works

Built-in exec terminal

Full terminal emulation into any running container, local or remote — with color themes (System, Solarized, Dracula, Nord).

Remote hosts over SSH

Tunnels exactly like docker -H ssh:// via dial-stdio — ProxyJump bastions, multi-key auth, auto-reconnect. Nothing to install on the server, secrets in the Keychain. One-click import from ~/.ssh/config and docker context ls.

Drag & drop file browser

Browse a container's filesystem, move files in and out, and drop whole folders straight from Finder — on Docker and apple/container hosts alike.

Open in browser & forward

One click opens a published port. SSH ports tunnel to localhost automatically — and if it's taken, Gantry picks a free one you can edit.

Share to the internet

One click exposes a published port over a Cloudflare Tunnel. Gantry installs cloudflared for you, then gives a quick tunnel (no account, a *.trycloudflare.com URL) or a named tunnel on your own domain — perfect for a dev preview, a webhook, or letting an AI agent reach a container on your Mac.

Compose, anywhere

Containers group by their Compose project. Bring a compose file up on any host — local Docker, SSH or apple/container — with an inline YAML editor; the runner adapts per engine.

Private registries, automatically

Pulls read the docker login you already did — Gantry resolves credentials from ~/.docker/config.json, helpers and the Keychain, on create, Quick Run and Compose alike.

Build & pull images

Drop a Dockerfile on the window to build with a live log, or pull by reference with per-layer progress. Tag, prune and read layer history. A badge marks images built for a different CPU architecture than the host.

Reclaim space

One panel shows what is taking space — dangling images, stopped containers, unused volumes, build cache — with sizes, and prunes each or all. On apple/container it also runs Trim Disk.

Touch ID on destructive actions

Opt in and Gantry asks for Touch ID — or your login password — before removing a container or deleting a host. Secrets already live in the Keychain.

Terminal themes

Dress the embedded shell in System, Solarized Dark, Dracula or Nord — a full foreground, background and 16-color ANSI palette, applied live.

apple/container GUI

The native macOS GUI for Apple container

Apple's container tool runs Linux containers as lightweight VMs on Apple silicon, but it ships only as a command-line tool. Gantry is the desktop app for it: what Docker Desktop is to Docker, Gantry is to container. It supports every container CLI from 1.0 up to the recommended 1.7.1, and turns on each feature only when your installed CLI supports it.

Containers, logs, stats and exec

Create, start, stop, kill and prune; live logs, stats, an exec terminal, top and tar export, in the same UI as your Docker hosts.

Kubernetes clusters

Create a Kubernetes cluster with container cluster: size the control plane and the workers separately, pick the CNI, and see the nodes, the Kubernetes version and the kubeconfig context. Cluster nodes are locked against accidental stop and delete. Read more

Local images in the cluster

On CLI 1.7, turn on Use local images (--shared-image-store) and pods run the images you build or pull, with no registry. On CLI 1.5 and 1.6, right-click an image and choose Load into Cluster.

Clear hints when the install is broken

If the cluster services do not answer, Gantry tells you why. A Homebrew build without the cluster services gets a link to the signed installer; anything else gets a Restart Services button.

Container machines in VS Code

Create, start and stop container machine Linux environments, set CPUs and memory, open a shell, or open the machine in VS Code over Remote-SSH.

Nested virtualization and custom kernels

Boot a machine with nested virtualization (M3 or newer) or your own kernel. Boot containers from a custom kernel with extra boot arguments.

Apple container compose

apple/container has no compose. Gantry runs your docker-compose.yml: it builds, creates the network and volumes, and starts services in depends_on order. Service names resolve through network DNS aliases.

Network DNS aliases

Container aliases, subtree aliases such as .gateway, and short names when a default DNS domain is set. Every container gets a routable IP and a name.domain hostname.

Manage the image builder

See the builder state, image, CPUs, memory and IP. Start it with CPU, memory and DNS options, stop it or delete it. When the builder image is outdated, Gantry offers to recreate it.

Registry logins

List, add and remove container registry logins. The password goes to the CLI on stdin only, and Gantry keeps no copy.

Kernel install

Install the recommended kernel, a kernel file or a tar archive, with live progress. Gantry warns you when no default kernel is installed.

Services and service logs

Start, stop and restart the container services, compare client and server versions, and stream service logs filtered by level, service and text.

System properties editor

Edit the container system properties in config.toml. Gantry marks the changes that need a restart and restarts the services for you. On CLI 1.7, it also edits the [container.dns] defaults: name servers, search domains and options.

Commit and Trim Disk

Commit a container to an image (container commit) and reclaim disk space with Trim Disk (container clean), also in the Reclaim Space panel.

File browser: upload and download

Browse a container's files, download them or drag them out to Finder (container copy), and drop files or whole folders in.

Quick Run and Finder

Pick an image, share a folder, map ports and choose a domain, then run. Right-click a compose file in Finder and open it with Gantry.

Labels that contain =

The container CLI rejects label values with =. Gantry encodes them on create and decodes them on read, so a value such as a=b stays intact.

One fleet, two runtimes

apple/container hosts sit next to your local Docker and SSH hosts on one dashboard, with the same sparklines, health and failure notifications.

MCP tools for agents

The bundled MCP server gives agents the same reach: containers, machines, clusters, and apple_* system tools for services, builder, registries, properties, logs and kernels.

FAQ

Questions, answered

Everything you might want to know before you install Gantry.

What is the best GUI for Apple container?

Gantry is a free, open-source native macOS GUI made for Apple's container tool (apple/container). It covers the container lifecycle, logs, stats and an exec terminal, plus the parts of the CLI that other GUIs do not reach: Kubernetes clusters (container cluster), container machines, the image builder, registry logins, kernels, service logs and system properties. It supports CLI 1.0 to 1.7.1 and turns each feature on only when your CLI supports it. See the apple/container guide.

What is Apple container (apple/container)?

apple/container is Apple's open-source tool for running Linux containers on a Mac. Each container runs in its own lightweight virtual machine, built on Apple's Virtualization framework. It needs a Mac with Apple silicon and ships as a command-line tool named container, with no desktop app. Gantry adds that desktop app.

Does Gantry support container cluster and Kubernetes?

Yes. On an apple/container host, Gantry creates and deletes Kubernetes clusters with container cluster (CLI 1.6.1 and 1.7; CLI 1.5.0 to 1.6.0 use container k8s). You choose the name, the workers, the CPUs and memory of the control plane and of the workers (1.7), the node image, the CNI and whether nodes use your local images (1.7). Gantry shows the nodes, writes the kubeconfig and opens the cluster in its Kubernetes browser. See Kubernetes on apple/container.

Can I use docker compose with Apple container?

Yes. apple/container has no compose command, so Gantry does the orchestration over the container CLI: it builds build: services, creates the project network and named volumes, and starts each service in depends_on order with the standard Compose labels. Service names resolve through network DNS aliases. Open a docker-compose.yml from Finder, the File menu or by dropping it on the window.

How do I open a container machine in VS Code?

Start the machine in Gantry and click Open in VS Code. Gantry opens the machine in VS Code over Remote-SSH, as in Apple's container-machine-vscode example. The machine image must run sshd, and VS Code with the Remote-SSH extension must be installed.

Which apple/container versions does Gantry support?

Gantry needs container CLI 1.0 or later and recommends 1.7.1. It reads the installed version and shows only the features that version supports, for example worker sizes and the shared image store (1.7), commit (1.6) and Trim Disk (1.4). If the CLI is missing or old, Gantry offers a guided setup.

Can Gantry browse a Kubernetes cluster?

Yes. The Kubernetes section lists pods, deployments, stateful sets, daemon sets, services, ingresses, config maps, secrets, nodes and events for each kubeconfig context, and has pod logs, a pod shell, port forwards, scale, rollout restart, delete and Apply YAML. It works with any cluster, and the contexts of apple/container clusters come first. The browser uses kubectl, and Gantry can install it with Homebrew. See Run Kubernetes on a Mac.

What does Explain Failure send to Apple Intelligence?

Recent logs and the container details, with environment values and secret-like text removed. Small requests run on the on-device model. With the setting for long logs on (macOS 27), long logs go to Private Cloud Compute. The panel shows what was sent. A suggested command opens in Terminal but does not run until you press Return. Without Apple Intelligence, Gantry offers a prompt to copy into another AI assistant.

Can I paste a docker run command into Gantry?

Yes. In the New Container sheet, choose Paste Command…. Gantry reads docker run, docker create, podman run and container run, fills the form and lists each flag that it cannot use, with the reason. See Create a container from a docker run command.

Can Gantry manage the apple/container builder, registries and kernel?

Yes. The System section of an apple/container host starts, stops and deletes the image builder with CPU, memory and DNS options; lists, adds and removes registry logins (the password goes to the CLI on stdin only); installs the recommended kernel, a kernel file or a tar archive; streams service logs; and edits the system properties in config.toml.

Is Gantry a Docker Desktop, OrbStack or Podman Desktop alternative?

For the GUI, yes. Gantry is a free, native macOS app for managing containers, images, volumes, networks, logs and stats. It is a client, not an engine: it uses the Docker daemon you already run (Docker Desktop, OrbStack, Colima) or Apple's container tool, and adds a multi-host view, SSH hosts and an MCP server. See the comparison.

Is Gantry free?

Yes. Gantry is free and open source under the MIT license. There is no subscription, no account, and no limit on the number of hosts or containers.

What do I need to run Gantry?

macOS 26 or later on Apple silicon or Intel, plus a Docker daemon (Docker Desktop, OrbStack, Colima or similar) or Apple's container tool. apple/container itself needs Apple silicon, so on an Intel Mac Gantry manages Docker hosts only.

Does Gantry work with OrbStack, Colima and Docker Desktop?

Yes. Gantry talks directly to the Docker Engine API over the Unix socket, so it works with any daemon that exposes it, including OrbStack, Colima and Docker Desktop.

Can Gantry manage remote Docker hosts?

Yes. Gantry connects to remote daemons over SSH, the same way as docker -H ssh://, with ProxyJump bastions, multi-key auth and auto-reconnect. Nothing needs to be installed on the server, and secrets live in the macOS Keychain.

Does Gantry alert me when a container fails?

Yes. Gantry posts a native macOS notification when a container crashes, runs out of memory, or fails its health check on any host: local, SSH or apple/container. Click it to go to the container. Stops and restarts you start from Gantry stay quiet, and you can turn it off in Settings.

Can Gantry pull from private registries?

Yes. On Docker hosts, Gantry reads credentials from your ~/.docker/config.json (the same docker login you already ran), including inline auth, credential helpers and the macOS Keychain. On apple/container hosts, it manages container registry logins.

Can Gantry expose a local container to the internet?

Yes. One click on a published port shares it over a Cloudflare Tunnel. Gantry installs cloudflared if needed, then starts a quick tunnel (no Cloudflare account, a temporary trycloudflare.com URL) or a named tunnel on your own hostname. The public URL shows under the port with open, copy and stop controls.

Is Gantry an Electron app?

No. Gantry is a native app built with SwiftUI and Swift 6. The UI is available in 28 languages: English, Simplified Chinese and 26 European languages, for example Serbian in Cyrillic and Latin script. It follows the macOS system language.

How do I install Gantry?

Run brew install --cask getgantry/tap/gantry, or download the latest release from GitHub and drag Gantry.app into Applications.

Can AI agents control Gantry?

Yes. Gantry bundles an MCP server and macOS App Intents, so Claude, Shortcuts, Siri and scripts get the same reach as the GUI on every host, including SSH hosts: containers, images, volumes, networks, Compose, apple/container machines, Kubernetes clusters, apple_* system tools (services, builder, registries, properties, logs, kernel) and port sharing. On macOS 26 and later, Explain Failure… also asks Apple Intelligence why a container failed. Add the MCP server with claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp.
