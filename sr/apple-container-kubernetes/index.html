Gantry/Kubernetes на apple/container

Kubernetes на Apple container-у

apple/container може да покрене Kubernetes кластер чији су чворови контејнери на вашем Mac-у. Gantry је GUI за то: креирајте кластер, пратите како се чворови подижу, повежите kubectl и учитајте локалне слике, без дугих container cluster командних линија.

Укратко. На apple/container хосту одељак Кластери у Gantry-ју креира и брише Kubernetes кластере командом container cluster (CLI 1.6.1) или container k8s (CLI од 1.5.0 до 1.6.0). Подржава више радних чворова, прилагођени CNI, приказ чворова, kubeconfig и kubectl контекст, као и Учитај у кластер за локалне слике.

Захтеви

  • Mac са Apple silicon чипом, macOS 26 и Gantry (brew install --cask getgantry/tap/gantry).
  • container CLI 1.5.0 или новији; препоручује се 1.6.1. Радни чворови и CNI Ништа захтевају 1.6.0 или новији.
  • kubectl, ако желите да кластер користите из терминала.

Креирање кластера

  1. Изаберите свој apple/container хост и отворите Кластери у бочној траци.
  2. Започните креирање новог кластера и попуните опције у наставку.
  3. Креирајте га. Листа приказује нови кластер са напретком уживо. Откажи прекида креирање и брише већ направљене чворове.
ОпцијаCLI заставицаНапомене
Име--nameУједно и име kubeconfig контекста
Радни чворови--workersБрој радних чворова. CLI 1.6.0+
CPU--cpusПо чвору
Меморија--memoryПо чвору, на пример 4G
Слика чвора--node-imageПразно задржава подразумевану вредност CLI-ја
CNI--cniПодразумевано (приложени kindnet), Ништа (NONE, CLI 1.6.0+) или путања до прилагођеног манифеста

Иста команда у CLI-ју:

Љуска
container cluster create --name dev --workers 2 --cpus 2 --memory 4G

Чворови и детаљи кластера

Листа кластера приказује сваки кластер са његовим чворовима: улога, стање и адреса. Приказ детаља садржи Преглед (kubectl контекст, API сервер, радни чворови, мрежа чворова), табелу Чворови, Инспекција за сирове податке чворова и радње Упиши Kubeconfig, Копирај kubectl команду контекста и Обриши.

Повезивање kubectl-а

CLI при креирању кластера додаје у ~/.kube/config контекст назван по кластеру. Користите Копирај kubectl команду контекста у Gantry-ју или је откуцајте:

Љуска
kubectl --context dev get nodes

Да бисте кластер држали у засебној датотеци, користите Упиши Kubeconfig. Gantry покреће container cluster write-config; подразумевана путања је ~/.kube/<name>.kubeconfig.

Учитавање локалних слика у кластер

Изградите или повуците слику на apple/container хосту, затим кликните десним тастером на њу у одељку Слике и изаберите Учитај у кластер. Gantry покреће container cluster load-image, који копира слику у containerd сваког чвора. За локални развој регистар вам није потребан.

Љуска
container cluster load-image --name dev myapp:dev

Избор CNI-ја

Подразумевано је приложени kindnet манифест. Изаберите Прилагођени манифест да бисте из датотеке инсталирали сопствени CNI, на пример Calico или Cilium. Изаберите Ништа да бисте CNI касније инсталирали сами; до тада чворови остају у стању NotReady.

Кластери преко AI агената

Gantry MCP сервер има list_clusters, create_cluster и delete_cluster, па агент као што је Claude Code може да направи привремени кластер за тест и да га после уклони.

Додајте Gantry MCP сервер
claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp

Више о apple/container-у

Прочитајте водич за apple/container за сваку container команду и њену могућност у Gantry-ју или погледајте како се Gantry пореди са Docker Desktop-ом, OrbStack-ом и Podman Desktop-ом.

Питања и одговори

Да ли Apple container подржава Kubernetes?

Да. container CLI креира Kubernetes кластере чији чворови раде као контејнери: container cluster у CLI-ју 1.6.1, container k8s у CLI-ју од 1.5.0 до 1.6.0. Gantry томе даје GUI.

Да ли Gantry подржава container cluster?

Да. Gantry приказује, креира и брише кластере на apple/container хостовима, приказује њихове чворове, уписује kubeconfig, копира kubectl команду контекста и учитава локалне слике у кластер. Користи cluster или k8s, у зависности од ваше верзије CLI-ја.

Како да користим kubectl са apple/container кластером?

Када CLI креира кластер, у ~/.kube/config додаје kubeconfig контекст назван по кластеру. Покрените kubectl --context <name> get nodes. За засебну датотеку користите Упиши Kubeconfig у Gantry-ју; подразумевана путања је ~/.kube/<name>.kubeconfig.

Како да пребацим локалну слику у кластер без регистра?

У Gantry-ју кликните десним тастером на слику у одељку Слике и изаберите Учитај у кластер. Gantry покреће container cluster load-image, који копира слику у containerd сваког чвора.

Могу ли да креирам кластер са више чворова?

Да. Подесите број радних чворова у прозору за креирање. Радни чворови захтевају CLI 1.6.0 или новији.

Могу ли да користим сопствени CNI, на пример Calico или Cilium?

Да. Изаберите Прилагођени манифест и затим датотеку манифеста или изаберите Ништа и сами примените CNI када се кластер покрене. Чворови остају у стању NotReady док CNI не почне да ради. Ништа захтева CLI 1.6.0 или новији. Подразумевани CNI је приложени kindnet манифест.
