Gantry/docker run -komennosta

Kontin luonti docker run -komennosta

Useimmissa README-tiedostoissa on docker run -rivi. Gantry lukee rivin ja täyttää Uusi kontti -lomakkeen Docker-isännälle tai Applen container-työkalulle. Tämä opas näyttää, miten se toimii ja miten komennon voi muuntaa käsin.

Lyhyesti. Avaa Gantryssa Uusi kontti, valitse Sijoita komento…, sijoita docker run -rivi ja napsauta Täytä lomake. Gantry luettelee syineen jokaisen valinnan, jota se ei voi käyttää. CLI:ssä useimmat valinnat ovat samat: korvaa docker run komennolla container run ja poista --restart.

Sijoita komento Gantryyn

  1. Valitse isäntä: Docker-isäntä tai apple/container-isäntä.
  2. Avaa Kontit ja napsauta Uusi kontti.
  3. Napsauta Sijoita komento… ja sijoita rivi. Rivinloppujen \, lainausmerkit, $-kehote ja sudo eivät haittaa.
  4. Lue esikatselu: levykuva, valinnat, joita Gantry ei voi käyttää, huomautukset ja tätä isäntää koskevat varoitukset.
  5. Napsauta Täytä lomake, tarkista arvot ja luo kontti.

Gantry lukee komennot docker run, docker container run, docker create, podman run ja container run. Merkintöjen &&, ||, ; tai | jälkeinen teksti ohitetaan, ja siitä näytetään huomautus.

Noin 80 muuta Dockerin valintaa tunnetaan: Gantry ohittaa niiden arvot oikein ja luettelee ne käyttämättöminä, joten mitään ei katoa ilman huomautusta.

    Varoitukset apple/container-isännille

Joitakin Dockerin valintoja ei ole apple/containerissa. Gantry varoittaa niistä ja jättää ne pois luontipyynnöstä:

  • uudelleenkäynnistyskäytännöt (--restart);
  • CPU:iden murto-osat, kuten --cpus 0.5;
  • verkkotilat host, none ja container:;
  • portit ilman isännän porttia, kuten -p 80.

Docker-isännällä Gantry varoittaa apple/containerin valinnoista: DNS-verkkotunnuksesta ja ytimen valinnoista.

    Muunna docker run container runiksi käsin

CLI:ssä useimmat valinnat pysyvät samoina. Esimerkki Redisillä:

Pääte
docker run -d --name cache --restart unless-stopped -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

muuttuu muotoon:

Pääte
container volume create redisdata
container run -d --name cache -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

Luo nimetty taltio ensin komennolla container volume create. Poista --restart ja pyöristä --cpus kokonaisluvuksi. --platform toimii kuten Dockerissa.

    Kopioi kontti komentona

Myös toiseen suuntaan onnistuu. Napsauta konttia hiiren oikealla tai käytä Lisää-valikkoa ja valitse Kopioi komentona: Gantry kirjoittaa docker run- tai container run -rivin. Se jättää pois levykuvan oletukset, kuten sen ympäristön ja komennon, joten rivi pysyy lyhyenä. Tämä toimii myös pysäytetyille konteille.

    Tallenna reseptiksi

Avaa Uusi kontti -ikkunassa Reseptit ja valitse Tallenna reseptiksi…. Seuraavalla kerralla Täytä reseptistä antaa saman lomakkeen millä tahansa isännällä. Reseptit ovat tiedostossa ~/Library/Application Support/Gantry/recipes.json, joten voit varmuuskopioida tai jakaa ne.

    Rajoitukset
  • Gantry säilyttää valinnan --env-file polun mutta ei lue tiedostoa, eikä se lue komentotulkkisi ympäristöä, kun -e KEY on ilman arvoa.
  • Valinnan --mount tmpfs-liitokset ja nimettömät taltiot luetellaan tukemattomina.
  • Kaksi porttia samalle kontin portille (-p 8080:80 -p 8081:80) täyttävät lomakkeen, mutta lomake hylkää sitten kaksoiskappaleen.

Kysymyksiä ja vastauksia

Miten docker run muunnetaan container runiksi?

Korvaa docker run komennolla container run. -d, -p, -e, -v, --name, --rm, -it, -w ja --entrypoint pysyvät samoina. Poista --restart ja käytä kokonaisia CPU:ita. Tai sijoita rivi Gantryyn ja anna sen täyttää lomake.

Voiko Gantry tuoda docker run -komennon?

Kyllä. Uusi kontti -ikkunan Sijoita komento… lukee komennot docker run, docker create, podman run ja container run ja täyttää lomakkeen.

Mitä tapahtuu valinnoille, joita Gantry ei tue?

Ne luetellaan esikatselussa syineen, ja ne jäävät lomakkeeseen osioon Sijoitetusta komennosta, joten voit tarkistaa ne myöhemmin.

Voiko käynnissä olevan kontin muuttaa takaisin docker run -komennoksi?

Kyllä. Konttivalikon Kopioi komentona kirjoittaa kontille docker run- tai container run -rivin.
