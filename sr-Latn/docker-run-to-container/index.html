Gantry/Iz docker run

Kreiranje kontejnera iz docker run komande

Većina README datoteka daje red docker run. Gantry čita taj red i popunjava obrazac Novi kontejner, za Docker host ili za Apple-ov alat container. Ovaj vodič pokazuje kako, kao i kako da komandu pretvorite ručno.

Ukratko. U Gantry-ju otvorite Novi kontejner, izaberite Nalepi komandu…, nalepite red docker run i kliknite Popuni obrazac. Gantry navodi svaku zastavicu koju ne može da upotrebi, sa razlogom. Za CLI je većina zastavica ista: zamenite docker run sa container run i uklonite --restart.

Nalepite komandu u Gantry

  1. Izaberite host: Docker host ili apple/container host.
  2. Otvorite Kontejneri i kliknite Novi kontejner.
  3. Kliknite Nalepi komandu… i nalepite red. Krajevi redova sa \, navodnici, odziv $ i sudo nisu problem.
  4. Pročitajte pregled: sliku, zastavice koje Gantry ne može da upotrebi, napomene i upozorenja za ovaj host.
  5. Kliknite Popuni obrazac, proverite vrednosti i kreirajte kontejner.

Gantry čita docker run, docker container run, docker create, podman run i container run. Tekst posle &&, ||, ; ili | se zanemaruje, uz napomenu.

Upozorenja za apple/container hostove

Neke Docker opcije ne postoje na apple/container-u. Gantry upozorava na njih i izostavlja ih iz zahteva za kreiranje:

  • smernice ponovnog pokretanja (--restart);
  • delovi CPU-a, kao što je --cpus 0.5;
  • mrežni režimi host, none i container:;
  • portovi bez porta hosta, kao što je -p 80.

Na Docker hostu Gantry upozorava na opcije apple/container-a: DNS domen i opcije jezgra.

Ručno pretvaranje docker run u container run

Za CLI većina zastavica ostaje ista. Primer za Redis:

Terminal
docker run -d --name cache --restart unless-stopped -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

postaje:

Terminal
container volume create redisdata
container run -d --name cache -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

Prvo kreirajte imenovani volumen komandom container volume create. Uklonite --restart i zaokružite --cpus na ceo broj. --platform radi kao u Docker-u.

Kopiranje kontejnera kao komande

Radi i u suprotnom smeru. Kliknite desnim tasterom na kontejner ili koristite meni Još i izaberite Kopiraj kao komandu: Gantry piše red docker run ili container run. Izostavlja podrazumevane vrednosti slike, kao što su njeno okruženje i komanda, pa red ostaje kratak. Ovo radi i za zaustavljene kontejnere.

Čuvanje kao recept

U prozoru Novi kontejner otvorite Recepti i izaberite Sačuvaj kao recept…. Sledeći put Popuni iz recepta daje isti obrazac na bilo kom hostu. Recepti se čuvaju u ~/Library/Application Support/Gantry/recipes.json, pa možete da ih arhivirate ili podelite.

Ograničenja

  • Gantry zadržava putanju iz --env-file, ali ne čita datoteku i ne čita vašu ljusku za -e KEY bez vrednosti.
  • tmpfs montiranja i anonimni volumeni iz --mount navode se kao nepodržani.
  • Dva porta za isti port kontejnera (-p 8080:80 -p 8081:80) popunjavaju obrazac, ali obrazac zatim odbija duplikat.

Pitanja i odgovori

Kako da pretvorim docker run u container run?

Zamenite docker run sa container run. -d, -p, -e, -v, --name, --rm, -it, -w i --entrypoint ostaju isti. Uklonite --restart i koristite ceo broj CPU-ova. Ili nalepite red u Gantry i pustite ga da popuni obrazac.

Može li Gantry da uveze docker run komandu?

Da. Nalepi komandu… u prozoru Novi kontejner čita docker run, docker create, podman run i container run i popunjava obrazac.

Šta se dešava sa zastavicama koje Gantry ne podržava?

Navode se u pregledu sa razlogom i ostaju u obrascu u odeljku Iz nalepljene komande, pa ih možete proveriti kasnije.

Mogu li da pokrenuti kontejner pretvorim nazad u docker run komandu?

Da. Kopiraj kao komandu u meniju kontejnera piše red docker run ili container run za taj kontejner.
