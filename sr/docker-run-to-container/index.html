Gantry/Из docker run

Креирање контејнера из docker run команде

Већина README датотека даје ред docker run. Gantry чита тај ред и попуњава образац Нови контејнер, за Docker хост или за Apple-ов алат container. Овај водич показује како, као и како да команду претворите ручно.

Укратко. У Gantry-ју отворите Нови контејнер, изаберите Налепи команду…, налепите ред docker run и кликните Попуни образац. Gantry наводи сваку заставицу коју не може да употреби, са разлогом. За CLI је већина заставица иста: замените docker run са container run и уклоните --restart.

Налепите команду у Gantry

  1. Изаберите хост: Docker хост или apple/container хост.
  2. Отворите Контејнери и кликните Нови контејнер.
  3. Кликните Налепи команду… и налепите ред. Крајеви редова са \, наводници, одзив $ и sudo нису проблем.
  4. Прочитајте преглед: слику, заставице које Gantry не може да употреби, напомене и упозорења за овај хост.
  5. Кликните Попуни образац, проверите вредности и креирајте контејнер.

Gantry чита docker run, docker container run, docker create, podman run и container run. Текст после &&, ||, ; или | се занемарује, уз напомену.

Упозорења за apple/container хостове

Неке Docker опције не постоје на apple/container-у. Gantry упозорава на њих и изоставља их из захтева за креирање:

  • смернице поновног покретања (--restart);
  • делови CPU-а, као што је --cpus 0.5;
  • мрежни режими host, none и container:;
  • портови без порта хоста, као што је -p 80.

На Docker хосту Gantry упозорава на опције apple/container-а: DNS домен и опције језгра.

Ручно претварање docker run у container run

За CLI већина заставица остаје иста. Пример за Redis:

Терминал
docker run -d --name cache --restart unless-stopped -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

постаје:

Терминал
container volume create redisdata
container run -d --name cache -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

Прво креирајте именовани волумен командом container volume create. Уклоните --restart и заокружите --cpus на цео број. --platform ради као у Docker-у.

Копирање контејнера као команде

Ради и у супротном смеру. Кликните десним тастером на контејнер или користите мени Још и изаберите Копирај као команду: Gantry пише ред docker run или container run. Изоставља подразумеване вредности слике, као што су њено окружење и команда, па ред остаје кратак. Ово ради и за заустављене контејнере.

Чување као рецепт

У прозору Нови контејнер отворите Рецепти и изаберите Сачувај као рецепт…. Следећи пут Попуни из рецепта даје исти образац на било ком хосту. Рецепти се чувају у ~/Library/Application Support/Gantry/recipes.json, па можете да их архивирате или поделите.

Ограничења

  • Gantry задржава путању из --env-file, али не чита датотеку и не чита вашу љуску за -e KEY без вредности.
  • tmpfs монтирања и анонимни волумени из --mount наводе се као неподржани.
  • Два порта за исти порт контејнера (-p 8080:80 -p 8081:80) попуњавају образац, али образац затим одбија дупликат.

Питања и одговори

Како да претворим docker run у container run?

Замените docker run са container run. -d, -p, -e, -v, --name, --rm, -it, -w и --entrypoint остају исти. Уклоните --restart и користите цео број CPU-ова. Или налепите ред у Gantry и пустите га да попуни образац.

Може ли Gantry да увезе docker run команду?

Да. Налепи команду… у прозору Нови контејнер чита docker run, docker create, podman run и container run и попуњава образац.

Шта се дешава са заставицама које Gantry не подржава?

Наводе се у прегледу са разлогом и остају у обрасцу у одељку Из налепљене команде, па их можете проверити касније.

Могу ли да покренути контејнер претворим назад у docker run команду?

Да. Копирај као команду у менију контејнера пише ред docker run или container run за тај контејнер.
