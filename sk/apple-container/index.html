Gantry/Sprievodca apple/container

Apple container na Macu: kompletný sprievodca a GUI

apple/container spúšťa linuxové kontajnery na vašom Macu, každý vo vlastnom odľahčenom virtuálnom stroji. Dodáva sa ako nástroj príkazového riadka. Gantry je preň natívne GUI pre macOS. Tento sprievodca vysvetľuje, čo nástroj dokáže, ako ho nastaviť a ktorá funkcia Gantry pokrýva jednotlivé príkazy container.

V skratke. Gantry je bezplatná open-source (MIT) aplikácia pre macOS, ktorá z jedného okna spravuje nástroj container od Apple aj Docker. Podporuje CLI container 1.0 až 1.7.1 (odporúčané) a zobrazuje iba funkcie, ktoré vaša verzia CLI podporuje. Nainštalujte ju príkazom brew install --cask getgantry/tap/gantry.

Čo je apple/container?

apple/container je open-source nástroj od Apple napísaný vo Swifte, ktorý vytvára a spúšťa linuxové kontajnery na Macu. Docker Desktop spúšťa všetky kontajnery v jednom zdieľanom linuxovom virtuálnom stroji; apple/container spúšťa každý kontajner vo vlastnom odľahčenom virtuálnom stroji postavenom na frameworku Virtualization od Apple. Používa štandardné obrazy OCI, takže sťahuje z tých istých registrov ako Docker a odosiela do nich.

  • Hardvér: Mac s Apple silicon.
  • macOS: Apple ho podporuje v macOS 26.
  • Rozhranie: iba CLI container. Neexistuje desktopová aplikácia ani príkaz compose.
  • Sieť: každý kontajner dostane na vašom Macu vlastnú IP adresu a lokálne domény DNS dávajú kontajnerom názvy ako web.test.

Prečo používať GUI pre apple/container?

CLI je kompletné, ale každodenná práca znamená množstvo príkazov: container list, logs, stats, exec a na zvyšok system, builder, registry, machine a cluster. Gantry ich sústredí do jedného okna so živými aktualizáciami, takže stav vidíte a nemusíte sa naň stále dopytovať. Pridáva aj to, čo CLI nemá: súbory Compose, hlásenia o zlyhaní, prehľad flotily s vašimi hostiteľmi Docker a server MCP pre AI agentov.

Nastavenie apple/container s Gantry

  1. Nainštalujte Gantry: brew install --cask getgantry/tap/gantry a potom odstráňte príznak karantény (pozrite si Inštalácia).
  2. Nainštalujte CLI container z podpísaného balíka .pkg na stránke vydaní apple/container. Ak chýba alebo je staršie ako 1.0, Gantry zobrazí hárok s postupom inštalácie.
  3. V Gantry vyberte Pridať hostiteľa… a pridajte hostiteľa Apple Container. Pri pripojení sa spustia služby container, ak sú zastavené.
  4. Ak nie je nainštalované predvolené jadro, prehľad hostiteľa zobrazí banner. Kliknite naň a nainštalujte odporúčané jadro.
Pozor
Použite podpísaný inštalačný balík, nie build z Homebrew. Build z Homebrew neobsahuje backend strojov a vo verzii 1.7.1 ani služby klastra, takže container machine a container cluster nefungujú.

Čo Gantry pridáva k apple/container

Klastre Kubernetes

Vytvárajte klastre Kubernetes pomocou container cluster, nastavte veľkosť pracovných uzlov, nechajte pody používať vaše lokálne obrazy, zvoľte CNI a sledujte každý uzol. Potom klaster prehliadajte v prehliadači Kubernetes v Gantry. Pozrite si Kubernetes na apple/container a podrobný návod Kubernetes na Macu.

Stroje container a VS Code

Stroje sú dlhodobé linuxové prostredia z container machine. Gantry ich vytvára, spúšťa, zastavuje a maže, nastavuje predvolený stroj, upravuje CPU a pamäť a otvára shell. Od CLI 1.1 môže stroj naštartovať s vnorenou virtualizáciou (Apple silicon M3 alebo novší) a vlastným jadrom. Otvoriť vo VS Code sa pripojí k spustenému stroju cez Remote-SSH; v obraze stroja musí bežať sshd.

Docker Compose na apple/container

Otvorte docker-compose.yml z Findera (Otvoriť v aplikácii ▸ Gantry alebo Rýchle akcie ▸ Compose Up v apple/container), z menu Súbor ▸ Otvoriť súbor Compose… alebo pretiahnutím do okna. Gantry zostaví služby s build:, vytvorí sieť projektu a pomenované zväzky a spustí služby v poradí podľa depends_on so štandardnými štítkami com.docker.compose.*. Keď je nastavená predvolená doména DNS, služby sa navzájom nájdu podľa názvu služby cez sieťové aliasy.

Aliasy DNS v sieti a lokálne domény

Gantry odovzdáva sieťové aliasy do container ako --network <name>,alias=…. Bez predvolenej domény DNS prejdú iba plne kvalifikované názvy a alias podstromu (s bodkou na začiatku, napríklad .gateway) prejde iba ako presný alias. S predvolenou doménou fungujú aj krátke názvy. Gantry vytvára a maže lokálne domény DNS, nastavuje predvolenú doménu a novým kontajnerom prideľuje názov hostiteľa name.domain. Pozrite si Lokálne názvy DNS.

Systém: služby, builder, registre, jadro, logy, vlastnosti

Každý hostiteľ apple/container má sekciu Systém. Funguje aj vtedy, keď je hostiteľ odpojený, takže z nej môžete spustiť zastavené služby.

  • Stav a verzia: verzie klienta a servera s upozornením, keď sa líšia; spustenie, zastavenie a reštart služieb; údaje o hostiteľovi a cesty.
  • Builder obrazov: stav, obraz, CPU, pamäť a IP; spustenie s možnosťami CPU, pamäte a DNS; zastavenie; vymazanie. Karta upozorní, keď je obraz buildera zastaraný, a vytvorí ho znova.
  • Prihlásenia do registrov: výpis, prihlásenie a odhlásenie. Heslo ide do CLI výhradne cez stdin (--password-stdin) a Gantry si neuchováva žiadnu kópiu.
  • Jadro: inštalácia odporúčaného jadra, súboru jadra alebo archívu tar s priebehom v reálnom čase.
  • Logy služieb: naživo alebo jednorazovo, za posledných 5 minút až 1 deň, filtrované podľa úrovne, služby a textu.
  • Systémové vlastnosti: úpravy sa ukladajú do ~/.config/container/config.toml, s príznakom čakajúceho reštartu a tlačidlom Reštartovať služby. V CLI 1.7 majú menné servery, vyhľadávacie domény a možnosti [container.dns] editor zoznamu.

Uloženie ako obraz, TRIM disku a súbory

Uložiť ako obraz používa container commit (CLI 1.6). Spustiť TRIM disku používa container clean (CLI 1.4) a zobrazuje sa aj ako riadok v paneli Uvoľniť miesto. Karta Súbory ukladá súbory do Macu a umožňuje ich vytiahnuť do Findera pomocou container copy (kontajner musí byť spustený) a tiež nahráva súbory a priečinky.

Štítky so znakom =

container create odmieta hodnotu štítka so znakom =, a to aj v CLI 1.6.1. Gantry takéto hodnoty pri vytváraní kontajnera zakóduje a pri spätnom čítaní dekóduje, takže vidíte presne tie štítky, ktoré ste nastavili.

Server MCP a Skratky

Vstavaný server gantry-mcp dáva AI agentom na hostiteľoch apple/container rovnaké možnosti: kontajnery, obrazy, zväzky, siete, Compose, stroje (list_machines, create_machine a ďalšie), klastre (list_clusters, create_cluster, delete_cluster) a systémové nástroje apple_* pre služby, builder, registre (bez nástroja na prihlásenie), vlastnosti, logy a inštaláciu jadra. App Intents pridávajú akcie pre Skratky a Siri. Pozrite si AI agenti a MCP.

Pridanie servera MCP Gantry
claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp

apple/container vedľa Dockeru

Gantry spravuje hostiteľov apple/container, lokálneho démona Dockeru (Docker Desktop, OrbStack, Colima) a vzdialených hostiteľov Docker cez SSH v jednom bočnom paneli a jednom prehľade flotily. Nemusíte si vyberať jedno prostredie. Porovnanie nástrojov funkciu po funkcii nájdete na stránke Gantry vs. Docker Desktop, OrbStack a Podman Desktop. Ako preniesť svoju prácu, opisuje návod Z Docker Desktop na Apple container.

Otázky a odpovede

Aké je najlepšie GUI pre Apple container?

Gantry je bezplatné natívne open-source GUI pre macOS, vytvorené pre apple/container. Prenáša CLI container do desktopovej aplikácie: kontajnery, logy, štatistiky a exec a k tomu klastre Kubernetes, stroje, builder obrazov, prihlásenia do registrov, jadrá, logy služieb a systémové vlastnosti. Tabuľka na tejto stránke uvádza každý príkaz a funkciu Gantry, ktorá ho používa.

Má Apple container GUI?

Apple dodáva container iba ako nástroj príkazového riadka. Gantry je samostatná open-source aplikácia, ktorá mu dáva GUI, hneď vedľa vašich hostiteľov Docker.

Dá sa používať docker compose s Apple container?

apple/container nemá príkaz compose. Gantry načíta docker-compose.yml, zostaví služby s build:, vytvorí sieť a pomenované zväzky a spustí služby v poradí podľa depends_on. Názvy služieb sa prekladajú cez aliasy DNS v sieti.

Ako otvoriť stroj container vo VS Code?

Spustite stroj v Gantry a kliknite na Otvoriť vo VS Code. Gantry ho otvorí cez Remote-SSH, rovnako ako v príklade container-machine-vscode od Apple. V obraze stroja musí bežať sshd.

Funguje Apple container na Macu s Intelom?

Nie. apple/container vyžaduje Mac s Apple silicon. Gantry beží aj na Macoch s Intelom, tam však spravuje iba hostiteľov Docker.

Ktorú verziu CLI container nainštalovať?

Gantry vyžaduje verziu 1.0 alebo novšiu a odporúča 1.7.1. Nainštalujte ju z podpísaného inštalačného balíka zo stránky vydaní apple/container. Build z Homebrew neobsahuje backend strojov ani, vo verzii 1.7.1, služby klastra, takže container machine a container cluster s ním nefungujú.
