Gantry/Docker Desktopista

Siirtyminen Docker Desktopista Apple containeriin

Applen container-työkalu ajaa samoja OCI-levykuvia kuin Docker, joten suurin osa työstäsi siirtyy muutamalla komentomuutoksella. Tämä opas rinnastaa Dockerin ja container-työkalun, siirtää levykuvat ja taltiot ja luettelee puutteet, jotka sinun kannattaa tietää ennen vaihtoa.

Lyhyesti. Asenna allekirjoitettu container-paketti, korvaa docker sanalla container ajossa, koonnissa, lokeissa, exec-komennoissa ja levykuvissa, kopioi nimetyt taltiot tar-tiedostolla ja avaa docker-compose.yml Gantryssa, koska CLI:ssä ei ole compose-komentoa. Voit pitää Docker Desktopin asennettuna kokeilun ajan.

Mikä muuttuu

  • Yksi virtuaalikone kontia kohden. Docker Desktop ajaa kaikki kontit yhdessä Linux-virtuaalikoneessa. apple/container käynnistää jokaiselle kontille pienen virtuaalikoneen, joten jokainen saa Macillasi oman IP-osoitteen.
  • Samat levykuvat ja rekisterit. Levykuvat ovat OCI-levykuvia; noudat niitä Docker Hubista, GHCR:stä ja yksityisistä rekistereistä kuten ennenkin.
  • Ei lisenssimaksua. apple/container on Apache 2.0 -lisensoitu. Docker Desktop vaatii maksullisen tilauksen organisaatioissa, joissa on vähintään 250 työntekijää tai vähintään 10 milj. dollarin liikevaihto.
  • Vain Apple-siru ja macOS 26. Intel-Maceilla pysy Docker-moottorissa.

Tuo levykuvasi

Rekisterissä olevat levykuvat: nouda ne uudelleen komennolla container image pull. Vain Dockerissa olevat paikalliset levykuvat: tallenna ne arkistoon ja lataa se. container image load lukee OCI-arkistoja, ja uudet Docker-versiot kirjoittavat komennolla docker save OCI-asettelun. Jos lataus epäonnistuu, lähetä levykuva rekisteriin ja nouda se sieltä.

Pääte
docker save -o app.tar app:dev
container image load -i app.tar
container image pull nginx:alpine

Siirrä nimetyt taltiot

Docker säilyttää taltioiden tiedot virtuaalikoneessaan. Kopioi jokainen taltio tar-tiedostoon lyhytikäisellä kontilla ja pura se sitten uuteen apple/container-taltioon:

Pääte
docker run --rm -v data:/from -v "$PWD":/to alpine tar -C /from -cf /to/data.tar .
container volume create data
container run --rm -v data:/to -v "$PWD":/from alpine tar -C /to -xf /from/data.tar

Nimetty taltio on apple/containerissa harva ext4-levykuva, oletuksena enintään 512 Gt. Aseta toinen koko valinnalla --opt size=20g. Macisi kansioiden sidosliitokset toimivat kuten Dockerissa: -v ~/project:/app.

Compose-tiedostot

container-CLI:ssä ei ole compose-komentoa. Avaa docker-compose.yml sen sijaan Gantryssa (Finder, Arkisto ▸ Avaa Compose-tiedosto… tai vetämällä ja pudottamalla). Gantry koostaa build:-palvelut, luo projektin verkon ja nimetyt taltiot ja käynnistää palvelut depends_on-järjestyksessä. Palvelut tavoittavat toisensa palvelunimellä verkon DNS-aliasten kautta.

Verkot ja portit

  • -p 8080:80 julkaisee portin osoitteessa localhost, kuten Dockerissa.
  • Jokaisella kontilla on myös oma IP-osoite. Luo paikallinen DNS-verkkotunnus komennolla sudo container system dns create test ja aja kontit valinnalla --dns-domain test: ne saavat nimiä kuten web.test.
  • container network create luo käyttäjän verkkoja; samassa verkossa olevat kontit tavoittavat toisensa.
  • Tiloja --network host, none ja container: ei ole.

Mitä puuttuu

  • Ei Docker Engine API:a. Työkalut, jotka käyttävät socketia /var/run/docker.sock, kuten Testcontainers, Docker SDK:t tai Dev Containers, eivät näe apple/containeria.
  • Ei uudelleenkäynnistyskäytäntöjä. --restart ei ole käytettävissä; kontti ei käynnisty uudelleen itsestään.
  • Ei Composea CLI:ssä. Gantry ajaa Compose-tiedostoja: katso Compose-tiedostot.
  • Ei Docker Desktopin laajennuksia.
  • Vain kokonaisia CPU:ita: --cpus 0.5 ei toimi.
  • Kubernetes toimii toisin: käytä komentoa container cluster, katso Kubernetes Macilla.

Pidä molemmat vaihdon ajan

Gantry hallitsee apple/containeria ja mitä tahansa Docker-moottoria (Docker Desktop, OrbStack, Colima tai Docker SSH:n kautta) yhdessä sivupalkissa. Siirrä yksi projekti kerrallaan ja pidä Docker työkaluille, jotka tarvitsevat sen API:a. Kun et enää tarvitse sitä, voit poistaa Docker Desktopin.

Aiheeseen liittyvät oppaat

  • Kubernetes Macilla Apple containerin avulla: vaiheittainen opas
  • Kontit ja taltiot ulkoisella levyllä Macissa
  • Kontin luonti docker run -komennosta Macilla (docker run container runiksi)
  • Apple container -GUI Macille: kattava apple/container-opas
  • Kubernetes Apple containerilla: GUI container clusterille ja Kubernetes-selain

Kysymyksiä ja vastauksia

Voiko Apple container korvata Docker Desktopin?

Konttien ajamiseen, koostamiseen ja noutamiseen Apple-sirulla kyllä. Siinä ei ole Docker Engine API:a, uudelleenkäynnistyskäytäntöjä, laajennuksia eikä compose-komentoa. Gantry tuo Compose-tiedostot ja GUI:n.

Toimivatko Docker-levykuvat Apple containerilla?

Kyllä. apple/container käyttää standardeja OCI-levykuvia ja noutaa samoista rekistereistä. arm64-levykuvat toimivat natiivisti; amd64-levykuvat toimivat Rosettan kautta valinnalla --arch amd64.

Toimiiko docker compose Apple containerilla?

Ei CLI:stä: komentoa container compose ei ole. Gantry lukee docker-compose.yml-tiedoston ja ajaa palvelut puolestasi apple/containerilla.

Voiko Docker Desktopia ja Apple containeria käyttää samaan aikaan?

Kyllä. Ne eivät jaa levykuvia eivätkä taltioita, mutta ne voivat toimia rinnakkain. Gantry näyttää molemmat yhdessä ikkunassa.

Onko Apple container ilmainen kaupalliseen käyttöön?

On. apple/container on avointa lähdekoodia Apache 2.0 -lisenssillä, ja Gantryllä on MIT-lisenssi. Molemmat ovat ilmaisia kaikenkokoisille yrityksille.
