Gantry/Aus docker run

Container aus einem docker run-Befehl erstellen

Die meisten READMEs geben eine docker run-Zeile an. Gantry liest diese Zeile und füllt das Formular „Neuer Container“ aus, für einen Docker-Host oder für Apples container-Tool. Diese Anleitung zeigt, wie das geht und wie du den Befehl von Hand umwandelst.

Kurz gesagt. Öffne in Gantry Neuer Container, wähle Befehl einsetzen…, setze die docker run-Zeile ein und klicke auf Formular ausfüllen. Gantry listet jedes Flag, das es nicht verwenden kann, mit dem Grund. Für die CLI sind die meisten Flags gleich: Ersetze docker run durch container run und entferne --restart.

Den Befehl in Gantry einsetzen

  1. Wähle einen Host: einen Docker-Host oder einen apple/container-Host.
  2. Öffne Container und klicke auf Neuer Container.
  3. Klicke auf Befehl einsetzen… und setze die Zeile ein. Zeilenenden mit \, Anführungszeichen, ein $-Prompt und sudo sind kein Problem.
  4. Lies die Vorschau: das Image, die Flags, die Gantry nicht verwenden kann, Hinweise und Warnungen für diesen Host.
  5. Klicke auf Formular ausfüllen, prüfe die Werte und erstelle den Container.

Gantry liest docker run, docker container run, docker create, podman run und container run. Text nach &&, ||, ; oder | wird mit einem Hinweis ignoriert.

Etwa 80 weitere Docker-Flags sind bekannt: Gantry überspringt ihre Werte korrekt und listet sie als nicht verwendet, sodass nichts ohne Hinweis verloren geht.

Warnungen für apple/container-Hosts

Manche Docker-Optionen gibt es in apple/container nicht. Gantry warnt davor und lässt sie in der Anfrage zum Erstellen weg:

  • Neustartrichtlinien (--restart);
  • CPU-Bruchteile wie --cpus 0.5;
  • die Netzwerkmodi host, none und container:;
  • Ports ohne Host-Port, etwa -p 80.

Auf einem Docker-Host warnt Gantry vor den apple/container-Optionen: der DNS-Domain und den Kernel-Optionen.

docker run von Hand in container run umwandeln

Für die CLI bleiben die meisten Flags gleich. Ein Beispiel mit Redis:

Terminal
docker run -d --name cache --restart unless-stopped -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

wird zu:

Terminal
container volume create redisdata
container run -d --name cache -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

Erstelle das benannte Volume zuerst mit container volume create. Entferne --restart und runde --cpus auf eine ganze Zahl. --platform funktioniert wie in Docker.

Einen Container als Befehl kopieren

Der umgekehrte Weg geht auch. Klicke mit der rechten Maustaste auf einen Container oder öffne das Menü „Mehr“ und wähle Als Befehl kopieren: Gantry schreibt eine docker run- oder container run-Zeile. Standardwerte des Images, etwa seine Umgebung und sein Befehl, lässt es weg, damit die Zeile kurz bleibt. Das funktioniert auch bei gestoppten Containern.

Als Rezept sichern

Öffne im Fenster „Neuer Container“ Rezepte und wähle Als Rezept sichern…. Beim nächsten Mal liefert Aus Rezept ausfüllen dasselbe Formular auf jedem Host. Rezepte liegen in ~/Library/Application Support/Gantry/recipes.json, du kannst sie also sichern oder weitergeben.

Grenzen

  • Gantry übernimmt den Pfad von --env-file, liest die Datei aber nicht, und liest für -e KEY ohne Wert nicht deine Shell aus.
  • tmpfs-Mounts und anonyme Volumes aus --mount werden als nicht unterstützt gelistet.
  • Zwei Ports für denselben Container-Port (-p 8080:80 -p 8081:80) füllen das Formular aus, aber das Formular lehnt das Duplikat dann ab.

Fragen und Antworten

Wie wandle ich docker run in container run um?

Ersetze docker run durch container run. -d, -p, -e, -v, --name, --rm, -it, -w und --entrypoint bleiben gleich. Entferne --restart und verwende ganze CPUs. Oder setze die Zeile in Gantry ein und lass das Formular ausfüllen.

Kann Gantry einen docker run-Befehl importieren?

Ja. Befehl einsetzen… im Fenster „Neuer Container“ liest docker run, docker create, podman run und container run und füllt das Formular aus.

Was passiert mit Flags, die Gantry nicht unterstützt?

Sie stehen mit dem Grund in der Vorschau und bleiben im Formular im Abschnitt „Aus dem eingesetzten Befehl“, damit du sie später prüfen kannst.

Kann ich einen laufenden Container wieder in einen docker run-Befehl umwandeln?

Ja. Als Befehl kopieren im Container-Menü schreibt eine docker run- oder container run-Zeile für diesen Container.
