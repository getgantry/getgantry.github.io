Gantry/Iz docker run

Stvaranje kontejnera iz naredbe docker run

Većina README datoteka navodi redak docker run. Gantry čita taj redak i ispunjava obrazac Novi kontejner, za Docker host ili za Appleov alat container. Ovaj vodič pokazuje kako, i kako naredbu pretvoriti ručno.

Ukratko. U Gantryju otvorite Novi kontejner, odaberite Zalijepi naredbu…, zalijepite redak docker run i kliknite Ispuni obrazac. Gantry navodi svaku zastavicu koju ne može upotrijebiti, s razlogom. Za CLI je većina zastavica ista: zamijenite docker run s container run i uklonite --restart.

Lijepljenje naredbe u Gantry

  1. Odaberite host: Docker host ili apple/container host.
  2. Otvorite Kontejneri i kliknite Novi kontejner.
  3. Kliknite Zalijepi naredbu… i zalijepite redak. Završeci redaka s \, navodnici, odzivnik $ i sudo nisu problem.
  4. Pročitajte pretpregled: sliku, zastavice koje Gantry ne može upotrijebiti, napomene i upozorenja za ovaj host.
  5. Kliknite Ispuni obrazac, provjerite vrijednosti i stvorite kontejner.

Gantry čita docker run, docker container run, docker create, podman run i container run. Tekst iza &&, ||, ; ili | zanemaruje se, uz napomenu.

Poznato je još oko 80 drugih Docker zastavica: Gantry ispravno preskače njihove vrijednosti i navodi ih kao neiskorištene, pa se ništa ne gubi bez napomene.

Upozorenja za apple/container hostove

Neke Docker opcije ne postoje na apple/containeru. Gantry upozorava na njih i izostavlja ih iz zahtjeva za stvaranje:

  • pravila ponovnog pokretanja (--restart);
  • dijelovi CPU-a, npr. --cpus 0.5;
  • mrežni načini host, none i container:;
  • portovi bez porta hosta, npr. -p 80.

Na Docker hostu Gantry upozorava na opcije apple/containera: DNS domenu i opcije jezgre.

Ručno pretvaranje docker run u container run

Za CLI većina zastavica ostaje ista. Primjer s Redisom:

Terminal
docker run -d --name cache --restart unless-stopped -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

postaje:

Terminal
container volume create redisdata
container run -d --name cache -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

Najprije stvorite imenovani volumen naredbom container volume create. Uklonite --restart i zaokružite --cpus na cijeli broj. --platform radi kao u Dockeru.

Kopiranje kontejnera kao naredbe

Radi i obrnuto. Desnom tipkom kliknite kontejner ili upotrijebite izbornik Više i odaberite Kopiraj kao naredbu: Gantry zapisuje redak docker run ili container run. Izostavlja zadane vrijednosti slike, kao što su njezino okruženje i naredba, pa redak ostaje kratak. Radi i za zaustavljene kontejnere.

Spremanje kao recept

U prozoru Novi kontejner otvorite Recepti i odaberite Spremi kao recept…. Sljedeći put Ispuni iz recepta daje isti obrazac na bilo kojem hostu. Recepti su u ~/Library/Application Support/Gantry/recipes.json, pa ih možete sigurnosno kopirati ili podijeliti.

Ograničenja

  • Gantry zadržava putanju iz --env-file, ali ne čita datoteku, a za -e KEY bez vrijednosti ne čita vašu ljusku.
  • tmpfs montiranja i anonimni volumeni iz --mount navode se kao nepodržani.
  • Dva porta za isti port kontejnera (-p 8080:80 -p 8081:80) ispunjavaju obrazac, ali obrazac zatim odbija duplikat.

Pitanja i odgovori

Kako pretvoriti docker run u container run?

Zamijenite docker run s container run. -d, -p, -e, -v, --name, --rm, -it, -w i --entrypoint ostaju isti. Uklonite --restart i koristite cijele CPU-ove. Ili zalijepite redak u Gantry i pustite ga da ispuni obrazac.

Može li Gantry uvesti naredbu docker run?

Da. Zalijepi naredbu… u prozoru Novi kontejner čita docker run, docker create, podman run i container run i ispunjava obrazac.

Što se događa sa zastavicama koje Gantry ne podržava?

Navode se u pretpregledu s razlogom i ostaju u obrascu u odjeljku Iz zalijepljene naredbe, pa ih možete kasnije provjeriti.

Mogu li pokrenuti kontejner pretvoriti natrag u naredbu docker run?

Da. Kopiraj kao naredbu u izborniku kontejnera zapisuje redak docker run ili container run za taj kontejner.
