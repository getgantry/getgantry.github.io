Gantry/Průvodce apple/container

Apple container na Macu: kompletní průvodce a GUI

apple/container spouští linuxové kontejnery na vašem Macu, každý ve vlastním odlehčeném virtuálním stroji. Dodává se jako nástroj příkazového řádku. Gantry je pro něj nativní GUI pro macOS. Tento průvodce vysvětluje, co nástroj umí, jak ho nastavit a která funkce Gantry pokrývá jednotlivé příkazy container.

Ve zkratce. Gantry je bezplatná open-source (MIT) aplikace pro macOS, která z jednoho okna spravuje nástroj container od Applu i Docker. Podporuje CLI container 1.0 až 1.7.1 (doporučeno) a zobrazuje jen funkce, které vaše verze CLI podporuje. Nainstalujte ji příkazem brew install --cask getgantry/tap/gantry.

Co je apple/container?

apple/container je open-source nástroj od Applu napsaný ve Swiftu, který vytváří a spouští linuxové kontejnery na Macu. Docker Desktop spouští všechny kontejnery v jednom sdíleném linuxovém virtuálním stroji; apple/container spouští každý kontejner ve vlastním odlehčeném virtuálním stroji postaveném na frameworku Virtualization od Applu. Používá standardní image OCI, takže stahuje ze stejných registrů jako Docker a odesílá do nich.

  • Hardware: Mac s Apple silicon.
  • macOS: Apple ho podporuje na macOS 26.
  • Rozhraní: jen CLI container. Neexistuje desktopová aplikace ani příkaz compose.
  • Síť: každý kontejner dostane na vašem Macu vlastní IP adresu a místní domény DNS dávají kontejnerům názvy jako web.test.

Proč používat GUI pro apple/container?

CLI je kompletní, ale každodenní práce znamená spoustu příkazů: container list, logs, stats, exec a na zbytek system, builder, registry, machine a cluster. Gantry je soustředí do jednoho okna s živými aktualizacemi, takže stav vidíte a nemusíte se na něj neustále dotazovat. Přidává i to, co CLI nemá: soubory Compose, oznámení o selhání, přehled flotily s vašimi hostiteli Docker a server MCP pro AI agenty.

Nastavení apple/container s Gantry

  1. Nainstalujte Gantry: brew install --cask getgantry/tap/gantry a pak odstraňte příznak karantény (viz Instalace).
  2. Nainstalujte CLI container z podepsaného balíčku .pkg na stránce vydání apple/container. Pokud chybí nebo je starší než 1.0, Gantry zobrazí list s postupem instalace.
  3. V Gantry zvolte Přidat hostitele… a přidejte hostitele Apple Container. Při připojení se spustí služby container, pokud jsou zastavené.
  4. Pokud není nainstalováno výchozí jádro, přehled hostitele zobrazí banner. Klikněte na něj a nainstalujte doporučené jádro.
Pozor
Použijte podepsaný instalační balíček, ne build z Homebrew. Build z Homebrew neobsahuje backend strojů a ve verzi 1.7.1 ani služby clusteru, takže container machine a container cluster nefungují.

Co Gantry přidává k apple/container

Clustery Kubernetes

Vytvářejte clustery Kubernetes pomocí container cluster, nastavte velikost pracovních uzlů, nechte pody používat vaše místní image, zvolte CNI a sledujte každý uzel. Pak cluster procházejte v prohlížeči Kubernetes v Gantry. Viz Kubernetes na apple/container a podrobný návod Kubernetes na Macu.

Stroje container a VS Code

Stroje jsou dlouhodobá linuxová prostředí z container machine. Gantry je vytváří, spouští, zastavuje a maže, nastavuje výchozí stroj, upravuje CPU a paměť a otevírá shell. Od CLI 1.1 může stroj nastartovat s vnořenou virtualizací (Apple silicon M3 nebo novější) a vlastním jádrem. Otevřít ve VS Code se připojí k běžícímu stroji přes Remote-SSH; v image stroje musí běžet sshd.

Docker Compose na apple/container

Otevřete docker-compose.yml z Finderu (Otevřít v aplikaci ▸ Gantry nebo Rychlé akce ▸ Compose Up v apple/container), z nabídky Soubor ▸ Otevřít soubor Compose… nebo přetažením do okna. Gantry sestaví služby s build:, vytvoří síť projektu a pojmenované svazky a spustí služby v pořadí podle depends_on se standardními štítky com.docker.compose.*. Když je nastavena výchozí doména DNS, služby se navzájem najdou podle názvu služby přes síťové aliasy.

Aliasy DNS v síti a místní domény

Gantry předává síťové aliasy do container jako --network <name>,alias=…. Bez výchozí domény DNS projdou jen plně kvalifikované názvy a alias podstromu (s tečkou na začátku, například .gateway) projde jen jako přesný alias. S výchozí doménou fungují i krátké názvy. Gantry vytváří a maže místní domény DNS, nastavuje výchozí doménu a novým kontejnerům přiděluje název hostitele name.domain. Viz Místní názvy DNS.

Systém: služby, builder, registry, jádro, logy, vlastnosti

Každý hostitel apple/container má sekci Systém. Funguje i tehdy, když je hostitel odpojený, takže z ní můžete spustit zastavené služby.

  • Stav a verze: verze klienta a serveru s upozorněním, když se liší; spuštění, zastavení a restart služeb; údaje o hostiteli a cesty.
  • Builder imagů: stav, image, CPU, paměť a IP; spuštění s možnostmi CPU, paměti a DNS; zastavení; smazání. Karta upozorní, když je image builderu zastaralý, a vytvoří ho znovu.
  • Přihlášení k registrům: výpis, přihlášení a odhlášení. Heslo jde do CLI výhradně přes stdin (--password-stdin) a Gantry si žádnou kopii neponechává.
  • Jádro: instalace doporučeného jádra, souboru jádra nebo archivu tar s průběhem v reálném čase.
  • Logy služeb: živě nebo jednorázově, za posledních 5 minut až 1 den, filtrované podle úrovně, služby a textu.
  • Systémové vlastnosti: úpravy se ukládají do ~/.config/container/config.toml, s příznakem čekajícího restartu a tlačítkem Restartovat služby. V CLI 1.7 mají jmenné servery, vyhledávací domény a možnosti [container.dns] editor seznamu.

Uložení jako image, Zmenšit disk a soubory

Uložit jako image používá container commit (CLI 1.6). Zmenšit disk používá container clean (CLI 1.4) a zobrazuje se i jako řádek v panelu Uvolnit místo. Karta Soubory ukládá soubory do Macu a umožňuje je přetáhnout do Finderu pomocí container copy (kontejner musí být spuštěný) a také nahrává soubory a složky.

Štítky se znakem =

container create odmítá hodnotu štítku se znakem =, a to i v CLI 1.6.1. Gantry takové hodnoty při vytváření kontejneru zakóduje a při zpětném čtení dekóduje, takže vidíte přesně ty štítky, které jste nastavili.

Server MCP a Zkratky

Vestavěný server gantry-mcp dává AI agentům na hostitelích apple/container stejné možnosti: kontejnery, image, svazky, sítě, Compose, stroje (list_machines, create_machine a další), clustery (list_clusters, create_cluster, delete_cluster) a systémové nástroje apple_* pro služby, builder, registry (bez nástroje pro přihlášení), vlastnosti, logy a instalaci jádra. App Intents přidávají akce pro Zkratky a Siri. Viz AI agenti a MCP.

Přidání serveru MCP Gantry
claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp

apple/container vedle Dockeru

Gantry spravuje hostitele apple/container, místního démona Dockeru (Docker Desktop, OrbStack, Colima) a vzdálené hostitele Docker přes SSH v jednom postranním panelu a jednom přehledu flotily. Nemusíte si vybírat jedno běhové prostředí. Srovnání nástrojů funkci po funkci najdete na stránce Gantry vs. Docker Desktop, OrbStack a Podman Desktop. Jak přenést svou práci, popisuje průvodce Z Docker Desktop na Apple container.

Otázky a odpovědi

Jaké je nejlepší GUI pro Apple container?

Gantry je bezplatné nativní open-source GUI pro macOS, vytvořené pro apple/container. Převádí CLI container do desktopové aplikace: kontejnery, logy, statistiky a exec, a k tomu clustery Kubernetes, stroje, builder imagů, přihlášení k registrům, jádra, logy služeb a systémové vlastnosti. Tabulka na této stránce uvádí každý příkaz a funkci Gantry, která ho používá.

Má Apple container GUI?

Apple dodává container jen jako nástroj příkazového řádku. Gantry je samostatná open-source aplikace, která mu dává GUI, hned vedle vašich hostitelů Docker.

Jde používat docker compose s Apple container?

apple/container nemá příkaz compose. Gantry načte docker-compose.yml, sestaví služby s build:, vytvoří síť a pojmenované svazky a spustí služby v pořadí podle depends_on. Názvy služeb se překládají přes aliasy DNS v síti.

Jak otevřít stroj container ve VS Code?

Spusťte stroj v Gantry a klikněte na Otevřít ve VS Code. Gantry ho otevře přes Remote-SSH, stejně jako v ukázce container-machine-vscode od Applu. V image stroje musí běžet sshd.

Funguje Apple container na Macu s Intelem?

Ne. apple/container vyžaduje Mac s Apple silicon. Gantry běží i na Macích s Intelem, tam ale spravuje jen hostitele Docker.

Kterou verzi CLI container nainstalovat?

Gantry vyžaduje verzi 1.0 nebo novější a doporučuje 1.7.1. Nainstalujte ji z podepsaného instalačního balíčku ze stránky vydání apple/container. Build z Homebrew neobsahuje backend strojů ani, ve verzi 1.7.1, služby clusteru, takže container machine a container cluster s ním nefungují.
