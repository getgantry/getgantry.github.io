Mac-програма для Apple container і Docker

Gantry — безплатна програма для Mac з відкритим кодом для інструмента container від Apple і для Docker, локально й через SSH. Контейнери, кластери Kubernetes, машини й проєкти Compose на apple/container — в одному вікні, поруч із вашими хостами Docker. Безплатна альтернатива Docker Desktop і OrbStack для Mac.

Завантажити для macOS
$ brew install --cask getgantry/tap/gantry

Gantry 0.29.0 · macOS 26+ · Apple silicon та Intel · ліцензія MIT · 28 мов · сервер MCP у комплекті

Контейнери

Створюйте, запускайте, відкривайте й змінюйте контейнери на кожному хості.

  • container run
  • docker exec -it
  • docker cp
  • docker port
Вставте docker run
Вставте команду docker run, podman run або container run, і Gantry заповнить форму нового контейнера та покаже прапорці, які не може використати. Будь-який контейнер можна скопіювати назад як команду або зберегти як шаблон. Як це працює
Вбудований термінал exec
Повноцінна емуляція термінала в будь-якому запущеному контейнері, локальному чи віддаленому, — з колірними темами (System, Solarized, Dracula, Nord).
Файловий браузер із перетягуванням
Переглядайте файлову систему контейнера, переносьте файли туди й назад і перетягуйте цілі папки просто з Finder — на хостах Docker і apple/container.
Відкрити в браузері й переадресувати
Одне клацання відкриває опублікований порт. Порти SSH-хостів автоматично переадресовуються на localhost, а якщо порт зайнятий, Gantry вибере вільний, який можна змінити.
Опублікувати в інтернеті
Одне клацання — і опублікований порт доступний через Cloudflare Tunnel. Gantry сам інсталює cloudflared, а потім дасть швидкий тунель (без облікового запису, URL-адреса *.trycloudflare.com) або іменований тунель на вашому домені. Зручно для попереднього перегляду під час розробки, вебхука або щоб ШІ-агент дістався до контейнера на вашому Mac.
Секрети з В’язки ключів у середовищі
Зберігайте паролі й токени у В’язці ключів macOS (Параметри → Секрети) і використовуйте їх як змінні середовища у вікнах «Новий контейнер» і «Швидкий запуск». Форма показує keychain:NAME, а не значення, і Gantry читає значення лише під час створення контейнера. Експорт у Compose, шаблони й «Скопіювати як команду» записують назву, а не значення.
Дії з багатьма одразу
Виберіть кілька контейнерів, образів, томів чи мереж і запустіть, зупиніть, перезапустіть або вилучіть їх за один крок, з перебігом виконання та звітом для кожного об’єкта.
Статистика в реальному часі
CPU, пам’ять, мережа й дисковий ввід-вивід на живих графіках із вимірюванням щосекунди.
Контейнери на зовнішньому диску
Перенесіть усі дані apple/container на зовнішній диск, зберігайте томи на вибраному диску й отримуйте зрозуміле попередження, якщо цей диск не під’єднано. Читати посібник

Образи й збірки

Завантажуйте, збирайте, скануйте й видаляйте образи.

  • docker build
  • docker pull
  • trivy image
  • docker system prune
Збірка й отримання образів
Перетягніть Dockerfile у вікно, щоб зібрати образ із живим журналом, або отримайте образ за назвою з відображенням перебігу для кожного шару. Додавайте теги, вилучайте невикористані образи, переглядайте історію шарів. Позначка вказує на образи, зібрані для іншої архітектури CPU, ніж у хоста.
Історія збірок
Кожен хост має розділ Збірки: збірки з кроками, влученнями в кеш і журналом. Gantry зберігає збірки, які запускає сам, з назвами аргументів збірки, але без їхніх значень. На хостах Docker він також читає docker buildx history (buildx 0.23.0 або новіший). apple/container не зберігає історії збірок, тож там видно збірки, які запустив Gantry.
Перевірка образів з Trivy або Grype
Виберіть Перевірити на вразливості… для образу. Gantry запускає інстальований вами Trivy (0.50.0 або новіший) чи Grype (0.74.0 або новіший), наприклад через Homebrew, і групує знахідки за рівнем: від критичного до невідомого. Експортувати SBOM записує CycloneDX, а з Trivy — також SPDX. Це працює на apple/container, локальному Docker і Docker через SSH; на Docker через SSH Gantry перевіряє копію образу з тегом у реєстрі.
Приватні реєстри
Під час отримання образів використовується docker login, який ви вже виконали: Gantry бере облікові дані з ~/.docker/config.json, помічників облікових даних і В’язки ключів — під час створення контейнера, у «Швидкому запуску» та в Compose.
Звільнити місце
Одна панель показує, що займає місце, — образи без тегів, зупинені контейнери, невикористані томи, кеш збірки — із розмірами, і вилучає кожну категорію або все одразу. На apple/container вона також виконує «Стиснути диск».

Compose

Запускайте docker-compose.yml у Docker або в apple/container і створюйте його із запущених контейнерів.

  • docker compose up -d
  • docker compose down
  • docker compose logs -f
Compose на кожному хості
Контейнери групуються за проєктами Compose. Запускайте файл compose на будь-якому хості — у локальному Docker, через SSH чи в apple/container — із вбудованим редактором YAML; запуск підлаштовується під рушій.
Експорт у Compose
Виберіть Експортувати як Compose… для одного чи кількох контейнерів і отримайте docker-compose.yml з портами, монтуваннями, мережами, політикою перезапуску, перевіркою стану, обмеженнями тощо. Значення, схожі на секрети, стають ${NAME}, якщо ви не включите їх у файл. На хостах apple/container Gantry попереджає про прапорці, які Compose не може виразити. Як це працює

Kubernetes

Переглядайте кожен контекст kubeconfig або створюйте кластер в apple/container.

  • kubectl get pods -A
  • kubectl logs -f
  • kubectl port-forward
  • container cluster
Браузер Kubernetes
Переглядайте поди, Deployments, StatefulSets, DaemonSets, сервіси, Ingress, ConfigMaps, секрети, вузли й події будь-якого контексту kubeconfig. Стежте за журналами подів, відкривайте оболонку, переадресовуйте порт, масштабуйте, перезапускайте розгортання й застосовуйте YAML. Gantry сам звертається до API Kubernetes, тож кластер, створений командою container cluster create, можна переглядати одразу, нічого більше не інсталюючи: kubectl не потрібен.
Кластери Kubernetes
Створюйте кластер Kubernetes командою container cluster: задавайте розмір вузла керування й робочих вузлів окремо, вибирайте CNI і переглядайте вузли, версію Kubernetes і контекст kubeconfig. Вузли кластера захищено від випадкової зупинки й видалення. Докладніше

Хости й парк

Цей Mac, хости Docker через SSH і apple/container на одній панелі.

  • docker -H ssh://user@host
  • docker context use
  • docker stats
Одна панель для всіх хостів
Локальний демон, SSH-хости й apple/container на одному екрані: спарклайни CPU й пам’яті в реальному часі, розподіл контейнерів за станами та проблеми зі станом, які ведуть просто до винуватця.
Віддалені хости через SSH
Тунель точно як у docker -H ssh:// через dial-stdio: бастіони ProxyJump, автентифікація кількома ключами, автоматичне перепід’єднання. На сервер нічого не треба інсталювати, секрети — у В’язці ключів. Імпорт одним клацанням із ~/.ssh/config і docker context ls.
Використання ресурсів на всіх хостах
Одна таблиця із сортуванням для запущених контейнерів на кожному під’єднаному хості: хост, назва, образ, CPU, пам’ять, мережевий і дисковий ввід-вивід, час роботи. Фільтруйте за назвою, образом або хостом чи покажіть один хост. Двічі клацніть рядок, щоб відкрити контейнер. Таблиця використовує вимірювання, які Gantry і так робить кожні 5 секунд, тому не відкриває нових потоків статистики. Відкрийте її з бокової панелі, через ⌘K або за посиланням gantry://open/usage.

Журнали й збої

Читайте, шукайте й експортуйте журнали. Знаходьте причину, коли контейнер дає збій.

  • docker logs -f
  • container logs
  • docker events
Журнали в реальному часі
Стеження в реальному часі, пошук за regex або текстом через ⌘F, фільтр за рівнем (Error→Trace), кольори ANSI, буфер на 50 тис. рядків — і об’єднані журнали стека для всього проєкту Compose.
Експорт журналів
Експортувати журнали… (⇧⌘E) зберігає видимі рядки з урахуванням фільтра за рівнем, пошуку й періоду у файл .log або .txt. Скопіювати видимі рядки копіює їх. На хостах Docker можна додати час і показати лише останні записи: від 5 хвилин до доби.
Сповіщення про збої
Нативне сповіщення, коли контейнер на будь-якому хості аварійно завершує роботу, вичерпує пам’ять або стає несправним. Клацніть його, щоб одразу перейти до контейнера, — про зупинки, які ви виконали самі, сповіщень немає.
«Пояснити збій» з Apple Intelligence
Виберіть Пояснити збій… для контейнера, що зазнав збою, або для невдалої операції. Gantry надсилає моделі на пристрої останні журнали й відомості, з яких вилучено значення змінних середовища й текст, схожий на секрети, і показує ймовірну причину, докази й подальші кроки. Довгі журнали можуть надсилатися в Private Cloud Compute (macOS 27). Панель показує, що саме надіслано.
Знімки екрана в «Пояснити збій»
Перетягніть, вставте або додайте до 3 зображень у «Пояснити збій», наприклад знімок екрана зі сторінкою помилки. Зображення залишаються на цьому Mac: їх читає лише модель на пристрої (macOS 27), ніколи не Private Cloud Compute.

macOS

Смуга меню, сповіщення, Spotlight, «Швидкі команди» і клавіатура.

  • ⌘K
  • ⌥⌘P
  • ⇧⌘E
Частина macOS
Сповіщення з діями «Перезапустити», «Показати журнали» і «Скопіювати як запит». Spotlight знаходить контейнери, проєкти Compose і хости. Дії для Siri і «Швидких команд», віджет стану парку хостів, елементи керування в Центрі керування для служб apple/container або вибраного контейнера та посилання gantry:// для скриптів.
Перебіг у смузі меню
Панель у смузі меню показує кожне поточне отримання, збірку й операцію Compose: індикатор перебігу, готові шари або служби, байти, час і кнопку Скасувати. Значок у смузі меню показує, скільки операцій виконується. Кожен проєкт Compose має Отримати образи і Зупинити Compose; «Зупинити Compose» зберігає томи й образи.
Палітра команд
Натисніть ⌘K і почніть вводити. Один пошук охоплює контейнери, проєкти Compose, образи, томи, мережі, машини, кластери й хости, з діями на кшталт «Запустити», «Показати журнали» і «Відкрити оболонку».
Touch ID для небезпечних дій
Увімкніть цю функцію, і Gantry запитуватиме Touch ID або пароль входу перед вилученням контейнера чи видаленням хоста. Секрети й так зберігаються у В’язці ключів.
Теми термінала
Оформіть вбудовану оболонку в стилі System, Solarized Dark, Dracula або Nord: повна палітра переднього плану, тла й 16 кольорів ANSI застосовується одразу.

Нативний GUI для Apple container на macOS

Інструмент container від Apple запускає контейнери Linux як легкі віртуальні машини на Apple silicon, але постачається лише як інструмент командного рядка. Gantry — настільна програма для нього: чим Docker Desktop є для Docker, тим Gantry є для container. Він підтримує всі версії CLI container від 1.0 до рекомендованої 1.7.1 і вмикає кожну функцію, лише якщо її підтримує інстальований CLI.

  • container system start
  • container machine
  • container builder start
  • container registry login
Контейнери, журнали, статистика й exec
Створення, запуск, зупинка, примусове завершення й очищення; журнали та статистика в реальному часі, термінал exec, top і експорт у tar — у тому самому інтерфейсі, що й для хостів Docker.
Кластери Kubernetes
Створюйте кластер Kubernetes командою container cluster: задавайте розмір вузла керування й робочих вузлів окремо, вибирайте CNI і переглядайте вузли, версію Kubernetes і контекст kubeconfig. Вузли кластера захищено від випадкової зупинки й видалення. Докладніше
Локальні образи в кластері
У CLI 1.7 увімкніть Використовувати локальні образи (--shared-image-store), і поди запускатимуть образи, які ви зібрали чи отримали, без реєстру. У CLI 1.5 і 1.6 клацніть образ правою кнопкою й виберіть Імпортувати в кластер.
Зрозумілі підказки, якщо інсталяцію пошкоджено
Якщо служби кластера не відповідають, Gantry пояснює чому. Для збірки Homebrew без служб кластера він дає посилання на підписаний інсталятор, в інших випадках — кнопку Перезапустити служби.
Машини container у VS Code
Створюйте, запускайте й зупиняйте Linux-середовища container machine, задавайте CPU і пам’ять, відкривайте оболонку або саму машину у VS Code через Remote-SSH.
Вкладена віртуалізація та власні ядра
Завантажуйте машину з вкладеною віртуалізацією (M3 або новіший) чи з власним ядром. Запускайте контейнери з власним ядром і додатковими параметрами завантаження.
Compose для Apple container
В apple/container немає compose. Gantry запускає ваш docker-compose.yml: збирає образи, створює мережу й томи та запускає служби в порядку depends_on. Імена служб розв’язуються через мережеві DNS-псевдоніми.
Мережеві DNS-псевдоніми
Псевдоніми контейнерів, псевдоніми піддерев на кшталт .gateway і короткі імена, якщо задано типовий DNS-домен. Кожен контейнер отримує маршрутизовану IP-адресу та ім’я хоста name.domain.
Керування збирачем образів
Стан збирача, його образ, CPU, пам’ять і IP. Запуск із параметрами CPU, пам’яті й DNS, зупинка й видалення. Якщо образ збирача застарів, Gantry запропонує створити його заново.
Входи в реєстри
Перегляд, додавання й вилучення входів container registry. Пароль передається в CLI лише через stdin, і Gantry не зберігає його копії.
Інсталяція ядра
Інсталяція рекомендованого ядра, файлу ядра або tar-архіву з відображенням перебігу в реальному часі. Gantry попередить, якщо типове ядро не інстальовано.
Служби та журнали служб
Запускайте, зупиняйте й перезапускайте служби container, порівнюйте версії клієнта й сервера та переглядайте журнали служб у реальному часі з фільтром за рівнем, службою й текстом.
Редактор системних властивостей
Редагуйте системні властивості container у config.toml. Gantry позначає зміни, які потребують перезапуску, і сам перезапускає служби. У CLI 1.7 він також редагує типові значення [container.dns]: DNS-сервери, домени пошуку й параметри.
Зберегти як образ і стиснути диск
Збережіть контейнер як образ (container commit) і звільніть місце на диску командою Стиснути диск (container clean) — вона є й на панелі «Звільнити місце».
Файловий браузер: вивантаження й завантаження
Переглядайте файли контейнера, завантажуйте їх або перетягуйте у Finder (container copy), а файли й цілі папки перетягуйте всередину.
Швидкий запуск і Finder
Виберіть образ, надайте доступ до папки, переадресуйте порти, виберіть домен — і запускайте. У Finder клацніть файл compose правою кнопкою й відкрийте його в Gantry.
Мітки, що містять =
CLI container відхиляє значення міток із =. Gantry кодує їх під час створення й декодує під час читання, тож значення на кшталт a=b лишається цілим.
Один парк, два середовища виконання
Хости apple/container стоять поруч із локальним Docker і SSH-хостами на одній панелі — з тими самими спарклайнами, станом і сповіщеннями про збої.

Запитання

Який GUI для Apple container найкращий?

Gantry — безплатний нативний GUI для macOS з відкритим кодом, створений для інструмента container від Apple (apple/container). Він охоплює життєвий цикл контейнерів, журнали, статистику й термінал exec, а також ті частини CLI, до яких не доходять інші GUI: кластери Kubernetes (container cluster), машини container, збирач образів, вхід у реєстри, ядра, журнали служб і системні властивості. Він підтримує CLI від 1.0 до 1.7.1 і вмикає кожну функцію, лише якщо її підтримує ваш CLI. Див. посібник з apple/container.

Що таке Apple container (apple/container)?

apple/container — інструмент Apple з відкритим кодом для запуску Linux-контейнерів на Mac. Кожен контейнер працює у власній легкій віртуальній машині на основі фреймворку Virtualization від Apple. Йому потрібен Mac з Apple silicon, а постачається він як утиліта командного рядка container, без програми з графічним інтерфейсом. Таку програму додає Gantry.

Чи підтримує Gantry container cluster і Kubernetes?

Так. На хості apple/container Gantry створює й видаляє кластери Kubernetes командою container cluster (CLI 1.6.1 і 1.7; у CLI від 1.5.0 до 1.6.0 — container k8s). Ви вибираєте назву, робочі вузли, CPU і пам’ять вузла керування та робочих вузлів (1.7), образ вузла, CNI і те, чи використовують вузли ваші локальні образи (1.7). Gantry показує вузли, записує kubeconfig і відкриває кластер у своєму браузері Kubernetes. Див. Kubernetes на apple/container.

Чи можна використовувати docker compose з Apple container?

Так. В apple/container немає команди compose, тож оркестрацію поверх CLI container бере на себе Gantry: збирає служби з build:, створює мережу проєкту та іменовані томи й запускає кожну службу в порядку depends_on зі стандартними мітками Compose. Імена служб розв’язуються через мережеві DNS-псевдоніми. Відкрийте docker-compose.yml із Finder, через меню «Файл» або перетягніть його у вікно.

Як відкрити машину container у VS Code?

Запустіть машину в Gantry і натисніть Відкрити у VS Code. Gantry відкриє машину у VS Code через Remote-SSH, як у прикладі Apple container-machine-vscode. В образі машини має працювати sshd, а VS Code з розширенням Remote-SSH має бути інстальовано.

Які версії apple/container підтримує Gantry?

Gantry потрібен CLI container версії 1.0 або новішої, рекомендовано 1.7.1. Gantry визначає інстальовану версію й показує лише ті функції, які вона підтримує, наприклад розміри робочих вузлів і спільне сховище образів (1.7), commit (1.6) і «Стиснути диск» (1.4). Якщо CLI немає або він застарів, Gantry запропонує покрокове налаштування.

Чи може Gantry переглядати кластер Kubernetes?

Так. Розділ Kubernetes показує поди, Deployments, StatefulSets, DaemonSets, сервіси, Ingress, ConfigMaps, секрети, вузли й події кожного контексту kubeconfig. У ньому є журнали подів, оболонка в поді, переадресація портів, масштабування, перезапуск розгортання, видалення й «Застосувати YAML». Gantry сам звертається до API Kubernetes, тому kubectl не потрібен. Див. Kubernetes на Mac.

Що «Пояснити збій» надсилає в Apple Intelligence?

Останні журнали й відомості про контейнер, з яких вилучено значення змінних середовища й текст, схожий на секрети. Невеликі запити обробляє модель на пристрої. Якщо ввімкнено параметр для довгих журналів (macOS 27), довгі журнали надсилаються в Private Cloud Compute. Панель показує, що саме надіслано. Запропонована команда відкривається в Терміналі, але не виконується, доки ви не натиснете Return. Без Apple Intelligence Gantry пропонує запит, який можна скопіювати в інший ШІ-асистент.

Чи можна вставити команду docker run у Gantry?

Так. У вікні створення контейнера виберіть Вставити команду…. Gantry розпізнає docker run, docker create, podman run і container run, заповнює форму й перелічує прапорці, які не може використати, з причиною для кожного. Див. Створення контейнера з команди docker run.

Чи може Gantry керувати збирачем, реєстрами та ядром apple/container?

Так. Розділ «Система» хоста apple/container запускає, зупиняє й видаляє збирач образів із параметрами CPU, пам’яті та DNS; показує, додає й вилучає входи в реєстри (пароль передається в CLI лише через stdin); інсталює рекомендоване ядро, файл ядра або tar-архів; транслює журнали служб і редагує системні властивості в config.toml.

Чи є Gantry альтернативою Docker Desktop, OrbStack або Podman Desktop?

Як GUI — так. Gantry — безплатна нативна програма для macOS для керування контейнерами, образами, томами, мережами, журналами й статистикою. Це клієнт, а не рушій: він працює з демоном Docker, який у вас уже запущено (Docker Desktop, OrbStack, Colima), або з інструментом container від Apple і додає перегляд кількох хостів в одному вікні, SSH-хости та сервер MCP. Див. порівняння.

Gantry безплатний?

Так. Gantry безплатний, його код відкритий за ліцензією MIT. Немає підписки, облікового запису й обмежень на кількість хостів чи контейнерів.

Що потрібно для роботи Gantry?

macOS 26 або новіша на Apple silicon чи Intel, а також демон Docker (Docker Desktop, OrbStack, Colima або подібний) чи інструмент container від Apple. Самому apple/container потрібен Apple silicon, тож на Mac з Intel Gantry керує лише хостами Docker.

Чи працює Gantry з OrbStack, Colima і Docker Desktop?

Так. Gantry звертається безпосередньо до Docker Engine API через Unix-сокет, тож працює з будь-яким демоном, що його надає, зокрема з OrbStack, Colima і Docker Desktop.

Чи може Gantry керувати віддаленими хостами Docker?

Так. Gantry під’єднується до віддалених демонів через SSH так само, як docker -H ssh://, із бастіонами через ProxyJump, автентифікацією кількома ключами й автоматичним перепід’єднанням. На сервер нічого не треба інсталювати, а секрети зберігаються у В’язці ключів macOS.

Чи повідомить Gantry про збій контейнера?

Так. Gantry надсилає сповіщення macOS, коли контейнер на будь-якому хості — локальному, SSH чи apple/container — аварійно завершує роботу, вичерпує пам’ять або не проходить перевірку стану. Клацніть сповіщення, щоб перейти до контейнера. Про зупинки й перезапуски, які ви виконуєте в Gantry, сповіщень немає, а самі сповіщення можна вимкнути в параметрах.

Чи може Gantry отримувати образи з приватних реєстрів?

Так. На хостах Docker Gantry бере облікові дані з ~/.docker/config.json (той самий docker login, який ви вже виконали), зокрема вбудовані дані auth, помічники облікових даних (credential helpers) і В’язку ключів macOS. На хостах apple/container він керує входами container registry.

Чи може Gantry відкрити доступ до локального контейнера з інтернету?

Так. Клацніть опублікований порт — і він стане доступним через Cloudflare Tunnel. Gantry за потреби інсталює cloudflared, а потім запускає швидкий тунель (без облікового запису Cloudflare, тимчасова URL-адреса на trycloudflare.com) або іменований тунель із вашим власним іменем хоста. Публічна URL-адреса з’являється під портом із кнопками для відкриття, копіювання й зупинки.

Gantry написано на Electron?

Ні. Gantry — нативна програма на SwiftUI та Swift 6. Інтерфейс доступний 28 мовами: англійською, спрощеною китайською та 26 європейськими мовами, наприклад сербською кирилицею й латиницею. Він відповідає мові системи macOS.

Як інсталювати Gantry?

Виконайте brew install --cask getgantry/tap/gantry або завантажте останній реліз із GitHub і перетягніть Gantry.app у папку «Програми».

Чи можуть ШІ-агенти керувати Gantry?

Так. Gantry містить сервер MCP і App Intents для macOS, тож Claude, «Швидкі команди», Siri і скрипти отримують ті самі можливості, що й GUI, на кожному хості, зокрема на хостах SSH: контейнери, образи, томи, мережі, Compose, машини apple/container, кластери Kubernetes, системні інструменти apple_* (служби, збирач, реєстри, властивості, журнали, ядро) і публікацію портів. У macOS 26 і новіших Пояснити збій… також запитує Apple Intelligence, чому контейнер зазнав збою. Додайте сервер MCP командою claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp.
