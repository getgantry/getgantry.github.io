Gantry/Iš docker run

Konteinerio kūrimas iš docker run komandos

Daugumoje README failų pateikiama docker run eilutė. Gantry nuskaito šią eilutę ir užpildo naujo konteinerio formą – Docker serveriui arba Apple container įrankiui. Šiame vadove parodyta, kaip tai veikia ir kaip konvertuoti komandą rankiniu būdu.

Trumpai. Gantry atidarykite Naujas konteineris, pasirinkite Įklijuoti komandą…, įklijuokite docker run eilutę ir spustelėkite Užpildyti formą. Gantry išvardija kiekvieną vėliavėlę, kurios negali panaudoti, su priežastimi. CLI dauguma vėliavėlių tokios pačios: pakeiskite docker run į container run ir pašalinkite --restart.

Komandos įklijavimas į Gantry

  1. Pasirinkite serverį: Docker serverį arba apple/container serverį.
  2. Atidarykite Konteineriai ir spustelėkite Naujas konteineris.
  3. Spustelėkite Įklijuoti komandą… ir įklijuokite eilutę. Eilučių pabaigos su \, kabutės, $ raginimas ir sudo netrukdo.
  4. Peržiūrėkite: atvaizdas, vėliavėlės, kurių Gantry negali panaudoti, pastabos ir įspėjimai šiam serveriui.
  5. Spustelėkite Užpildyti formą, patikrinkite reikšmes ir sukurkite konteinerį.

Gantry supranta docker run, docker container run, docker create, podman run ir container run. Tekstas po &&, ||, ; ar | ignoruojamas, apie tai pateikiama pastaba.

Žinoma dar apie 80 kitų Docker vėliavėlių: Gantry teisingai praleidžia jų reikšmes ir pažymi jas kaip nepanaudotas, todėl niekas neprarandama be pastabos.

    Įspėjimai apple/container serveriams

Kai kurių Docker parinkčių apple/container nėra. Gantry apie jas įspėja ir neįtraukia jų į kūrimo užklausą:

  • paleidimo iš naujo politikos (--restart);
  • CPU dalys, pavyzdžiui, --cpus 0.5;
  • tinklo režimai host, none ir container:;
  • prievadai be serverio prievado, pavyzdžiui, -p 80.

Docker serveryje Gantry įspėja apie apple/container parinktis: DNS domeną ir branduolio parinktis.

    docker run konvertavimas į container run rankiniu būdu

CLI dauguma vėliavėlių lieka tokios pačios. Redis pavyzdys:

Terminalas
docker run -d --name cache --restart unless-stopped -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

tampa:

Terminalas
container volume create redisdata
container run -d --name cache -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

Pirmiausia sukurkite vardinį tomą su container volume create. Pašalinkite --restart ir suapvalinkite --cpus iki sveikojo skaičiaus. --platform veikia kaip Docker.

    Konteinerio kopijavimas kaip komandos

Veikia ir atvirkščiai. Dešiniuoju pelės klavišu spustelėkite konteinerį arba atidarykite meniu „Daugiau“ ir pasirinkite Kopijuoti kaip komandą: Gantry parašo docker run arba container run eilutę. Atvaizdo numatytųjų reikšmių, pavyzdžiui, jo aplinkos ir komandos, ji neįtraukia, todėl eilutė lieka trumpa. Tai veikia ir su sustabdytais konteineriais.

    Įrašymas kaip recepto

Naujo konteinerio lange atidarykite Receptai ir pasirinkite Įrašyti kaip receptą…. Kitą kartą Užpildyti pagal receptą bet kuriame serveryje pateiks tą pačią formą. Receptai saugomi faile ~/Library/Application Support/Gantry/recipes.json, todėl galite juos kurti atsargines kopijas ar bendrinti.

    Apribojimai
  • Gantry išsaugo --env-file kelią, bet failo neskaito, o -e KEY be reikšmės neima reikšmės iš jūsų apvalkalo.
  • tmpfs prijungimai ir anoniminiai tomai iš --mount pažymimi kaip nepalaikomi.
  • Du prievadai tam pačiam konteinerio prievadui (-p 8080:80 -p 8081:80) užpildo formą, bet forma tada atmeta dublikatą.

Klausimai ir atsakymai

Kaip konvertuoti docker run į container run?

Pakeiskite docker run į container run. -d, -p, -e, -v, --name, --rm, -it, -w ir --entrypoint lieka tokios pačios. Pašalinkite --restart ir naudokite sveikus CPU. Arba įklijuokite eilutę į Gantry, ir ji užpildys formą.

Ar Gantry gali importuoti docker run komandą?

Taip. Naujo konteinerio lange Įklijuoti komandą… nuskaito docker run, docker create, podman run ir container run ir užpildo formą.

Kas nutinka vėliavėlėms, kurių Gantry nepalaiko?

Jos išvardijamos peržiūroje su priežastimi ir lieka formoje skiltyje „Pagal įklijuotą komandą“, todėl vėliau galite jas patikrinti.

Ar galima veikiantį konteinerį vėl paversti docker run komanda?

Taip. Konteinerio meniu Kopijuoti kaip komandą parašo to konteinerio docker run arba container run eilutę.
