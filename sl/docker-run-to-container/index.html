Gantry/Iz docker run

Ustvarjanje vsebnika iz ukaza docker run

Večina datotek README navaja vrstico docker run. Gantry to vrstico prebere in izpolni obrazec Nov vsebnik, za gostitelja Docker ali za Applovo orodje container. Ta vodnik pokaže, kako, in kako ukaz pretvorite ročno.

Na kratko. V Gantryju odprite Nov vsebnik, izberite Prilepi ukaz…, prilepite vrstico docker run in kliknite Izpolni obrazec. Gantry izpiše vsako zastavico, ki je ne more uporabiti, skupaj z razlogom. Za CLI je večina zastavic enakih: docker run zamenjajte z container run in odstranite --restart.

Lepljenje ukaza v Gantry

  1. Izberite gostitelja: gostitelja Docker ali gostitelja apple/container.
  2. Odprite Vsebniki in kliknite Nov vsebnik.
  3. Kliknite Prilepi ukaz… in prilepite vrstico. Konci vrstic z \, narekovaji, poziv $ in sudo niso težava.
  4. Preberite predogled: sliko, zastavice, ki jih Gantry ne more uporabiti, opombe in opozorila za tega gostitelja.
  5. Kliknite Izpolni obrazec, preverite vrednosti in ustvarite vsebnik.

Gantry prebere docker run, docker container run, docker create, podman run in container run. Besedilo za &&, ||, ; ali | prezre in to zapiše v opombo.

Gantry pozna še približno 80 drugih zastavic Docker: njihove vrednosti pravilno preskoči in jih izpiše kot neuporabljene, zato se nič ne izgubi brez opombe.

Opozorila za gostitelje apple/container

Nekaterih možnosti Docker v apple/container ni. Gantry nanje opozori in jih izpusti iz zahteve za ustvarjanje:

  • pravilniki ponovnega zagona (--restart);
  • deli CPU-ja, na primer --cpus 0.5;
  • omrežni načini host, none in container:;
  • vrata brez vrat gostitelja, na primer -p 80.

Na gostitelju Docker Gantry opozori na možnosti apple/container: domeno DNS in možnosti jedra.

Ročna pretvorba docker run v container run

Za CLI večina zastavic ostane enakih. Primer z Redisom:

Terminal
docker run -d --name cache --restart unless-stopped -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

postane:

Terminal
container volume create redisdata
container run -d --name cache -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

Poimenovani nosilec najprej ustvarite z container volume create. Odstranite --restart in --cpus zaokrožite na celo število. --platform deluje kot v Dockerju.

Kopiranje vsebnika kot ukaza

Deluje tudi v obratni smeri. Z desno tipko kliknite vsebnik ali uporabite meni Več in izberite Kopiraj kot ukaz: Gantry zapiše vrstico docker run ali container run. Privzete vrednosti slike, na primer njeno okolje in ukaz, izpusti, da vrstica ostane kratka. To deluje tudi za ustavljene vsebnike.

Shranjevanje kot recept

V oknu Nov vsebnik odprite Recepti in izberite Shrani kot recept…. Naslednjič Izpolni iz recepta da enak obrazec na katerem koli gostitelju. Recepti so v ~/Library/Application Support/Gantry/recipes.json, zato jih lahko varnostno kopirate ali delite.

Omejitve

  • Gantry ohrani pot --env-file, vendar datoteke ne prebere, in za -e KEY brez vrednosti ne bere vaše lupine.
  • Priklopi tmpfs in anonimni nosilci iz --mount so izpisani kot nepodprti.
  • Dvoje vrat za ista vrata vsebnika (-p 8080:80 -p 8081:80) izpolni obrazec, vendar obrazec nato dvojnik zavrne.

Vprašanja in odgovori

Kako pretvorim docker run v container run?

docker run zamenjajte z container run. -d, -p, -e, -v, --name, --rm, -it, -w in --entrypoint ostanejo enaki. Odstranite --restart in uporabljajte cele CPU-je. Lahko pa vrstico prilepite v Gantry in ta izpolni obrazec.

Ali lahko Gantry uvozi ukaz docker run?

Da. Prilepi ukaz… v oknu Nov vsebnik prebere docker run, docker create, podman run in container run ter izpolni obrazec.

Kaj se zgodi z zastavicami, ki jih Gantry ne podpira?

V predogledu so izpisane z razlogom in ostanejo v obrazcu v razdelku Iz prilepljenega ukaza, da jih lahko preverite pozneje.

Ali lahko vsebnik, ki se izvaja, spremenim nazaj v ukaz docker run?

Da. Kopiraj kot ukaz v meniju vsebnika zapiše vrstico docker run ali container run za ta vsebnik.
