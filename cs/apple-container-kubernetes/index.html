Gantry/Kubernetes na apple/container

Kubernetes na Apple container

apple/container umí spustit cluster Kubernetes, jehož uzly jsou kontejnery na vašem Macu. Gantry je pro něj GUI: vytvořte cluster, sledujte, jak se uzly rozbíhají, připojte kubectl a načtěte místní image – bez dlouhých příkazů container cluster.

Ve zkratce. Na hostiteli apple/container vytváří a maže sekce Clustery v Gantry clustery Kubernetes pomocí container cluster (CLI 1.6.1) nebo container k8s (CLI 1.5.0 až 1.6.0). Podporuje více pracovních uzlů, vlastní CNI, zobrazení uzlů, kubeconfig a kontext kubectl a Načíst do clusteru pro místní image.

Požadavky

  • Mac s Apple silicon, macOS 26 a Gantry (brew install --cask getgantry/tap/gantry).
  • CLI container 1.5.0 nebo novější; doporučeno 1.6.1. Pracovní uzly a CNI Žádný vyžadují 1.6.0 nebo novější.
  • kubectl, pokud chcete cluster používat z terminálu.

Vytvoření clusteru

  1. Vyberte hostitele apple/container a v postranním panelu otevřete Clustery.
  2. Založte nový cluster a vyplňte možnosti níže.
  3. Vytvořte ho. Seznam zobrazí nový cluster s průběhem v reálném čase. Zrušit vytváření zastaví a smaže uzly, které už vznikly.
MožnostPříznak CLIPoznámky
Název--nameZároveň název kontextu v kubeconfig
Pracovní uzly--workersPočet pracovních uzlů. CLI 1.6.0+
CPU--cpusNa uzel
Paměť--memoryNa uzel, například 4G
Image uzlu--node-imagePrázdné pole ponechá výchozí hodnotu CLI
CNI--cniVýchozí (vestavěný kindnet), Žádný (NONE, CLI 1.6.0+) nebo cesta k vlastnímu manifestu

Stejný příkaz v CLI:

Shell
container cluster create --name dev --workers 2 --cpus 2 --memory 4G

Uzly a podrobnosti clusteru

Seznam clusterů zobrazuje každý cluster s jeho uzly: roli, stav a adresu. Podrobné zobrazení obsahuje Přehled (kontext kubectl, server API, pracovní uzly, síť uzlů), tabulku Uzly, kartu Inspekce se surovými daty uzlů a akce Zapsat kubeconfig, Kopírovat příkaz kubectl pro kontext a Smazat.

Připojení kubectl

Při vytváření clusteru přidá CLI do ~/.kube/config kontext pojmenovaný podle clusteru. Použijte v Gantry Kopírovat příkaz kubectl pro kontext, nebo ho napište ručně:

Shell
kubectl --context dev get nodes

Chcete-li mít cluster v samostatném souboru, použijte Zapsat kubeconfig. Gantry spustí container cluster write-config; výchozí cesta je ~/.kube/<name>.kubeconfig.

Načtení místních imagů do clusteru

Sestavte nebo stáhněte image na hostiteli apple/container, pak na něj v sekci Image klikněte pravým tlačítkem a zvolte Načíst do clusteru. Gantry spustí container cluster load-image, který zkopíruje image do containerd každého uzlu. Pro místní vývoj nepotřebujete registr.

Shell
container cluster load-image --name dev myapp:dev

Volba CNI

Výchozí je vestavěný manifest kindnet. Zvolte Vlastní manifest a nainstalujte vlastní CNI ze souboru, například Calico nebo Cilium. Zvolte Žádný, pokud chcete CNI nainstalovat sami později; do té doby zůstanou uzly ve stavu NotReady.

Clustery z AI agentů

Server MCP Gantry nabízí list_clusters, create_cluster a delete_cluster, takže agent jako Claude Code si může vytvořit dočasný cluster pro test a potom ho odstranit.

Přidání serveru MCP Gantry
claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp

Více o apple/container

Přečtěte si průvodce apple/container s každým příkazem container a jeho funkcí v Gantry, nebo se podívejte, jak si Gantry stojí ve srovnání s Docker Desktop, OrbStack a Podman Desktop.

Otázky a odpovědi

Podporuje Apple container Kubernetes?

Ano. CLI container vytváří clustery Kubernetes, jejichž uzly běží jako kontejnery: container cluster v CLI 1.6.1, container k8s v CLI 1.5.0 až 1.6.0. Gantry k tomu přidává GUI.

Podporuje Gantry container cluster?

Ano. Gantry vypisuje, vytváří a maže clustery na hostitelích apple/container, zobrazuje jejich uzly, zapisuje kubeconfig, kopíruje příkaz pro kontext kubectl a načítá místní image do clusteru. Podle verze vašeho CLI použije cluster nebo k8s.

Jak používat kubectl s clusterem apple/container?

Když CLI vytvoří cluster, přidá do ~/.kube/config kontext kubeconfig pojmenovaný podle clusteru. Spusťte kubectl --context <name> get nodes. Chcete-li mít samostatný soubor, použijte v Gantry Zapsat kubeconfig; výchozí cesta je ~/.kube/<name>.kubeconfig.

Jak dostat místní image do clusteru bez registru?

V Gantry klikněte pravým tlačítkem na image v sekci Image a zvolte Načíst do clusteru. Gantry spustí container cluster load-image, který zkopíruje image do containerd každého uzlu.

Jde vytvořit cluster s více uzly?

Ano. Počet pracovních uzlů nastavte v listu pro vytvoření. Pracovní uzly vyžadují CLI 1.6.0 nebo novější.

Můžu použít vlastní CNI, například Calico nebo Cilium?

Ano. Zvolte Vlastní manifest a vyberte soubor manifestu, nebo zvolte Žádný a CNI nasaďte sami po spuštění clusteru. Dokud CNI neběží, uzly zůstávají ve stavu NotReady. Žádný vyžaduje CLI 1.6.0 nebo novější. Výchozí CNI je vestavěný manifest kindnet.
