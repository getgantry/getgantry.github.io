Mac lietotne rīkam Apple container un Docker

Gantry ir bezmaksas atvērtā koda Mac lietotne Apple rīkam container un Docker – lokāli un caur SSH. Pārvaldiet konteinerus, Kubernetes klasterus, mašīnas un Compose projektus apple/container vidē no viena loga, blakus saviem Docker resursdatoriem. Bezmaksas Docker Desktop un OrbStack alternatīva Mac datoram.

Lejupielādēt macOS versiju
$ brew install --cask getgantry/tap/gantry

Gantry 0.29.0 · macOS 26+ · Apple silicon un Intel · MIT licence · 28 valodas · MCP serveris komplektā

Konteineri

Izveidojiet, palaidiet, atveriet un mainiet konteinerus katrā resursdatorā.

  • container run
  • docker exec -it
  • docker cp
  • docker port
Ielīmējiet docker run
Ielīmējiet docker run, podman run vai container run komandu, un Gantry aizpilda jauna konteinera veidlapu un uzskaita karodziņus, ko tā nevar izmantot. Jebkuru konteineru var nokopēt atpakaļ kā komandu vai saglabāt kā recepti. Kā tas darbojas
Iebūvēts exec terminālis
Pilnvērtīga termināļa emulācija jebkurā darbojošā konteinerā, lokālā vai attālā, ar krāsu motīviem (System, Solarized, Dracula, Nord).
Failu pārlūks ar vilkšanu un nomešanu
Pārlūkojiet konteinera failu sistēmu, pārvietojiet failus iekšā un ārā un nometiet veselas mapes tieši no Finder – gan Docker, gan apple/container resursdatoros.
Atvēršana pārlūkā un portu pāradresācija
Viens klikšķis atver publicēto portu. SSH resursdatoru porti tiek automātiski tunelēti uz localhost, un, ja ports ir aizņemts, Gantry izvēlas brīvu, ko varat mainīt.
Kopīgošana internetā
Ar vienu klikšķi publicētais ports kļūst pieejams caur Cloudflare Tunnel. Gantry pati instalē cloudflared un tad izveido ātro tuneli (bez konta, ar *.trycloudflare.com URL) vai nosaukto tuneli jūsu domēnā – noder izstrādes priekšskatījumam, webhook vai lai MI aģents piekļūtu konteineram jūsu Mac datorā.
Atslēgu piekariņa noslēpumi vidē
Glabājiet paroles un marķierus macOS atslēgu piekariņā (Iestatījumi → Noslēpumi) un izmantojiet tos kā vides mainīgos logos „Jauns konteiners” un „Ātrā palaišana”. Veidlapā redzams keychain:NAME, nevis vērtība, un Gantry nolasa vērtību tikai tad, kad izveido konteineru. Compose eksports, receptes un „Kopēt kā komandu” ieraksta nosaukumu, nevis vērtību.
Darbības ar daudziem vienlaikus
Atlasiet vairākus konteinerus, attēlus, sējumus vai tīklus un startējiet, apturiet, restartējiet vai noņemiet tos vienā solī, redzot norisi un rezultātu katram vienumam.
Statistika reāllaikā
CPU, atmiņas, tīkla un diska I/O diagrammas reāllaikā ar 1 s intervālu.
Konteineri ārējā diskā
Pārvietojiet visus apple/container datus uz ārējo disku, glabājiet sējumus jūsu izvēlētā diskā un saņemiet skaidru brīdinājumu, ja šis disks nav pievienots. Lasīt ceļvedi

Attēli un būvējumi

Lejupielādējiet, būvējiet, skenējiet un noņemiet attēlus.

  • docker build
  • docker pull
  • trivy image
  • docker system prune
Attēlu būvēšana un lejupielāde
Nometiet Dockerfile logā, lai būvētu ar žurnālu reāllaikā, vai lejupielādējiet pēc atsauces, redzot katra slāņa norisi. Pievienojiet tagus, iztīriet un skatiet slāņu vēsturi. Emblēma atzīmē attēlus, kas būvēti citai CPU arhitektūrai nekā resursdatoram.
Būvējumu vēsture
Katram resursdatoram ir sadaļa Būvējumi: būvējumi ar soļiem, kešatmiņas trāpījumiem un žurnālu. Gantry glabā būvējumus, ko pati sāk, ar būvēšanas argumentu nosaukumiem, bet bez to vērtībām. Docker resursdatoros tā arī nolasa docker buildx history (buildx 0.23.0 vai jaunāka). apple/container neglabā būvējumu vēsturi, tāpēc tur redzami būvējumi, ko sāka Gantry.
Attēlu skenēšana ar Trivy vai Grype
Attēlam izvēlieties Skenēt ievainojamības…. Gantry palaiž jūsu instalēto Trivy (0.50.0 vai jaunāku) vai Grype (0.74.0 vai jaunāku), piemēram, no Homebrew, un grupē atradumus pēc līmeņa no kritiskā līdz nezināmajam. Eksportēt SBOM ieraksta CycloneDX vai, ar Trivy, SPDX. Tas darbojas ar apple/container, lokālo Docker un Docker caur SSH; Docker caur SSH gadījumā Gantry skenē tagota attēla kopiju reģistrā.
Privātie reģistri
Lejupielādes izmanto jūsu jau veikto docker login: Gantry iegūst akreditācijas datus no ~/.docker/config.json, palīgprogrammām un atslēgu piekariņa – gan izveidē, gan ātrajā palaišanā, gan Compose.
Atgūstiet vietu
Viens panelis parāda, kas aizņem vietu – nepiesaistītie attēli, apturētie konteineri, neizmantotie sējumi, būvēšanas kešatmiņa – ar izmēriem un ļauj iztīrīt katru atsevišķi vai visu uzreiz. apple/container vidē tas veic arī diska TRIM.

Compose

Palaidiet docker-compose.yml Docker vai apple/container vidē un izveidojiet to no darbojošiem konteineriem.

  • docker compose up -d
  • docker compose down
  • docker compose logs -f
Compose katrā resursdatorā
Konteineri tiek grupēti pēc Compose projekta. Palaidiet Compose failu jebkurā resursdatorā – lokālajā Docker, SSH vai apple/container – ar iebūvētu YAML redaktoru; palaišana pielāgojas katram dzinējam.
Eksports kā Compose
Vienam vai vairākiem konteineriem izvēlieties Eksportēt kā Compose…, lai iegūtu docker-compose.yml ar portiem, montējumiem, tīkliem, restartēšanas politiku, veselības pārbaudi, ierobežojumiem un citu. Vērtības, kas izskatās pēc noslēpumiem, kļūst par ${NAME}, ja vien tās neiekļaujat. apple/container resursdatoros Gantry brīdina par karodziņiem, ko Compose nevar izteikt. Kā tas darbojas

Kubernetes

Pārlūkojiet katru kubeconfig kontekstu vai izveidojiet klasteri ar apple/container.

  • kubectl get pods -A
  • kubectl logs -f
  • kubectl port-forward
  • container cluster
Kubernetes pārlūks
Pārlūkojiet jebkura kubeconfig konteksta podus, Deployments, StatefulSets, DaemonSets, pakalpojumus, Ingresses, ConfigMaps, noslēpumus, mezglus un notikumus. Sekojiet podu žurnāliem, atveriet čaulu, pārsūtiet portu, mērogojiet, restartējiet izvēršanu un lietojiet YAML. Gantry pati sazinās ar Kubernetes API, tāpēc klasteri, kas izveidots ar container cluster create, var pārlūkot uzreiz, neko citu neinstalējot: nav vajadzīgs kubectl.
Kubernetes klasteri
Izveidojiet Kubernetes klasteri ar container cluster: atsevišķi norādiet vadības plaknes un darba mezglu izmēru, izvēlieties CNI un skatiet mezglus, Kubernetes versiju un kubeconfig kontekstu. Klastera mezgli ir aizsargāti pret nejaušu apturēšanu un dzēšanu. Lasīt vairāk
  • Kubernetes apple/container vidē
  • Kubernetes Mac datorā

Resursdatori un parks

Šis Mac, Docker resursdatori caur SSH un apple/container vienā informācijas panelī.

  • docker -H ssh://user@host
  • docker context use
  • docker stats
Viens informācijas panelis visiem resursdatoriem
Lokālais Docker dēmons, SSH resursdatori un apple/container vienā ekrānā: CPU un atmiņas mini diagrammas reāllaikā, konteineru stāvokļu sadalījums un veselības problēmas, no kurām var uzreiz pāriet uz vaininieku.
Attāli resursdatori caur SSH
Tunelis tieši kā docker -H ssh:// caur dial-stdio: ProxyJump starpniekserveri, vairāku atslēgu autentifikācija, automātiska atkārtota savienošanās. Serverī nekas nav jāinstalē, noslēpumi glabājas atslēgu piekariņā. Imports ar vienu klikšķi no ~/.ssh/config un docker context ls.
Visu resursdatoru resursu lietojums
Viena kārtojama tabula ar darbojošos konteineriem katrā savienotajā resursdatorā: resursdators, nosaukums, attēls, CPU, atmiņa, tīkla I/O, diska I/O un darbības laiks. Filtrējiet pēc nosaukuma, attēla vai resursdatora vai rādiet vienu resursdatoru. Veiciet dubultklikšķi uz rindas, lai atvērtu konteineru. Tabula izmanto paraugus, ko Gantry jau ņem ik pēc 5 sekundēm, tāpēc tā neatver jaunas statistikas plūsmas. Atveriet to no sānjoslas, ar ⌘K vai ar gantry://open/usage.

Žurnāli un kļūmes

Lasiet, meklējiet un eksportējiet žurnālus. Atrodiet cēloni, kad konteinerim ir kļūme.

  • docker logs -f
  • container logs
  • docker events
Tiešraides žurnāli
Sekošana reāllaikā, regex vai precīza ⌘F meklēšana, līmeņa filtrs (Error→Trace), ANSI krāsas, 50 tūkst. rindu buferis – un apvienoti steka žurnāli visam Compose projektam.
Žurnālu eksports
Eksportēt žurnālus… (⇧⌘E) saglabā redzamās rindas ar līmeņa filtru, meklēšanu un laika periodu .log vai .txt failā. Kopēt redzamās rindas tās nokopē. Docker resursdatoros varat pievienot laikspiedolus un rādīt tikai pēdējos ierakstus: no 5 minūtēm līdz dienai.
Paziņojumi par kļūmēm
Natīvs paziņojums, kad konteiners jebkurā resursdatorā avarē, tam pietrūkst atmiņas vai tas kļūst nevesels. Noklikšķiniet, lai uzreiz pārietu uz konteineru; par jūsu pašu veiktu apturēšanu paziņojumi netiek rādīti.
Kļūmju skaidrojums ar Apple Intelligence
Avarējušam konteineram vai neizdevušai darbībai izvēlieties Izskaidrot kļūmi…. Gantry nosūta modelim ierīcē nesenos žurnālus un informāciju, no kuras noņemtas vides mainīgo vērtības un noslēpumiem līdzīgs teksts, un parāda iespējamo cēloni, pierādījumus un nākamās darbības. Garos žurnālus var nosūtīt uz Private Cloud Compute (macOS 27). Panelī redzams tieši tas, kas tika nosūtīts.
Ekrānuzņēmumi funkcijā „Izskaidrot kļūmi”
Funkcijā „Izskaidrot kļūmi” ievelciet, ielīmējiet vai pievienojiet līdz 3 attēliem, piemēram, kļūdas lapas ekrānuzņēmumu. Attēli paliek šajā Mac datorā: tos lasa tikai modelis ierīcē (macOS 27), nekad Private Cloud Compute.

macOS

Izvēļņu josla, paziņojumi, Spotlight, Īsceļi un tastatūra.

  • ⌘K
  • ⌥⌘P
  • ⇧⌘E
Daļa no macOS
Paziņojumi ar darbībām „Restartēt”, „Skatīt žurnālus” un „Kopēt kā uzvedni”. Spotlight atrod konteinerus, Compose projektus un resursdatorus. Siri un Īsceļu darbības, infrastruktūras veselības logrīks, Vadības centra vadīklas apple/container pakalpojumiem vai izlases konteineram un gantry:// saites skriptiem.
Norise izvēļņu joslā
Izvēļņu joslas panelis rāda katru notiekošo lejupielādi, būvēšanu un Compose darbību ar norises joslu, pabeigtajiem slāņiem vai pakalpojumiem, baitiem, laiku un pogu Atcelt. Izvēļņu joslas ikona rāda, cik darbību notiek. Katram Compose projektam ir Lejupielādēt attēlus un Compose Down; Compose Down saglabā sējumus un attēlus.
Komandu palete
Nospiediet ⌘K un rakstiet. Viena meklēšana aptver konteinerus, Compose projektus, attēlus, sējumus, tīklus, mašīnas, klasterus un resursdatorus, ar tādām darbībām kā „Startēt”, „Rādīt žurnālus” un „Atvērt čaulu”.
Touch ID bīstamām darbībām
Ieslēdziet šo opciju, un pirms konteinera noņemšanas vai resursdatora dzēšanas Gantry pieprasīs Touch ID vai jūsu pieteikšanās paroli. Noslēpumi jau tāpat glabājas atslēgu piekariņā.
Termināļa motīvi
Ietērpiet iebūvēto čaulu motīvā System, Solarized Dark, Dracula vai Nord: pilna priekšplāna, fona un 16 krāsu ANSI palete, kas tiek lietota uzreiz.

Natīvā macOS grafiskā saskarne rīkam Apple container

Apple rīks container palaiž Linux konteinerus kā vieglas virtuālās mašīnas uz Apple silicon, taču tiek piegādāts tikai kā komandrindas rīks. Gantry ir tā darbvirsmas lietotne: kas Docker Desktop ir rīkam Docker, tas Gantry ir rīkam container. Tā atbalsta katru container CLI versiju no 1.0 līdz ieteicamajai 1.7.1 un ieslēdz katru iespēju tikai tad, ja to atbalsta jūsu instalētais CLI.

  • container system start
  • container machine
  • container builder start
  • container registry login
Konteineri, žurnāli, statistika un exec
Izveidojiet, startējiet, apturiet, piespiedu kārtā apturiet un iztīriet; žurnāli un statistika reāllaikā, exec terminālis, top un tar eksports – tajā pašā saskarnē, kur jūsu Docker resursdatori.
Kubernetes klasteri
Izveidojiet Kubernetes klasteri ar container cluster: atsevišķi norādiet vadības plaknes un darba mezglu izmēru, izvēlieties CNI un skatiet mezglus, Kubernetes versiju un kubeconfig kontekstu. Klastera mezgli ir aizsargāti pret nejaušu apturēšanu un dzēšanu. Lasīt vairāk
Lokālie attēli klasterī
CLI 1.7 versijā ieslēdziet Izmantot lokālos attēlus (--shared-image-store), un podi palaiž attēlus, ko būvējat vai lejupielādējat, bez reģistra. CLI 1.5 un 1.6 versijā ar peles labo pogu noklikšķiniet uz attēla un izvēlieties Ielādēt klasterī.
Skaidri norādījumi, ja instalācija ir bojāta
Ja klastera pakalpojumi neatbild, Gantry pasaka, kāpēc. Homebrew versijai bez klastera pakalpojumiem tiek dota saite uz parakstīto instalētāju; visos citos gadījumos ir poga Restartēt pakalpojumus.
Konteineru mašīnas lietotnē VS Code
Izveidojiet, startējiet un apturiet container machine Linux vides, iestatiet CPU un atmiņu, atveriet čaulu vai atveriet mašīnu VS Code caur Remote-SSH.
Ligzdotā virtualizācija un pielāgoti kodoli
Sāknējiet mašīnu ar ligzdoto virtualizāciju (M3 vai jaunāks) vai savu kodolu. Sāknējiet konteinerus no pielāgota kodola ar papildu sāknēšanas argumentiem.
Compose ar Apple container
apple/container nav compose. Gantry palaiž jūsu docker-compose.yml: būvē, izveido tīklu un sējumus un startē pakalpojumus depends_on secībā. Pakalpojumu nosaukumi tiek atrisināti ar tīkla DNS aizstājvārdiem.
Tīkla DNS aizstājvārdi
Konteineru aizstājvārdi, apakškoka aizstājvārdi, piemēram, .gateway, un īsie nosaukumi, ja iestatīts noklusējuma DNS domēns. Katrs konteiners saņem maršrutējamu IP un resursdatora nosaukumu name.domain.
Attēlu būvētāja pārvaldība
Skatiet būvētāja stāvokli, attēlu, CPU, atmiņu un IP. Startējiet to ar CPU, atmiņas un DNS opcijām, apturiet vai dzēsiet. Ja būvētāja attēls ir novecojis, Gantry piedāvā to izveidot no jauna.
Pieteikšanās reģistros
Skatiet, pievienojiet un noņemiet container registry pieteikšanos. Parole tiek nodota CLI tikai caur stdin, un Gantry tās kopiju neglabā.
Kodola instalēšana
Instalējiet ieteicamo kodolu, kodola failu vai tar arhīvu, redzot norisi reāllaikā. Gantry brīdina, ja nav instalēts noklusējuma kodols.
Pakalpojumi un pakalpojumu žurnāli
Startējiet, apturiet un restartējiet container pakalpojumus, salīdziniet klienta un servera versijas un straumējiet pakalpojumu žurnālus, filtrējot pēc līmeņa, pakalpojuma un teksta.
Sistēmas rekvizītu redaktors
Rediģējiet container sistēmas rekvizītus failā config.toml. Gantry atzīmē izmaiņas, kurām vajadzīga restartēšana, un pati restartē pakalpojumus. CLI 1.7 versijā tā rediģē arī [container.dns] noklusējumus: vārdu serverus, meklēšanas domēnus un opcijas.
Saglabāšana kā attēlu un diska TRIM
Saglabājiet konteineru kā attēlu (container commit) un atgūstiet diska vietu ar Veikt diska TRIM (container clean), kas pieejams arī panelī „Atgūt vietu”.
Failu pārlūks: augšupielāde un lejupielāde
Pārlūkojiet konteinera failus, lejupielādējiet tos vai izvelciet uz Finder (container copy) un nometiet iekšā failus vai veselas mapes.
Ātrā palaišana un Finder
Izvēlieties attēlu, kopīgojiet mapi, piesaistiet portus, izvēlieties domēnu un palaidiet. Finder ar peles labo pogu noklikšķiniet uz Compose faila un atveriet to ar Gantry.
Etiķetes, kas satur =
container CLI noraida etiķešu vērtības ar =. Gantry tās kodē izveidē un atkodē nolasot, tāpēc vērtība, piemēram, a=b, paliek nemainīga.
Viens parks, divas izpildes vides
apple/container resursdatori atrodas blakus jūsu lokālajam Docker un SSH resursdatoriem vienā informācijas panelī ar tām pašām mini diagrammām, veselības stāvokli un paziņojumiem par kļūmēm.
MCP rīki aģentiem
Komplektā iekļautais MCP serveris aģentiem dod tādas pašas iespējas: konteinerus, mašīnas, klasterus un apple_* sistēmas rīkus pakalpojumiem, būvētājam, reģistriem, rekvizītiem, žurnāliem un kodoliem.
  • apple/container ceļvedis: katra CLI komanda un tai atbilstošā Gantry iespēja
  • Gantry salīdzinājumā ar Docker Desktop, OrbStack un Podman Desktop
  • No Docker Desktop
  • Ārējais disks
  • No docker run

Aģenti

Komplektā iekļautais MCP serveris un App Intents atver katru resursdatoru, arī SSH, rīkiem Claude, Īsceļi, Siri un skriptiem ar tādām pašām iespējām kā grafiskajā saskarnē: konteineru izveide un pārvaldība, attēlu būvēšana un lejupielāde, sējumi un tīkli, Compose Up, apple/container mašīnas un Kubernetes klasteri, apple_* sistēmas rīki pakalpojumiem, būvētājam, reģistriem un kodoliem, pat porta atvēršana caur Cloudflare Tunnel.

  • claude mcp add gantry

Nospiediet ⌥⌘P uz jebkura konteinera, un Gantry ievietos starpliktuvē gatavu atkļūdošanas uzvedni: resursdatoru un to, kā tam piekļūt, MCP host_id un rīkus, pilnu konteinera stāvokli un simptomam atbilstošu uzdevumu.
MCP rīki aģentiem
Komplektā iekļautais MCP serveris aģentiem dod tādas pašas iespējas: konteinerus, mašīnas, klasterus un apple_* sistēmas rīkus pakalpojumiem, būvētājam, reģistriem, rekvizītiem, žurnāliem un kodoliem.

Jautājumi

Kāda ir labākā Apple container grafiskā saskarne (GUI)?

Gantry ir bezmaksas atvērtā koda natīvā macOS grafiskā saskarne, kas radīta Apple rīkam container (apple/container). Tā aptver konteineru dzīves ciklu, žurnālus, statistiku un exec termināli, kā arī tās CLI daļas, līdz kurām citas grafiskās saskarnes netiek: Kubernetes klasterus (container cluster), konteineru mašīnas, attēlu būvētāju, pieteikšanos reģistros, kodolus, pakalpojumu žurnālus un sistēmas rekvizītus. Tā atbalsta CLI no 1.0 līdz 1.7.1 un ieslēdz katru iespēju tikai tad, ja to atbalsta jūsu CLI. Skatiet apple/container ceļvedi.

Kas ir Apple container (apple/container)?

apple/container ir Apple atvērtā koda rīks Linux konteineru palaišanai Mac datorā. Katrs konteiners darbojas savā vieglā virtuālajā mašīnā, kas balstīta uz Apple Virtualization ietvaru. Tam nepieciešams Mac dators ar Apple silicon, un tas tiek piegādāts kā komandrindas rīks container bez darbvirsmas lietotnes. Gantry ir šī darbvirsmas lietotne.

Vai Gantry atbalsta container cluster un Kubernetes?

Jā. apple/container resursdatorā Gantry izveido un dzēš Kubernetes klasterus ar container cluster (CLI 1.6.1 un 1.7; CLI no 1.5.0 līdz 1.6.0 izmanto container k8s). Jūs izvēlaties nosaukumu, darba mezglus, vadības plaknes un darba mezglu CPU un atmiņu (1.7), mezgla attēlu, CNI un to, vai mezgli izmanto jūsu lokālos attēlus (1.7). Gantry rāda mezglus, ieraksta kubeconfig un atver klasteri savā Kubernetes pārlūkā. Skatiet Kubernetes apple/container vidē.

Vai ar Apple container var izmantot docker compose?

Jā. apple/container nav komandas compose, tāpēc Gantry pati veic orķestrēšanu ar container CLI: būvē build: pakalpojumus, izveido projekta tīklu un nosauktos sējumus un startē katru pakalpojumu depends_on secībā ar standarta Compose etiķetēm. Pakalpojumu nosaukumi tiek atrisināti ar tīkla DNS aizstājvārdiem. Atveriet docker-compose.yml no Finder, izvēlnes Fails vai nometot to logā.

Kā atvērt konteinera mašīnu lietotnē VS Code?

Startējiet mašīnu lietotnē Gantry un noklikšķiniet uz Atvērt lietotnē VS Code. Gantry atver mašīnu lietotnē VS Code caur Remote-SSH, kā Apple piemērā container-machine-vscode. Mašīnas attēlā jādarbojas sshd, un jābūt instalētam VS Code ar paplašinājumu Remote-SSH.

Kuras apple/container versijas atbalsta Gantry?

Gantry nepieciešams container CLI 1.0 vai jaunāka versija, ieteicamā ir 1.7.1. Lietotne nolasa instalēto versiju un rāda tikai tās iespējas, ko šī versija atbalsta, piemēram, darba mezglu izmērus un kopīgo attēlu krātuvi (1.7), saglabāšanu kā attēlu (1.6) un diska TRIM (1.4). Ja CLI nav vai tas ir novecojis, Gantry piedāvā iestatīšanu soli pa solim.

Vai Gantry var pārlūkot Kubernetes klasteri?

Jā. Sadaļa Kubernetes katram kubeconfig kontekstam rāda podus, Deployments, StatefulSets, DaemonSets, pakalpojumus, Ingresses, ConfigMaps, noslēpumus, mezglus un notikumus. Tajā ir podu žurnāli, poda čaula, portu pārsūtīšana, mērogošana, izvēršanas restartēšana, dzēšana un YAML lietošana. Gantry pati sazinās ar Kubernetes API, tāpēc kubectl nav vajadzīgs. Skatiet Kubernetes palaišana Mac datorā.

Ko kļūmes skaidrojums nosūta Apple Intelligence?

Nesenos žurnālus un konteinera informāciju, no kuras noņemtas vides mainīgo vērtības un noslēpumiem līdzīgs teksts. Nelieli pieprasījumi tiek apstrādāti ar modeli ierīcē. Ja ir ieslēgts garo žurnālu iestatījums (macOS 27), garie žurnāli tiek nosūtīti uz Private Cloud Compute. Panelī redzams, kas tika nosūtīts. Ieteiktā komanda tiek atvērta lietotnē Terminal, bet netiek izpildīta, kamēr nenospiežat Return. Bez Apple Intelligence Gantry piedāvā uzvedni, ko nokopēt citā MI asistentā.

Vai Gantry var ielīmēt docker run komandu?

Jā. Jauna konteinera logā izvēlieties Ielīmēt komandu…. Gantry nolasa docker run, docker create, podman run un container run, aizpilda veidlapu un uzskaita katru karodziņu, ko tā nevar izmantot, ar iemeslu. Skatiet Konteinera izveide no docker run komandas.

Vai Gantry var pārvaldīt apple/container būvētāju, reģistrus un kodolu?

Jā. apple/container resursdatora sadaļa „Sistēma” startē, aptur un dzēš attēlu būvētāju ar CPU, atmiņas un DNS opcijām; rāda, pievieno un noņem pieteikšanos reģistros (parole tiek nodota CLI tikai caur stdin); instalē ieteicamo kodolu, kodola failu vai tar arhīvu; straumē pakalpojumu žurnālus un rediģē sistēmas rekvizītus failā config.toml.

Vai Gantry ir Docker Desktop, OrbStack vai Podman Desktop alternatīva?

Kā grafiskā saskarne – jā. Gantry ir bezmaksas natīvā macOS lietotne konteineru, attēlu, sējumu, tīklu, žurnālu un statistikas pārvaldībai. Tā ir klients, nevis dzinējs: tā izmanto jau darbojošos Docker dēmonu (Docker Desktop, OrbStack, Colima) vai Apple rīku container un pievieno vairāku resursdatoru skatu, SSH resursdatorus un MCP serveri. Skatiet salīdzinājumu.

Vai Gantry ir bezmaksas?

Jā. Gantry ir bezmaksas un atvērtā koda lietotne ar MIT licenci. Nav abonementa, nav konta un nav ierobežojumu resursdatoru vai konteineru skaitam.

Kas nepieciešams, lai palaistu Gantry?

Mac dators ar Apple silicon vai Intel procesoru un macOS 26 vai jaunāku versiju, kā arī Docker dēmons (Docker Desktop, OrbStack, Colima vai līdzīgs) vai Apple rīks container. Pašam apple/container nepieciešams Apple silicon, tāpēc Intel Mac datorā Gantry pārvalda tikai Docker resursdatorus.

Vai Gantry darbojas ar OrbStack, Colima un Docker Desktop?

Jā. Gantry sazinās tieši ar Docker Engine API caur Unix ligzdu, tāpēc darbojas ar jebkuru dēmonu, kas to nodrošina, tostarp OrbStack, Colima un Docker Desktop.

Vai Gantry var pārvaldīt attālus Docker resursdatorus?

Jā. Gantry savienojas ar attāliem dēmoniem caur SSH tāpat kā docker -H ssh://, ar ProxyJump starpniekserveriem, vairāku atslēgu autentifikāciju un automātisku atkārtotu savienošanos. Serverī nekas nav jāinstalē, un noslēpumi glabājas macOS atslēgu piekariņā.

Vai Gantry brīdina, ja konteiners avarē?

Jā. Gantry nosūta natīvu macOS paziņojumu, kad konteiners avarē, tam pietrūkst atmiņas vai tam neizdodas veselības pārbaude jebkurā resursdatorā: lokālā, SSH vai apple/container. Noklikšķiniet uz paziņojuma, lai pārietu uz konteineru. Par apturēšanu un restartēšanu, ko veicat lietotnē Gantry, paziņojumi netiek rādīti, un paziņojumus var izslēgt iestatījumos.

Vai Gantry var lejupielādēt attēlus no privātiem reģistriem?

Jā. Docker resursdatoros Gantry nolasa akreditācijas datus no jūsu ~/.docker/config.json (tā paša docker login, ko jau izpildījāt), tostarp iekļautos datus, akreditācijas datu palīgprogrammas un macOS atslēgu piekariņu. apple/container resursdatoros tā pārvalda container registry pieteikšanos.

Vai ar Gantry var padarīt lokālu konteineru pieejamu internetā?

Jā. Ar vienu klikšķi publicētais ports tiek kopīgots caur Cloudflare Tunnel. Gantry vajadzības gadījumā instalē cloudflared un tad startē ātro tuneli (bez Cloudflare konta, ar pagaidu trycloudflare.com URL) vai nosaukto tuneli jūsu domēnā. Publiskais URL tiek rādīts zem porta ar atvēršanas, kopēšanas un apturēšanas pogām.

Vai Gantry ir Electron lietotne?

Nē. Gantry ir natīvā lietotne, kas veidota ar SwiftUI un Swift 6. Saskarne ir pieejama 28 valodās: angļu, vienkāršotajā ķīniešu un 26 Eiropas valodās, piemēram, serbu valodā kirilicā un latīņu rakstībā. Tā seko macOS sistēmas valodai.

Kā instalēt Gantry?

Izpildiet brew install --cask getgantry/tap/gantry vai lejupielādējiet jaunāko laidienu no GitHub un ievelciet Gantry.app mapē Lietotnes.

Vai MI aģenti var vadīt Gantry?

Jā. Gantry komplektā ir MCP serveris un macOS App Intents, tāpēc Claude, Īsceļi, Siri un skripti katrā resursdatorā, arī SSH resursdatoros, var paveikt to pašu, ko grafiskā saskarne: konteineri, attēli, sējumi, tīkli, Compose, apple/container mašīnas, Kubernetes klasteri, apple_* sistēmas rīki (pakalpojumi, būvētājs, reģistri, rekvizīti, žurnāli, kodols) un portu kopīgošana. macOS 26 un jaunākā versijā Izskaidrot kļūmi… arī jautā Apple Intelligence, kāpēc konteiners cieta kļūmi. Pievienojiet MCP serveri ar claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp.
