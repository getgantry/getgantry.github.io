Gantry/Docker Desktopilt

Docker Desktopilt Apple containerile

Apple'i container-tööriist käitab samu OCI-tõmmiseid nagu Docker, seega liigub suurem osa teie tööst üle vaid mõne käsumuudatusega. See juhend seob Dockeri käsud container-i käskudega, viib üle tõmmised ja köited ning loetleb puudujäägid, millest peaksite enne üleminekut teadma.

Lühidalt. Installige allkirjastatud container pakett, asendage käivitamisel, koostamisel, logides, exec'is ja tõmmistes docker sõnaga container, kopeerige nimega köited tar-faili abil ja avage oma docker-compose.yml Gantrys, sest CLI-l pole käsku compose. Proovimise ajal võite Docker Desktopi installituks jätta.

Mis muutub

  • Üks virtuaalmasin konteineri kohta. Docker Desktop käitab kõiki konteinereid ühes Linuxi virtuaalmasinas. apple/container käivitab iga konteineri jaoks väikese virtuaalmasina, seega saab igaüks teie Macis oma IP-aadressi.
  • Samad tõmmised ja registrid. Tõmmised on OCI-tõmmised; tõmbate neid Docker Hubist, GHCR-ist ja privaatsetest registritest nagu varemgi.
  • Litsentsitasu pole. apple/container on Apache 2.0 litsentsiga. Docker Desktop vajab tasulist paketti organisatsioonides, kus on 250 või rohkem töötajat või 10 mln dollarit või rohkem käivet.
  • Ainult Apple'i kiip ja macOS 26. Inteli Macides jääge Dockeri mootori juurde.

Tõmmiste üleviimine

Registris olevad tõmmised: tõmmake need uuesti käsuga container image pull. Kohalikud tõmmised, mis on olemas ainult Dockeris: salvestage need arhiivi ja laadige see. container image load loeb OCI-arhiive ja Dockeri uued versioonid kirjutavad käsuga docker save OCI-paigutuse. Kui laadimine nurjub, lükake tõmmis registrisse ja tõmmake see sealt.

Terminal
docker save -o app.tar app:dev
container image load -i app.tar
container image pull nginx:alpine

Nimega köidete teisaldamine

Docker hoiab köidete andmeid oma virtuaalmasinas. Kopeerige iga köide lühiajalise konteineriga tar-faili ja pakkige see seejärel lahti uude apple/containeri köitesse:

Terminal
docker run --rm -v data:/from -v "$PWD":/to alpine tar -C /from -cf /to/data.tar .
container volume create data
container run --rm -v data:/to -v "$PWD":/from alpine tar -C /to -xf /from/data.tar

Nimega köide on apple/containeris hõre ext4-kettatõmmis, vaikimisi kuni 512 GB. Muu suuruse määrake valikuga --opt size=20g. Teie Maci kaustade bind mount'id töötavad nagu Dockeris: -v ~/project:/app.

Compose'i failid

container CLI-l pole käsku compose. Avage docker-compose.yml selle asemel Gantrys (Finderist, menüüst Fail ▸ Ava Compose'i fail… või lohistades). Gantry koostab build:-teenused, loob projekti võrgu ja nimega köited ning käivitab teenused depends_on järjekorras. Teenused leiavad üksteist teenuse nime järgi võrgu DNS-aliaste kaudu.

Võrgud ja pordid

  • -p 8080:80 avaldab pordi aadressil localhost, nagu Dockeris.
  • Igal konteineril on ka oma IP-aadress. Looge kohalik DNS-domeen käsuga sudo container system dns create test ja käivitage konteinerid lipuga --dns-domain test: need saavad nimed, nagu web.test.
  • container network create loob kasutaja võrke; samas võrgus olevad konteinerid jõuavad üksteiseni.
  • Režiime --network host, none ja container: pole.

Mis puudub

  • Docker Engine API-t pole. Tööriistad, mis suhtlevad sokliga /var/run/docker.sock, nagu Testcontainers, Dockeri SDK-d või Dev Containers, apple/containerit ei näe.
  • Taaskäivituspoliitikaid pole. --restart pole saadaval; konteiner ei käivitu ise uuesti.
  • CLI-s pole Compose'i. Gantry käitab Compose'i faile: vaadake jaotist Compose'i failid.
  • Docker Desktopi laiendusi pole.
  • Ainult täisarv CPU-sid: --cpus 0.5 ei tööta.
  • Kubernetes on teistsugune: kasutage käsku container cluster, vaadake juhendit Kubernetes Macis.

Hoidke ülemineku ajal mõlemad alles

Gantry haldab apple/containerit ja mis tahes Dockeri mootorit (Docker Desktop, OrbStack, Colima või Docker SSH kaudu) ühes külgribas. Viige üle üks projekt korraga ja jätke Docker nende tööriistade jaoks, mis vajavad selle API-t. Kui te seda enam ei vaja, võite Docker Desktopi eemaldada.

Küsimused ja vastused

Kas Apple container saab Docker Desktopi asendada?

Konteinerite käitamiseks, koostamiseks ja tõmbamiseks Apple'i kiibil jah. Sellel pole Docker Engine API-t, taaskäivituspoliitikaid, laiendusi ega käsku compose. Gantry lisab Compose'i failide toe ja GUI.

Kas Dockeri tõmmised töötavad Apple containeriga?

Jah. apple/container kasutab standardseid OCI-tõmmiseid ja tõmbab samadest registritest. arm64-tõmmised töötavad natiivselt; amd64-tõmmised töötavad Rosetta kaudu lipuga --arch amd64.

Kas docker compose töötab Apple containeriga?

CLI-st mitte: käsku container compose pole. Gantry loeb faili docker-compose.yml ja käitab teenused teie eest apple/containeris.

Kas Docker Desktopi ja Apple containerit saab kasutada samal ajal?

Jah. Neil pole ühiseid tõmmiseid ega köiteid, kuid need saavad töötada kõrvuti. Gantry näitab mõlemat ühes aknas.

Kas Apple container on äriliseks kasutuseks tasuta?

Jah. apple/container on avatud lähtekoodiga Apache 2.0 litsentsi all ja Gantry on MIT-litsentsiga. Mõlemad on tasuta igas suuruses ettevõtetele.
