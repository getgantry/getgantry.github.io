Containers

The container list groups by Compose project, filters by state, and searches by name, image or ID. Everything you can do to a container is reachable here.

Creating a container

Two paths, both from the Containers toolbar:

  • New Container — the full docker run surface: image, name, command, port mappings, environment, volume binds, restart policy, TTY and auto-remove. On apple hosts it also offers a DNS domain. If the image is missing locally it offers to pull and retry.
  • Quick Run — an OrbStack-style fast path: pick a local image, optionally share a Mac folder, map a port, choose a DNS domain, and open it in the browser when ready.

The detail view

Select a container to open its detail tabs:

  • Overview — state, address, ports, mounts, networks, config and environment.
  • Logs — live streaming with search, level filter and follow toggle. Export Logs… (⇧⌘E) saves exactly the lines on screen, as a .log or .txt file; Copy Visible Lines copies them. On Docker hosts the display menu adds Show Timestamps and a Time Range from the last 5 minutes to the last day. apple/container does not report log times, so that menu is off there.
  • Stats — live CPU, memory, network and I/O charts.
  • Terminal — an interactive shell into the running container.
  • Files — browse, download and upload files.
  • Processes — a live top table.
  • Inspect — the raw JSON.

Actions

Start, stop, restart and kill from the toolbar; the overflow menu adds Rename, Commit to Image, Export Filesystem, Restart Policy, Copy ID and Copy as Prompt. On apple/container hosts, Commit to Image needs CLI 1.6, and Trim Disk (CLI 1.4) reclaims disk space of a running container. Most actions are also on the right-click menu in the list and the menu bar.

Resource Usage

Resource Usage, under Dashboard in the sidebar, is one table of the running containers on all connected hosts: host, name, image, CPU, memory, network I/O, disk I/O and uptime. It uses the samples that the dashboard already takes every 5 seconds. Click a column to sort, type in Name, image or host to filter, or pick one host. Double-click a row or press Return to open the container; the row menu has Show in Containers, Show Stats and Copy Name. A host that is not connected gets one line with a Retry button. The MCP tool fleet_activity returns the same table.

Export as Compose

Right-click one or more containers, or use the More menu of a container, and choose Export as Compose…. Gantry writes a docker-compose.yml with one service per container: ports, binds, volumes, tmpfs, networks with aliases, restart policy, healthcheck, CPU and memory limits, capabilities, DNS, devices, ulimits and logging. Named volumes and networks are external: true. Values that look like secrets become ${NAME}; include the ones you want under Secret Values. A file that holds a secret value is saved with mode 0600. On apple/container hosts, Warnings lists flags that Compose cannot express, such as --kernel, --rosetta and --ssh.

Keychain secrets

Add secrets in Settings → Secrets. The values go to the macOS Keychain and Gantry never shows them again; you can rename, replace or delete a secret, and turn on Require Touch ID to use secrets. In New Container and Quick Run, the key menu of an environment row offers your secrets, New Secret…, Save Value in Keychain… and Use Plain Value. A row with a secret shows keychain:NAME. Gantry reads the value only when it creates the container. Copy as Command, recipes and Compose export write keychain:NAME, and the Inspect tab shows KEY=[REDACTED]. The engine keeps the value in the container configuration, so docker inspect or container inspect outside Gantry can show it.

Explain Failure with screenshots

On macOS 27 with the on-device model, you can add up to 3 images (20 MB each) to Explain Failure: drop them, paste them with ⌘V, or click Add Image…. Gantry reduces each image to 1024 pixels on the longer side. Images go only to the on-device model, never to Private Cloud Compute, and Copy as Prompt stays text only. Gantry does not hide secrets in images, so check what a screenshot shows.
