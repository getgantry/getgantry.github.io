Gantry/Skenovanie obrazov

Skenovanie obrazov kontajnerov na zraniteľnosti na Macu

Trivy a Grype sú bezplatné open-source skenery, ktoré porovnávajú balíky v obraze s databázami známych zraniteľností. Obrazy Dockeru čítajú priamo. Nástroj container od Apple nemá príkaz na skenovanie ani socket Dockeru, takže obraz najprv uložíte. Tento návod ukazuje oba postupy, ako čítať nálezy, ako zapísať SBOM a ako skenovať z Gantry.

V skratke. Spustite brew install trivy grype. Na Dockeri spustite trivy image app:dev. Na Apple container uložte obraz príkazom container image save --platform linux/arm64 -o app.tar app:dev, rozbaľte ho príkazom tar -xf app.tar -C app-img a naskenujte priečinok: trivy image --input app-img alebo grype oci-dir:app-img. Samotný súbor tar oba nástroje odmietajú.

Inštalácia skenera

Nainštalujte jeden skener alebo oba cez Homebrew. Každý si pri prvom skene stiahne databázu zraniteľností, čo trvá asi minútu.

Terminál
brew install trivy grype

Príkazy v tomto návode sme overili s Trivy 0.76.2, Grype 0.121.3 a container 1.7.1. Gantry vyžaduje Trivy 0.50.0 alebo Grype 0.74.0 či novší.

Sken obrazu Dockeru

S Docker enginom (Docker Desktop, OrbStack alebo Colima) oba nástroje čítajú lokálny obraz podľa názvu cez socket Dockeru:

Terminál
trivy image app:dev
grype app:dev

Sken obrazu Apple container

Uložte obraz do archívu OCI a rozbaľte ho do priečinka. Zadajte --platform: keď úložisko obrazov obsahuje len niektoré platformy obrazu, container image save bez neho zlyhá.

Terminál
container image pull python:3.11-slim
container image save --platform linux/arm64 -o python.tar python:3.11-slim
mkdir python-img && tar -xf python.tar -C python-img

Potom naskenujte priečinok. Trivy ho číta s --input, Grype s predponou oci-dir::

Terminál
trivy image --input python-img --severity HIGH,CRITICAL
grype oci-dir:python-img
Pozor
Neodovzdávajte súbor .tar. Archív z container image save začína položkou ./: Trivy hlási „file manifest.json not found in tar“ a Grype ho odmietne ako „potential path traversal attack“. Rozbalený priečinok funguje s oboma.

Čítanie výsledkov

  • Závažnosť: Critical, High, Medium, Low alebo Unknown. Začnite s Critical a High. --severity HIGH,CRITICAL obmedzí výstup Trivy.
  • Nainštalovaná a opravená verzia: ak opravená verzia existuje, aktualizujte základný obraz alebo balík a zostavte znova. trivy --ignore-unfixed a grype --only-fixed skryjú nálezy bez opravy.
  • „won't fix“: distribúcia sa rozhodla balík v tomto vydaní neopraviť. Použite novší základný obraz, alebo riziko prijmite.
  • Dva nástroje, dve databázy: Trivy a Grype často hlásia rôzne počty. Ani jeden sa nemýli; používajú rôzne zdroje.

Export SBOM

Súpis softvérových komponentov (SBOM) uvádza každý balík v obraze. Trivy zapisuje CycloneDX aj SPDX; sprievodný nástroj Grype, Syft, zapisuje tiež oba formáty.

Terminál
trivy image --input python-img --format cyclonedx -o sbom.cdx.json
trivy image --input python-img --format spdx-json -o sbom.spdx.json

Zlyhanie zostavenia pri vážnych nálezoch

V skripte nechajte návratový kód nastaviť skener. Grype skončí s nenulovým kódom, keď existuje nález zadanej alebo vyššej závažnosti; s Trivy použite --exit-code 1 --severity HIGH,CRITICAL.

Terminál
grype oci-dir:python-img --fail-on high
echo $?

Skenovanie z Gantry

Gantry 0.29.0 tieto kroky vykoná za vás. Zvoľte Skontrolovať zraniteľnosti… v ponuke obrazu alebo na paneli s nástrojmi detailu obrazu.

  • Gantry nájde Trivy alebo Grype v GANTRY_TRIVY alebo GANTRY_GRYPE, v PATH alebo v /opt/homebrew/bin a /usr/local/bin. Keď sú nainštalované oba, predvolený je Trivy. Bez skenera hárok zobrazí príkazy Homebrew.
  • Na apple/container Gantry uloží obraz s --platform, rozbalí ho a naskenuje priečinok. Na lokálnom Dockeri skenuje uložený archív. Pri Dockeri cez SSH skenuje kópiu tagu v registri.
  • Nálezy sú zoskupené podľa závažnosti, so symbolom a slovom, nielen farbou. Každý riadok obsahuje ID s odkazom, balík, nainštalovanú verziu a opravenú verziu. Filter nájde balík alebo ID.
  • Exportovať SBOM zapíše CycloneDX (oba nástroje) alebo SPDX (Trivy).
  • Zastaviť alebo zatvorenie hárka zastaví skener a odstráni dočasné súbory.

Otázky a odpovede

Ako naskenovať obraz Apple container na zraniteľnosti?

Uložte ho príkazom container image save --platform linux/arm64 -o app.tar app:dev, rozbaľte príkazom tar -xf app.tar -C app-img a potom spustite trivy image --input app-img alebo grype oci-dir:app-img. Gantry tieto kroky vykoná cez Skontrolovať zraniteľnosti….

Prečo Trivy alebo Grype zlyháva na archíve z container image save?

Archív začína položkou ./. Trivy v ňom nenájde manifest.json ani index.json a Grype túto položku považuje za path traversal. Archív rozbaľte a naskenujte priečinok.

Trivy, alebo Grype: ktorý použiť?

Oba sú bezplatné a open source. Trivy navyše nájde tajné údaje a chybné konfigurácie a zapisuje SPDX; Grype je malý a zameraný na balíky. Používajú rôzne databázy, takže spustenie oboch nájde viac. Gantry použije Trivy, keď sú nainštalované oba.

Inštaluje Gantry skenery?

Nie. Nainštalujte ich príkazom brew install trivy grype. Gantry ich hľadá v PATH, /opt/homebrew/bin a /usr/local/bin, alebo v GANTRY_TRIVY a GANTRY_GRYPE.

Potrebujem na skenovanie obrazov Docker Scout alebo účet Docker?

Nie. Trivy a Grype fungujú bez účtu, na obrazoch Dockeru aj na obrazoch Apple container.
