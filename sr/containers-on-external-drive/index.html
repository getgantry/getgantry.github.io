Gantry/Спољни диск

Контејнери и волумени на спољном диску

Слике, контејнери и волумени брзо попуне мали интерни диск. Уз Apple-ов алат container те податке можете да чувате на спољном SSD-у: поједине фасцикле преко монтираних фасцикли (bind mount) или цео коренски директоријум података. Овај водич приказује оба начина и како да искључите диск без оштећења.

Укратко. Форматирајте диск као APFS. За један пројекат монтирајте фасциклу: -v /Volumes/Fast/pg:/data. За све податке зауставите сервисе, копирајте ~/Library/Application Support/com.apple.container на диск командом cp -Rp и сваки пут покрећите сервисе командом container system start --app-root /Volumes/Fast/container.

Где су подаци сада

apple/container чува све своје податке у једној фасцикли, коренском директоријуму апликације (app root). Подразумевано је то ~/Library/Application Support/com.apple.container, са фасциклама за контејнере, садржај слика, снимке, волумене, језгра и мреже. Проверите путању и заузети простор:

Терминал
container system status | grep appRoot
container system df

Избор и форматирање диска

  • Користите SSD на USB-C или Thunderbolt прикључку. Диск са плочама ради, али се контејнери спорије покрећу.
  • Форматирајте га као APFS (ради и Mac OS Extended). Не користите exFAT, FAT ни NTFS: волумени су ретке (sparse) слике диска, а ти системи датотека немају ретке датотеке ни Unix дозволе.
  • Не користите мрежни диск за коренски директоријум апликације.
  • Дајте диску кратко име без размака, на пример Fast. Путања је тада /Volumes/Fast.
    Опција 1: подаци пројекта на диску преко монтираних фасцикли

Монтирана фасцикла (bind mount) дели фасциклу са вашег Mac-а са контејнером, а фасцикла може да буде на било ком диску. Ово је једноставан начин да велике податке, као што су база података или датотеке модела, држите ван интерног диска:

Терминал
mkdir -p /Volumes/Fast/site
container run -d --name web -p 8080:80 \
  -v /Volumes/Fast/site:/usr/share/nginx/html:ro nginx:alpine

Диск мора да буде повезан пре него што се контејнер покрене. Слике и сам контејнер остају на интерном диску.

    Опција 2: премештање свих apple/container података на диск

Овим се премештају слике, контејнери, снимци и волумени. Прво зауставите сервисе, да се ниједна датотека не мења током копирања:

Терминал
container system stop
cp -Rp ~/Library/Application\ Support/com.apple.container /Volumes/Fast/container
container system start --app-root /Volumes/Fast/container
container system status | grep appRoot
container ls -a && container image ls && container volume ls

Користите cp -Rp. У нашем тесту на macOS-у 27 (са APFS-а на APFS преко USB-а) задржао је слике волумена ретким и сачувао проширене атрибуте. ditto је сваку ретку слику записао у пуној величини, што може да попуни диск. Задржите стару фасциклу док не проверите да се ваши контејнери, слике и волумени приказују.

Пажња
CLI не памти --app-root. Свако container system start без те заставице поново користи интерну фасциклу. Користите заставицу сваки пут, на пример у алијасу љуске, и проверите paths.appRoot у container system status.

Gantry 0.27.0 покреће сервисе без --app-root када се повеже са хостом чији су сервиси заустављени. Прво покрените сервисе из терминала са заставицом; Gantry тада користи покренуте сервисе.

    Архивирање слика на диску

Да бисте ослободили простор без губитка слике, сачувајте је на спољни диск и обришите је. Поново је учитајте када вам затреба:

Терминал
mkdir -p /Volumes/Fast/images
container image save -o /Volumes/Fast/images/myapp.tar myapp:dev
container image delete myapp:dev
container image load -i /Volumes/Fast/images/myapp.tar
    Безбедно искључивање диска
  1. Зауставите контејнере који користе диск: container stop <name>.
  2. Ако је коренски директоријум апликације на диску, зауставите сервисе: container system stop.
  3. Избаците диск у Finder-у, па га искључите.

Ако диск нестане док контејнери раде са њега, они престају да раде, а уписи у току могу да се изгубе. Када поново повежете диск, покрените сервисе уз --app-root, а затим покрените контејнере.

    Спољни дискови у Gantry-ју

Gantry већ сада покреће монтиране фасцикле са било ког диска: у прозору Нови контејнер додајте волумен, изаберите фасциклу на спољном диску и путању у контејнеру.

    Docker Desktop и OrbStack

Docker Desktop премешта своју слику диска у Settings ▸ Resources ▸ Advanced ▸ Disk image location. OrbStack је у верзији 0.13.0 додао подешавање локације података. Погледајте поређење.

Питања и одговори

Могу ли да чувам Apple container слике на спољном диску?

Да. Покрените сервисе командом container system start --app-root /Volumes/Disk/container. Све слике, контејнери, снимци и волумени тада се налазе у тој фасцикли.

Који систем датотека треба да користи спољни диск?

APFS. Волумени су ретке слике диска, а контејнерима су потребне Unix дозволе, које exFAT, FAT и NTFS немају.

Како да копирам податке контејнера, а да не попуним диск?

Користите cp -Rp, који је у нашем тесту задржао ретке слике волумена малим. ditto је сваку ретку слику копирао у пуној величини.

Шта се дешава ако искључим диск док контејнери раде?

Контејнери који користе диск престају да раде, а подаци који још нису уписани могу да се изгубе. Пре избацивања диска зауставите контејнере и, ако је коренски директоријум апликације на диску, сервисе.

Да ли container CLI памти нову локацију?

Не. Прослеђујте --app-root свакој команди container system start. container system status приказује коренски директоријум у употреби као paths.appRoot.
