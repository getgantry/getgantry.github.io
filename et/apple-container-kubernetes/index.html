Gantry/Kubernetes apple/containeris

Kubernetes Apple containeris

apple/container saab käitada Kubernetese klastrit, mille sõlmed on konteinerid teie Macis. Gantry on selle GUI: looge klaster, jälgige sõlmede käivitumist, ühendage kubectl ja laadige oma kohalikud tõmmised, ilma pikkade container cluster käsuridadeta.

Lühidalt. apple/containeri hostis loob ja kustutab Gantry jaotis Klastrid Kubernetese klastreid käsuga container cluster (CLI 1.6.1) või container k8s (CLI 1.5.0 kuni 1.6.0). See toetab mitut töösõlme, kohandatud CNI-d, sõlmede vaadet, kubeconfigi ja kubectl-i konteksti ning käsku Laadi klastrisse kohalike tõmmiste jaoks.

Nõuded

  • Apple'i kiibiga Mac, macOS 26 ja Gantry (brew install --cask getgantry/tap/gantry).
  • container CLI 1.5.0 või uuem; soovitatav on 1.6.1. Töösõlmed ja CNI Puudub vajavad versiooni 1.6.0 või uuemat.
  • kubectl, kui soovite klastrit kasutada terminalist.

Klastri loomine

  1. Valige oma apple/containeri host ja avage külgribal Klastrid.
  2. Alustage uut klastrit ja täitke allolevad valikud.
  3. Looge see. Loendis kuvatakse uus klaster koos edenemisega reaalajas. Tühista peatab loomise ja kustutab juba loodud sõlmed.

Sama käsk CLI-s:

Shell
container cluster create --name dev --workers 2 --cpus 2 --memory 4G

Sõlmed ja klastri üksikasjad

Klastrite loend näitab iga klastrit koos sõlmedega: roll, olek ja aadress. Üksikasjade vaates on Ülevaade (kubectl-i kontekst, API-server, töösõlmed, sõlmede võrk), tabel Sõlmed, Uuri sõlmede toorandmete jaoks ning toimingud Kirjuta kubeconfig, Kopeeri kubectl-i konteksti käsk ja Kustuta.

kubectl-i ühendamine

CLI lisab klastri loomisel faili ~/.kube/config klastri järgi nimetatud konteksti. Kasutage Gantrys käsku Kopeeri kubectl-i konteksti käsk või tippige see ise:

Shell
kubectl --context dev get nodes

Klastri hoidmiseks eraldi failis kasutage käsku Kirjuta kubeconfig. Gantry käivitab käsu container cluster write-config; vaiketee on ~/.kube/<name>.kubeconfig.

Kohalike tõmmiste laadimine klastrisse

Koostage või tõmmake tõmmis apple/containeri hostis, seejärel paremklõpsake seda jaotises Tõmmised ja valige Laadi klastrisse. Gantry käivitab käsu container cluster load-image, mis kopeerib tõmmise iga sõlme containerd'sse. Kohalikuks arenduseks pole registrit vaja.

Shell
container cluster load-image --name dev myapp:dev

CNI valimine

Vaikimisi kasutatakse kaasasolevat kindneti manifesti. Valige Kohandatud manifest, et installida failist oma CNI, näiteks Calico või Cilium. Valige Puudub, et installida CNI hiljem ise; seni jäävad sõlmed olekusse NotReady.

Klastrid AI-agentide abil

Gantry MCP-serveril on tööriistad list_clusters, create_cluster ja delete_cluster, nii et agent, näiteks Claude Code, saab luua testi jaoks ajutise klastri ja selle pärast eemaldada.

Gantry MCP-serveri lisamine
claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp

Veel apple/containerist

Lugege apple/containeri juhendit, kust leiate iga container käsu ja sellele vastava Gantry funktsiooni, või vaadake Gantry võrdlust Docker Desktopi, OrbStacki ja Podman Desktopiga.

Küsimused ja vastused

Kas Apple container toetab Kubernetest?

Jah. container CLI loob Kubernetese klastreid, mille sõlmed töötavad konteineritena: container cluster CLI 1.6.1-s, container k8s CLI versioonides 1.5.0 kuni 1.6.0. Gantry annab sellele GUI.

Kas Gantry toetab container clusterit?

Jah. Gantry loetleb, loob ja kustutab apple/containeri hostides klastreid, näitab nende sõlmi, kirjutab kubeconfigi, kopeerib kubectl-i konteksti käsu ja laadib kohalikke tõmmiseid klastrisse. See kasutab käsku cluster või k8s vastavalt teie CLI versioonile.

Kuidas kasutada kubectl-i apple/containeri klastriga?

Kui CLI loob klastri, lisab see faili ~/.kube/config klastri järgi nimetatud kubeconfigi konteksti. Käivitage kubectl --context <name> get nodes. Eraldi faili jaoks kasutage Gantrys käsku Kirjuta kubeconfig; vaiketee on ~/.kube/<name>.kubeconfig.

Kuidas saada kohalik tõmmis klastrisse ilma registrita?

Paremklõpsake Gantrys jaotises Tõmmised tõmmist ja valige Laadi klastrisse. Gantry käivitab käsu container cluster load-image, mis kopeerib tõmmise iga sõlme containerd'sse.

Kas saab luua mitme sõlmega klastri?

Jah. Määrake loomislehel töösõlmede arv. Töösõlmed vajavad CLI versiooni 1.6.0 või uuemat.

Kas saab kasutada oma CNI-d, nt Calicot või Ciliumit?

Jah. Valige Kohandatud manifest ja valige manifestifail või valige Puudub ja rakendage CNI ise pärast klastri käivitumist. Sõlmed jäävad olekusse NotReady, kuni mõni CNI töötab. Puudub vajab CLI versiooni 1.6.0 või uuemat. Vaikimisi CNI on kaasasolev kindneti manifest.
