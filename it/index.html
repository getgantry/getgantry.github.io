La GUI nativa per macOS per Apple container
e Docker — tutta la tua flotta su un solo ponte.

Gantry è un'app per Mac gratuita e open source per lo strumento container di Apple e per Docker, in locale e via SSH. Gestisci container, cluster Kubernetes, macchine e progetti Compose su apple/container da un'unica finestra, accanto ai tuoi host Docker. Un'alternativa a Docker Desktop nativa per Mac. Niente Electron. Niente abbonamento. Nessun limite.

Scarica per macOS
$ brew install --cask getgantry/tap/gantry

Terminale exec integrato

Emulazione di terminale completa in qualsiasi container in esecuzione, locale o remoto, con temi a colori (Sistema, Solarized, Dracula, Nord).

Host remoti via SSH

Tunnel identici a docker -H ssh:// tramite dial-stdio: bastion ProxyJump, autenticazione con più chiavi, riconnessione automatica. Niente da installare sul server, segreti nel portachiavi. Importazione con un clic da ~/.ssh/config e docker context ls.

File browser con drag & drop

Sfoglia il file system di un container, sposta file dentro e fuori e trascina intere cartelle direttamente dal Finder, sugli host Docker come su apple/container.

Apri nel browser & inoltra

Un clic apre una porta pubblicata. Le porte SSH vengono inoltrate in automatico su localhost; se la porta è occupata, Gantry ne sceglie una libera che puoi modificare.

Condividi su Internet

Un clic espone una porta pubblicata tramite un Cloudflare Tunnel. Gantry installa cloudflared per te, poi ti dà un tunnel rapido (senza account, un URL *.trycloudflare.com) o un tunnel con nome sul tuo dominio: perfetto per un'anteprima di sviluppo, un webhook o per far raggiungere a un agente AI un container sul tuo Mac.

Compose, ovunque

I container sono raggruppati per progetto Compose. Avvia un file Compose su qualsiasi host (Docker locale, SSH o apple/container) con un editor YAML integrato; l'esecuzione si adatta a ogni motore.

Registri privati, in automatico

I pull usano il docker login che hai già fatto: Gantry risolve le credenziali da ~/.docker/config.json, dagli helper e dal portachiavi, sia alla creazione sia in Esecuzione rapida e in Compose.

Crea & scarica immagini

Trascina un Dockerfile sulla finestra per creare l'immagine con il log in tempo reale, oppure scaricala per riferimento con l'avanzamento di ogni layer. Aggiungi tag, ripulisci e leggi la cronologia dei layer. Un badge segnala le immagini create per un'architettura di CPU diversa da quella dell'host.

Recupera spazio

Un pannello mostra cosa occupa spazio (immagini orfane, container arrestati, volumi inutilizzati, cache di build) con le dimensioni, e ripulisce ogni voce o tutto insieme. Su apple/container esegue anche Compatta disco.

Touch ID per le azioni distruttive

Se lo attivi, Gantry chiede Touch ID (o la password di login) prima di rimuovere un container o eliminare un host. I segreti sono già nel portachiavi.

Temi del terminale

Vesti la shell integrata con Sistema, Solarized Dark, Dracula o Nord: una palette completa per primo piano, sfondo e 16 colori ANSI, applicata in tempo reale.

GUI per apple/container

La GUI nativa per macOS per Apple container

Lo strumento container di Apple esegue container Linux come VM leggere su chip Apple, ma esiste solo come strumento a riga di comando. Gantry è la sua app desktop: Gantry sta a container come Docker Desktop sta a Docker. Supporta ogni CLI container dalla 1.0 fino alla 1.6.1 consigliata, e attiva ogni funzione solo se la CLI installata la supporta.

Container, log, statistiche ed exec

Crea, avvia, arresta, forza l'arresto e ripulisci; log in tempo reale, statistiche, terminale exec, top ed esportazione tar, nella stessa interfaccia dei tuoi host Docker.

Cluster Kubernetes

Crea un cluster Kubernetes con più worker tramite container cluster, scegli il CNI (predefinito, nessuno o un tuo manifest), tieni d'occhio i nodi, scrivi il kubeconfig e copia il contesto kubectl. Scopri di più

Carica immagini locali in un cluster

Fai clic destro su un'immagine e scegli Carica nel cluster per inviarla a ogni nodo, senza push su un registro.

Macchine container in VS Code

Crea, avvia e arresta ambienti Linux container machine, imposta CPU e memoria, apri una shell o apri la macchina in VS Code tramite Remote-SSH.

Virtualizzazione annidata e kernel personalizzati

Avvia una macchina con la virtualizzazione annidata (M3 o successivo) o con un tuo kernel. Avvia i container da un kernel personalizzato con argomenti di avvio aggiuntivi.

Compose per Apple container

apple/container non ha compose. Gantry esegue il tuo docker-compose.yml: crea le immagini, la rete e i volumi, e avvia i servizi nell'ordine di depends_on. I nomi dei servizi vengono risolti tramite alias DNS di rete.

Alias DNS di rete

Alias dei container, alias di sottoalbero come .gateway e nomi brevi quando è impostato un dominio DNS predefinito. Ogni container riceve un IP instradabile e un hostname name.domain.

Gestisci il builder di immagini

Vedi stato, immagine, CPU, memoria e IP del builder. Avvialo con opzioni per CPU, memoria e DNS, arrestalo o eliminalo.

Accessi ai registri

Elenca, aggiungi e rimuovi gli accessi container registry. La password arriva alla CLI solo tramite stdin, e Gantry non ne conserva copia.

Installazione del kernel

Installa il kernel consigliato, un file del kernel o un archivio tar, con l'avanzamento in tempo reale. Gantry ti avvisa quando non è installato alcun kernel predefinito.

Servizi e log dei servizi

Avvia, arresta e riavvia i servizi di container, confronta le versioni di client e server e segui in tempo reale i log dei servizi, filtrati per livello, servizio e testo.

Editor delle proprietà di sistema

Modifica le proprietà di sistema di container in config.toml. Gantry segnala le modifiche che richiedono un riavvio e riavvia i servizi per te.

Salva come immagine e Compatta disco

Salva un container come immagine (container commit) e recupera spazio su disco con Compatta disco (container clean), disponibile anche nel pannello Recupera spazio.

File browser: caricamento e download

Sfoglia i file di un container, scaricali o trascinali nel Finder (container copy), e trascina dentro file o intere cartelle.

Esecuzione rapida e Finder

Scegli un'immagine, condividi una cartella, mappa le porte e scegli un dominio, poi avvia. Fai clic destro su un file Compose nel Finder e aprilo con Gantry.

Etichette che contengono =

La CLI container rifiuta i valori delle etichette con =. Gantry li codifica alla creazione e li decodifica in lettura, così un valore come a=b resta intatto.

Una flotta, due runtime

Gli host apple/container stanno accanto ai tuoi host Docker locali e SSH in un'unica dashboard, con le stesse sparkline, lo stesso stato di integrità e le stesse notifiche di guasto.

Strumenti MCP per gli agenti

Il server MCP incluso dà agli agenti la stessa portata: container, macchine, cluster e strumenti di sistema apple_* per servizi, builder, registri, proprietà, log e kernel.

FAQ

Domande e risposte

Tutto quello che potresti voler sapere prima di installare Gantry.

Qual è la migliore GUI per Apple container?

Gantry è una GUI nativa per macOS, gratuita e open source, pensata per lo strumento container di Apple (apple/container). Copre il ciclo di vita dei container, i log, le statistiche e un terminale exec, oltre alle parti della CLI che le altre GUI non raggiungono: cluster Kubernetes (container cluster), macchine container, builder di immagini, accessi ai registri, kernel, log dei servizi e proprietà di sistema. Supporta le CLI dalla 1.0 alla 1.6.1 e attiva ogni funzione solo se la tua CLI la supporta. Leggi la guida ad apple/container.

Cos'è Apple container (apple/container)?

apple/container è lo strumento open source di Apple per eseguire container Linux su un Mac. Ogni container gira nella propria macchina virtuale leggera, basata sul framework Virtualization di Apple. Richiede un Mac con chip Apple ed è distribuito come strumento a riga di comando chiamato container, senza app desktop. Gantry è quell'app desktop.

Gantry supporta container cluster e Kubernetes?

Sì. Su un host apple/container, Gantry crea ed elimina cluster Kubernetes con container cluster (CLI 1.6.1; le CLI dalla 1.5.0 alla 1.6.0 usano container k8s). Scegli il nome, il numero di worker, le CPU, la memoria, l'immagine dei nodi e il CNI (predefinito, nessuno o un manifest personalizzato). Gantry mostra i nodi, scrive il kubeconfig, copia il comando del contesto kubectl e carica le immagini locali nel cluster. Vedi Kubernetes su apple/container.

Si può usare docker compose con Apple container?

Sì. apple/container non ha un comando compose, quindi è Gantry a orchestrare tramite la CLI container: crea le immagini dei servizi build:, crea la rete del progetto e i volumi con nome, e avvia ogni servizio nell'ordine di depends_on con le etichette Compose standard. I nomi dei servizi vengono risolti tramite alias DNS di rete. Apri un docker-compose.yml dal Finder, dal menu File o trascinandolo sulla finestra.

Come si apre una macchina container in VS Code?

Avvia la macchina in Gantry e fai clic su Apri in VS Code. Gantry apre la macchina in VS Code tramite Remote-SSH, come nell'esempio container-machine-vscode di Apple. L'immagine della macchina deve eseguire sshd, e devi avere installato VS Code con l'estensione Remote-SSH.

Quali versioni di apple/container supporta Gantry?

Gantry richiede la CLI container 1.0 o successiva e consiglia la 1.6.1. Legge la versione installata e mostra solo le funzioni che quella versione supporta, per esempio Salva come immagine (1.6), Compatta disco (1.4) e i worker dei cluster (1.6). Se la CLI manca o è vecchia, Gantry propone una configurazione guidata.

Gantry può gestire builder, registri e kernel di apple/container?

Sì. La sezione Sistema di un host apple/container avvia, arresta ed elimina il builder di immagini con opzioni per CPU, memoria e DNS; elenca, aggiunge e rimuove gli accessi ai registri (la password arriva alla CLI solo tramite stdin); installa il kernel consigliato, un file del kernel o un archivio tar; trasmette i log dei servizi in tempo reale; e modifica le proprietà di sistema in config.toml.

Gantry è un'alternativa a Docker Desktop, OrbStack o Podman Desktop?

Per la GUI, sì. Gantry è un'app nativa e gratuita per macOS per gestire container, immagini, volumi, reti, log e statistiche. È un client, non un motore: usa il daemon Docker che hai già (Docker Desktop, OrbStack, Colima) o lo strumento container di Apple, e aggiunge una vista multi-host, host SSH e un server MCP. Vedi il confronto.

Gantry è gratis?

Sì. Gantry è gratuito e open source con licenza MIT. Nessun abbonamento, nessun account e nessun limite al numero di host o di container.

Cosa serve per usare Gantry?

macOS 26 o successivo su chip Apple o Intel, più un daemon Docker (Docker Desktop, OrbStack, Colima o simili) oppure lo strumento container di Apple. apple/container richiede a sua volta un chip Apple, quindi su un Mac Intel Gantry gestisce solo host Docker.

Gantry funziona con OrbStack, Colima e Docker Desktop?

Sì. Gantry comunica direttamente con l'API di Docker Engine tramite il socket Unix, quindi funziona con qualsiasi daemon che la espone, compresi OrbStack, Colima e Docker Desktop.

Gantry può gestire host Docker remoti?

Sì. Gantry si connette ai daemon remoti via SSH, come docker -H ssh://, con bastion ProxyJump, autenticazione con più chiavi e riconnessione automatica. Sul server non serve installare nulla, e i segreti restano nel portachiavi di macOS.

Gantry mi avvisa quando un container si guasta?

Sì. Gantry invia una notifica nativa di macOS quando un container va in crash, esaurisce la memoria o non supera il controllo di integrità, su qualsiasi host: locale, SSH o apple/container. Fai clic sulla notifica per andare al container. Arresti e riavvii che avvii da Gantry non generano notifiche, e puoi disattivare la funzione nelle Impostazioni.

Gantry può scaricare immagini da registri privati?

Sì. Sugli host Docker, Gantry legge le credenziali dal tuo ~/.docker/config.json (lo stesso docker login che hai già fatto), comprese autenticazione inline, credential helper e portachiavi di macOS. Sugli host apple/container gestisce gli accessi container registry.

Gantry può esporre un container locale su Internet?

Sì. Con un clic su una porta pubblicata la condividi tramite Cloudflare Tunnel. Se serve, Gantry installa cloudflared, poi avvia un tunnel rapido (senza account Cloudflare, con un URL temporaneo trycloudflare.com) o un tunnel con nome sul tuo hostname. L'URL pubblico appare sotto la porta, con i comandi per aprirlo, copiarlo e fermarlo.

Gantry è un'app Electron?

No. Gantry è un'app nativa scritta con SwiftUI e Swift 6. L'interfaccia è in inglese e cinese semplificato e segue la lingua di sistema di macOS.

Come si installa Gantry?

Esegui brew install --cask getgantry/tap/gantry, oppure scarica l'ultima release da GitHub e trascina Gantry.app in Applicazioni.

Gli agenti AI possono controllare Gantry?

Sì. Gantry include un server MCP e App Intents di macOS, così Claude, Comandi Rapidi, Siri e gli script arrivano dove arriva la GUI, su ogni host, compresi quelli SSH: container, immagini, volumi, reti, Compose, macchine apple/container, cluster Kubernetes, strumenti di sistema apple_* (servizi, builder, registri, proprietà, log, kernel) e condivisione delle porte. Aggiungilo con claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp.
