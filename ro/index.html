GUI-ul nativ macOS pentru Apple container
și Docker — toată flota dvs. pe un singur panou.

Gantry este o aplicație Mac gratuită și open source pentru instrumentul container de la Apple și pentru Docker, local și prin SSH. Rulați containere, clustere Kubernetes, mașini și proiecte Compose pe apple/container dintr-o singură fereastră, lângă gazdele Docker. O alternativă nativă la Docker Desktop pentru Mac. Fără Electron. Fără abonament. Fără limite.

Descarcă pentru macOS
$ brew install --cask getgantry/tap/gantry

Terminal exec integrat

Emulare completă de terminal în orice container care rulează, local sau la distanță — cu teme de culori (Sistem, Solarized, Dracula, Nord).

Gazde la distanță prin SSH

Tunele exact ca docker -H ssh:// prin dial-stdio — bastioane ProxyJump, autentificare cu mai multe chei, reconectare automată. Nimic de instalat pe server, secretele în portchei. Import cu un clic din ~/.ssh/config și docker context ls.

Browser de fișiere cu tragere și plasare

Răsfoiți sistemul de fișiere al unui container, mutați fișiere înăuntru și în afară și plasați dosare întregi direct din Finder — atât pe gazde Docker, cât și pe gazde apple/container.

Deschidere în browser și redirecționare

Un clic deschide un port publicat. Porturile SSH sunt tunelate automat către localhost — iar dacă portul e ocupat, Gantry alege unul liber, pe care îl puteți modifica.

Partajare pe internet

Un clic expune un port publicat printr-un Cloudflare Tunnel. Gantry instalează cloudflared pentru dvs., apoi vă oferă un tunel rapid (fără cont, cu un URL *.trycloudflare.com) sau un tunel cu nume pe propriul domeniu — perfect pentru o previzualizare de dezvoltare, un webhook sau pentru ca un agent AI să ajungă la un container de pe Mac.

Compose oriunde

Containerele sunt grupate după proiectul Compose. Porniți un fișier Compose pe orice gazdă — Docker local, SSH sau apple/container — cu un editor YAML integrat; executorul se adaptează fiecărui motor.

Registre private, automat

Descărcările folosesc docker login-ul pe care l-ați făcut deja — Gantry preia datele de autentificare din ~/.docker/config.json, din helpers și din portchei, la creare, în Rulare rapidă și în Compose.

Construiți și descărcați imagini

Trageți un Dockerfile în fereastră pentru build cu jurnal în timp real sau descărcați după referință, cu progres pe fiecare strat. Adăugați taguri, curățați și citiți istoricul straturilor. O insignă marchează imaginile construite pentru altă arhitectură de CPU decât cea a gazdei.

Recuperați spațiu

Un panou arată ce ocupă spațiu — imagini orfane, containere oprite, volume nefolosite, cache de build — cu dimensiunile lor și curăță fiecare categorie sau pe toate. Pe apple/container rulează și Compactează discul.

Touch ID pentru acțiuni distructive

Dacă activați opțiunea, Gantry cere Touch ID — sau parola de autentificare — înainte de a elimina un container sau de a șterge o gazdă. Secretele stau deja în portchei.

Teme pentru terminal

Îmbrăcați shellul integrat în Sistem, Solarized Dark, Dracula sau Nord — o paletă completă pentru prim-plan, fundal și 16 culori ANSI, aplicată pe loc.

GUI pentru apple/container

GUI-ul nativ macOS pentru Apple container

Instrumentul container de la Apple rulează containere Linux ca mașini virtuale ușoare pe Apple silicon, dar vine doar ca instrument de linie de comandă. Gantry este aplicația desktop pentru el: ce este Docker Desktop pentru Docker, este Gantry pentru container. Acceptă orice CLI container de la 1.0 până la versiunea recomandată 1.6.1 și activează fiecare funcție doar când CLI-ul instalat o acceptă.

Containere, jurnale, statistici și exec

Creați, porniți, opriți, forțați oprirea și curățați; jurnale în timp real, statistici, un terminal exec, top și export tar, în aceeași interfață ca gazdele Docker.

Clustere Kubernetes

Creați cu container cluster un cluster Kubernetes cu mai mulți workeri, alegeți CNI-ul (implicit, niciunul sau propriul manifest), urmăriți nodurile, salvați kubeconfig și copiați contextul kubectl. Aflați mai multe

Încărcarea imaginilor locale într-un cluster

Faceți clic dreapta pe o imagine și alegeți Încarcă în cluster pentru a o trimite pe toate nodurile, fără a o trimite într-un registru.

Mașini container în VS Code

Creați, porniți și opriți medii Linux container machine, setați CPU-urile și memoria, deschideți un shell sau deschideți mașina în VS Code prin Remote-SSH.

Virtualizare imbricată și kerneluri personalizate

Porniți o mașină cu virtualizare imbricată (M3 sau mai nou) sau cu propriul kernel. Porniți containere dintr-un kernel personalizat, cu argumente de boot suplimentare.

Compose pentru Apple container

apple/container nu are compose. Gantry rulează fișierul dvs. docker-compose.yml: construiește, creează rețeaua și volumele și pornește serviciile în ordinea din depends_on. Numele serviciilor se rezolvă prin aliasuri DNS de rețea.

Aliasuri DNS de rețea

Aliasuri de container, aliasuri de subarbore precum .gateway și nume scurte când este setat un domeniu DNS implicit. Fiecare container primește un IP rutabil și un hostname name.domain.

Gestionarea builderului de imagini

Vedeți starea builderului, imaginea, CPU-urile, memoria și IP-ul. Porniți-l cu opțiuni de CPU, memorie și DNS, opriți-l sau ștergeți-l.

Autentificări la registre

Listați, adăugați și eliminați autentificări container registry. Parola ajunge la CLI doar prin stdin, iar Gantry nu păstrează nicio copie.

Instalarea kernelului

Instalați kernelul recomandat, un fișier kernel sau o arhivă tar, cu progresul în timp real. Gantry vă avertizează când nu este instalat niciun kernel implicit.

Servicii și jurnalele serviciilor

Porniți, opriți și reporniți serviciile container, comparați versiunile clientului și serverului și urmăriți în timp real jurnalele serviciilor, filtrate după nivel, serviciu și text.

Editor de proprietăți de sistem

Editați proprietățile de sistem container din config.toml. Gantry marchează modificările care necesită o repornire și repornește serviciile în locul dvs.

Salvare ca imagine și Compactează discul

Salvați un container ca imagine (container commit) și recuperați spațiu pe disc cu Compactează discul (container clean), disponibil și în panoul Recuperează spațiu.

Browser de fișiere: încărcare și descărcare

Răsfoiți fișierele unui container, descărcați-le sau trageți-le în Finder (container copy) și plasați înăuntru fișiere sau dosare întregi.

Rulare rapidă și Finder

Alegeți o imagine, partajați un dosar, mapați porturi, alegeți un domeniu și rulați. Faceți clic dreapta pe un fișier Compose în Finder și deschideți-l cu Gantry.

Etichete care conțin =

CLI-ul container respinge valorile de etichetă care conțin =. Gantry le codifică la creare și le decodifică la citire, așa că o valoare precum a=b rămâne intactă.

O flotă, două runtime-uri

Gazdele apple/container stau lângă gazdele Docker locale și SSH pe același panou, cu aceleași minigrafice, aceeași stare de sănătate și aceleași notificări de eroare.

Instrumente MCP pentru agenți

Serverul MCP inclus le oferă agenților aceeași acoperire: containere, mașini, clustere și instrumentele de sistem apple_* pentru servicii, builder, registre, proprietăți, jurnale și kerneluri.

Tot ce ați putea vrea să știți înainte să instalați Gantry.

Care este cel mai bun GUI pentru Apple container?

Gantry este un GUI nativ macOS, gratuit și open source, creat pentru instrumentul container de la Apple (apple/container). Acoperă ciclul de viață al containerelor, jurnalele, statisticile și un terminal exec, plus părțile CLI-ului la care alte GUI-uri nu ajung: clustere Kubernetes (container cluster), mașini container, builderul de imagini, autentificările la registre, kernelurile, jurnalele serviciilor și proprietățile de sistem. Este compatibil cu CLI 1.0–1.6.1 și activează fiecare funcție doar când CLI-ul dvs. o acceptă. Consultați ghidul apple/container.

Ce este Apple container (apple/container)?

apple/container este instrumentul open source de la Apple pentru rularea containerelor Linux pe Mac. Fiecare container rulează în propria mașină virtuală ușoară, construită pe framework-ul Virtualization de la Apple. Necesită un Mac cu Apple silicon și vine ca instrument de linie de comandă numit container, fără aplicație desktop. Gantry adaugă această aplicație desktop.

Gantry acceptă container cluster și Kubernetes?

Da. Pe o gazdă apple/container, Gantry creează și șterge clustere Kubernetes cu container cluster (CLI 1.6.1; CLI 1.5.0–1.6.0 folosesc container k8s). Alegeți numele, numărul de workeri, CPU-urile, memoria, imaginea nodurilor și CNI-ul (implicit, niciunul sau un manifest personalizat). Gantry afișează nodurile, salvează kubeconfig, copiază comanda de context kubectl și încarcă imagini locale în cluster. Consultați Kubernetes pe apple/container.

Pot folosi docker compose cu Apple container?

Da. apple/container nu are comanda compose, așa că Gantry face orchestrarea prin CLI-ul container: construiește serviciile cu build:, creează rețeaua proiectului și volumele cu nume și pornește fiecare serviciu în ordinea din depends_on, cu etichetele Compose standard. Numele serviciilor se rezolvă prin aliasuri DNS de rețea. Deschideți un docker-compose.yml din Finder, din meniul Fișier sau trăgându-l în fereastră.

Cum deschid o mașină container în VS Code?

Porniți mașina în Gantry și faceți clic pe Deschide în VS Code. Gantry deschide mașina în VS Code prin Remote-SSH, ca în exemplul container-machine-vscode de la Apple. Imaginea mașinii trebuie să ruleze sshd, iar VS Code cu extensia Remote-SSH trebuie să fie instalat.

Ce versiuni apple/container acceptă Gantry?

Gantry necesită CLI-ul container 1.0 sau o versiune ulterioară și recomandă 1.6.1. Citește versiunea instalată și afișează doar funcțiile acceptate de acea versiune, de exemplu Salvează ca imagine (1.6), Compactează discul (1.4) și workerii de cluster (1.6). Dacă CLI-ul lipsește sau este vechi, Gantry oferă o configurare ghidată.

Poate Gantry gestiona builderul, registrele și kernelul apple/container?

Da. Secțiunea Sistem a unei gazde apple/container pornește, oprește și șterge builderul de imagini, cu opțiuni de CPU, memorie și DNS; listează, adaugă și elimină autentificări la registre (parola ajunge la CLI doar prin stdin); instalează kernelul recomandat, un fișier kernel sau o arhivă tar; transmite în timp real jurnalele serviciilor; și editează proprietățile de sistem din config.toml.

Este Gantry o alternativă la Docker Desktop, OrbStack sau Podman Desktop?

Ca GUI, da. Gantry este o aplicație nativă macOS gratuită pentru gestionarea containerelor, imaginilor, volumelor, rețelelor, jurnalelor și statisticilor. Este un client, nu un motor: folosește daemonul Docker pe care îl rulați deja (Docker Desktop, OrbStack, Colima) sau instrumentul container de la Apple și adaugă o vizualizare pentru mai multe gazde, gazde SSH și un server MCP. Consultați comparația.

Gantry este gratuit?

Da. Gantry este gratuit și open source, sub licența MIT. Fără abonament, fără cont și fără limită de gazde sau de containere.

De ce am nevoie ca să rulez Gantry?

macOS 26 sau o versiune ulterioară pe Apple silicon sau Intel, plus un daemon Docker (Docker Desktop, OrbStack, Colima sau similar) ori instrumentul container de la Apple. apple/container în sine necesită Apple silicon, așa că pe un Mac cu Intel Gantry gestionează doar gazde Docker.

Gantry funcționează cu OrbStack, Colima și Docker Desktop?

Da. Gantry comunică direct cu API-ul Docker Engine prin socketul Unix, deci funcționează cu orice daemon care îl expune, inclusiv OrbStack, Colima și Docker Desktop.

Poate Gantry gestiona gazde Docker la distanță?

Da. Gantry se conectează la daemonuri la distanță prin SSH, la fel ca docker -H ssh://, cu bastioane ProxyJump, autentificare cu mai multe chei și reconectare automată. Nu trebuie instalat nimic pe server, iar secretele stau în portcheiul macOS.

Mă anunță Gantry când un container cade?

Da. Gantry trimite o notificare nativă macOS când un container se închide neașteptat, rămâne fără memorie sau nu trece verificarea de sănătate pe orice gazdă: locală, SSH sau apple/container. Faceți clic pe ea pentru a ajunge la container. Opririle și repornirile pe care le lansați din Gantry nu generează notificări, iar funcția se poate dezactiva din Configurări.

Poate Gantry descărca imagini din registre private?

Da. Pe gazdele Docker, Gantry citește datele de autentificare din ~/.docker/config.json (același docker login pe care l-ați rulat deja), inclusiv autentificarea inline, credential helpers și portcheiul macOS. Pe gazdele apple/container, gestionează autentificările container registry.

Poate Gantry expune un container local pe internet?

Da. Un clic pe un port publicat îl partajează printr-un Cloudflare Tunnel. Gantry instalează cloudflared dacă este nevoie, apoi pornește un tunel rapid (fără cont Cloudflare, cu un URL temporar trycloudflare.com) sau un tunel cu nume pe propriul dvs. hostname. URL-ul public apare sub port, cu butoane pentru deschidere, copiere și oprire.

Este Gantry o aplicație Electron?

Nu. Gantry este o aplicație nativă construită cu SwiftUI și Swift 6. Interfața este în engleză și chineză simplificată și urmează limba sistemului macOS.

Cum instalez Gantry?

Rulați brew install --cask getgantry/tap/gantry sau descărcați cea mai recentă versiune de pe GitHub și trageți Gantry.app în Aplicații.

Pot agenții AI să controleze Gantry?

Da. Gantry include un server MCP și App Intents macOS, așa că Claude, Scurtături, Siri și scripturile ajung la fel de departe ca GUI-ul, pe fiecare gazdă, inclusiv pe gazdele SSH: containere, imagini, volume, rețele, Compose, mașini apple/container, clustere Kubernetes, instrumentele de sistem apple_* (servicii, builder, registre, proprietăți, jurnale, kernel) și partajarea porturilor. Adăugați-l cu claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp.
