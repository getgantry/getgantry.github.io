Nativní GUI pro Apple container
a Docker na macOS – celá flotila v jednom okně.

Gantry je bezplatná open-source aplikace pro Mac pro nástroj container od Applu i pro Docker, lokálně i přes SSH. Spouštějte kontejnery, clustery Kubernetes, stroje a projekty Compose na apple/container z jednoho okna, hned vedle hostitelů Docker. Bezplatná alternativa k Docker Desktop a OrbStack pro Mac. Žádný Electron. Žádné předplatné. Žádné limity.

$ brew install --cask getgantry/tap/gantry

Novinky ve verzi 0.27.0

Kubernetes, Apple Intelligence a zbytek macOS

Gantry 0.27.0 přidává prohlížeč Kubernetes, vysvětluje selhané kontejnery pomocí Apple Intelligence a spolupracuje se Spotlightem, Siri, widgety a Ovládacím centrem. Podporuje apple/container 1.7.1 a má nový vzhled podle Human Interface Guidelines od Applu.

Prohlížeč Kubernetes

Procházejte pody, deploymenty, StatefulSety, DaemonSety, služby, ingressy, ConfigMapy, secrety, uzly a události libovolného kontextu kubeconfig. Sledujte logy podů, otevřete shell, přesměrujte port, škálujte, restartujte nasazení a použijte YAML. Gantry komunikuje s Kubernetes API sama, takže cluster vytvořený příkazem container cluster create můžete procházet hned, bez instalace čehokoli dalšího: bez kubectl.

Vysvětlit selhání s Apple Intelligence

U spadlého kontejneru nebo neúspěšné operace zvolte Vysvětlit selhání…. Gantry pošle nedávné logy a podrobnosti, bez hodnot proměnných prostředí a textu, který vypadá jako tajný údaj, modelu v zařízení a zobrazí pravděpodobnou příčinu, důkazy a další kroky. Dlouhé logy mohou jít do Private Cloud Compute (macOS 27). Panel ukazuje přesně, co bylo odesláno.

Součást macOS

Oznámení s akcemi Restartovat, Zobrazit logy a Kopírovat jako prompt. Spotlight najde kontejnery, projekty Compose a hostitele. Akce pro Siri a Zkratky, widget se stavem flotily, ovládací prvky v Ovládacím centru pro služby apple/container nebo oblíbený kontejner a odkazy gantry:// pro skripty.

Paleta příkazů

Stiskněte ⌘K a pište. Jedno hledání pokrývá kontejnery, projekty Compose, image, svazky, sítě, stroje, clustery a hostitele, s akcemi jako Spustit, Zobrazit logy a Otevřít shell.

Vestavěný terminál exec

Plnohodnotná emulace terminálu v jakémkoli běžícím kontejneru, místním i vzdáleném – s barevnými motivy (System, Solarized, Dracula, Nord).

Vzdálení hostitelé přes SSH

Tunelování přesně jako docker -H ssh:// přes dial-stdio – bastiony ProxyJump, ověřování více klíči, automatické opětovné připojení. Na serveru nic neinstalujete, tajné údaje jsou v Klíčence. Import jedním kliknutím z ~/.ssh/config a docker context ls.

Prohlížeč souborů s přetahováním

Procházejte souborový systém kontejneru, přesouvejte soubory dovnitř i ven a vkládejte celé složky přímo z Finderu – na hostitelích Docker i apple/container.

Otevření v prohlížeči a přesměrování

Jedno kliknutí otevře publikovaný port. Porty přes SSH se automaticky tunelují na localhost – a pokud je port obsazený, Gantry vybere volný, který můžete změnit.

Sdílení na internet

Jedno kliknutí zpřístupní publikovaný port přes Cloudflare Tunnel. Gantry za vás nainstaluje cloudflared a pak nabídne rychlý tunel (bez účtu, URL *.trycloudflare.com) nebo pojmenovaný tunel na vaší vlastní doméně – ideální pro náhled vývojové verze, webhook nebo přístup AI agenta ke kontejneru na vašem Macu.

Compose kdekoli

Kontejnery se seskupují podle projektu Compose. Spusťte soubor Compose na libovolném hostiteli – místním Dockeru, SSH nebo apple/container – s vestavěným editorem YAML; spouštění se přizpůsobí danému enginu.

Soukromé registry automaticky

Stahování využívá docker login, který už máte za sebou – Gantry načte přihlašovací údaje z ~/.docker/config.json, credential helperů a Klíčenky, při vytváření kontejneru, v Rychlém spuštění i v Compose.

Sestavení a stahování imagů

Přetáhněte Dockerfile do okna a sestavte image s živým logem, nebo stáhněte image podle reference s průběhem pro každou vrstvu. Přidávejte tagy, pročišťujte a čtěte historii vrstev. Štítek označí image sestavené pro jinou architekturu CPU, než má hostitel.

Uvolněte místo

Jeden panel ukáže, co zabírá místo – nepojmenované image, zastavené kontejnery, nepoužívané svazky, mezipaměť sestavení – včetně velikostí, a odstraní každou položku zvlášť nebo vše najednou. Na apple/container spustí i Zmenšit disk.

Touch ID u destruktivních akcí

Zapněte si to a Gantry si před odstraněním kontejneru nebo smazáním hostitele vyžádá Touch ID – nebo přihlašovací heslo. Tajné údaje už stejně leží v Klíčence.

Motivy terminálu

Oblečte vestavěný shell do motivu System, Solarized Dark, Dracula nebo Nord – kompletní paleta popředí, pozadí a 16 barev ANSI, použitá okamžitě.

GUI pro apple/container

Nativní GUI pro Apple container na macOS

Nástroj container od Applu spouští linuxové kontejnery jako odlehčené virtuální stroje na Apple silicon, ale dodává se jen jako nástroj příkazového řádku. Gantry je pro něj desktopová aplikace: čím je Docker Desktop pro Docker, tím je Gantry pro container. Podporuje každé CLI container od 1.0 po doporučenou 1.7.1 a každou funkci zapne, až když ji nainstalované CLI podporuje.

Kontejnery, logy, statistiky a exec

Vytváření, spouštění, zastavování, vynucené ukončení a pročištění; živé logy, statistiky, terminál exec, top a export do taru – ve stejném rozhraní jako vaši hostitelé Docker.

Clustery Kubernetes

Vytvořte cluster Kubernetes pomocí container cluster: nastavte velikost řídicí roviny a pracovních uzlů zvlášť, zvolte CNI a sledujte uzly, verzi Kubernetes a kontext kubeconfig. Uzly clusteru jsou chráněné proti nechtěnému zastavení a smazání. Více

Místní image v clusteru

V CLI 1.7 zapněte Používat místní image (--shared-image-store) a pody spustí image, které sestavíte nebo stáhnete, bez registru. V CLI 1.5 a 1.6 klikněte na image pravým tlačítkem a zvolte Načíst do clusteru.

Jasné rady, když je instalace poškozená

Když služby clusteru neodpovídají, Gantry řekne proč. Build z Homebrew bez služeb clusteru dostane odkaz na podepsaný instalátor, ve všech ostatních případech se zobrazí tlačítko Restartovat služby.

Stroje container ve VS Code

Vytvářejte, spouštějte a zastavujte linuxová prostředí container machine, nastavte CPU a paměť, otevřete shell nebo otevřete stroj ve VS Code přes Remote-SSH.

Vnořená virtualizace a vlastní jádra

Spusťte stroj s vnořenou virtualizací (M3 nebo novější) nebo s vlastním jádrem. Spouštějte kontejnery z vlastního jádra s dalšími spouštěcími argumenty.

Compose pro Apple container

apple/container nemá compose. Gantry spustí váš docker-compose.yml: sestaví, vytvoří síť a svazky a spustí služby v pořadí podle depends_on. Názvy služeb se překládají přes aliasy DNS v síti.

Aliasy DNS v síti

Aliasy kontejnerů, aliasy podstromu jako .gateway a krátké názvy, když je nastavena výchozí doména DNS. Každý kontejner dostane směrovatelnou IP adresu a název hostitele name.domain.

Správa builderu imagů

Zobrazte stav builderu, image, CPU, paměť a IP. Spusťte ho s možnostmi CPU, paměti a DNS, zastavte nebo smažte. Když je image builderu zastaralý, Gantry nabídne jeho opětovné vytvoření.

Přihlášení k registrům

Vypisujte, přidávejte a odebírejte přihlášení container registry. Heslo jde do CLI výhradně přes stdin a Gantry si žádnou kopii neponechává.

Instalace jádra

Nainstalujte doporučené jádro, soubor jádra nebo archiv tar s průběhem v reálném čase. Gantry upozorní, když není nainstalováno žádné výchozí jádro.

Služby a logy služeb

Spouštějte, zastavujte a restartujte služby container, porovnávejte verze klienta a serveru a streamujte logy služeb filtrované podle úrovně, služby a textu.

Editor systémových vlastností

Upravujte systémové vlastnosti container v config.toml. Gantry označí změny, které vyžadují restart, a služby restartuje za vás. V CLI 1.7 upravuje také výchozí hodnoty [container.dns]: jmenné servery, vyhledávací domény a možnosti.

Uložení jako image a Zmenšit disk

Uložte kontejner jako image (container commit) a uvolněte místo na disku funkcí Zmenšit disk (container clean), dostupnou i v panelu Uvolnit místo.

Prohlížeč souborů: nahrávání a ukládání

Procházejte soubory kontejneru, ukládejte je do Macu nebo je přetáhněte do Finderu (container copy) a vkládejte soubory i celé složky přetažením.

Rychlé spuštění a Finder

Vyberte image, sdílejte složku, namapujte porty a zvolte doménu – a spusťte. Na soubor Compose ve Finderu klikněte pravým tlačítkem a otevřete ho v Gantry.

Štítky se znakem =

CLI container odmítá hodnoty štítků se znakem =. Gantry je při vytváření zakóduje a při čtení dekóduje, takže hodnota jako a=b zůstane beze změny.

Jedna flotila, dva runtimy

Hostitelé apple/container jsou na jednom přehledu vedle místního Dockeru a hostitelů SSH, se stejnými grafy, stavem zdraví a oznámeními o selhání.

FAQ

Otázky a odpovědi

Vše, co byste mohli chtít vědět, než Gantry nainstalujete.

Jaké je nejlepší GUI pro Apple container?

Gantry je bezplatné nativní open-source GUI pro macOS, vytvořené pro nástroj container od Applu (apple/container). Pokrývá životní cyklus kontejnerů, logy, statistiky a terminál exec a navíc části CLI, na které jiná GUI nedosáhnou: clustery Kubernetes (container cluster), stroje container, builder imagů, přihlášení k registrům, jádra, logy služeb a systémové vlastnosti. Podporuje CLI 1.0 až 1.7.1 a každou funkci zapne, až když ji vaše CLI podporuje. Viz průvodce apple/container.

Co je Apple container (apple/container)?

apple/container je open-source nástroj od Applu pro spouštění linuxových kontejnerů na Macu. Každý kontejner běží ve vlastním odlehčeném virtuálním stroji postaveném na frameworku Virtualization od Applu. Vyžaduje Mac s Apple silicon a dodává se jako nástroj příkazového řádku container, bez desktopové aplikace. Gantry je ta desktopová aplikace.

Podporuje Gantry container cluster a Kubernetes?

Ano. Na hostiteli apple/container Gantry vytváří a maže clustery Kubernetes pomocí container cluster (CLI 1.6.1 a 1.7; CLI 1.5.0 až 1.6.0 používá container k8s). Zvolíte název, pracovní uzly, CPU a paměť řídicí roviny a pracovních uzlů (1.7), image uzlu, CNI a to, zda uzly používají vaše místní image (1.7). Gantry zobrazí uzly, zapíše kubeconfig a otevře cluster ve svém prohlížeči Kubernetes. Viz Kubernetes na apple/container.

Jde používat docker compose s Apple container?

Ano. apple/container nemá příkaz compose, a tak orchestraci přes CLI container zajišťuje Gantry: sestaví služby s build:, vytvoří síť projektu a pojmenované svazky a spustí služby v pořadí podle depends_on se standardními štítky Compose. Názvy služeb se překládají přes aliasy DNS v síti. Soubor docker-compose.yml otevřete z Finderu, z nabídky Soubor nebo přetažením do okna.

Jak otevřít stroj container ve VS Code?

Spusťte stroj v Gantry a klikněte na Otevřít ve VS Code. Gantry stroj otevře ve VS Code přes Remote-SSH, stejně jako v ukázce container-machine-vscode od Applu. V image stroje musí běžet sshd a musí být nainstalován VS Code s rozšířením Remote-SSH.

Které verze apple/container Gantry podporuje?

Gantry vyžaduje CLI container 1.0 nebo novější a doporučuje 1.7.1. Přečte nainstalovanou verzi a zobrazí jen funkce, které tato verze podporuje, například velikosti pracovních uzlů a sdílené úložiště imagů (1.7), uložení jako image (1.6) a Zmenšit disk (1.4). Pokud CLI chybí nebo je zastaralé, Gantry nabídne průvodce instalací.

Umí Gantry procházet cluster Kubernetes?

Ano. Sekce Kubernetes zobrazuje pody, deploymenty, StatefulSety, DaemonSety, služby, ingressy, ConfigMapy, secrety, uzly a události pro každý kontext kubeconfig a nabízí logy podů, shell v podu, přesměrování portů, škálování, restart nasazení, smazání a Použít YAML. Gantry komunikuje s Kubernetes API sama, takže kubectl nepotřebujete. Viz Kubernetes na Macu.

Co funkce Vysvětlit selhání posílá do Apple Intelligence?

Nedávné logy a podrobnosti kontejneru, bez hodnot proměnných prostředí a textu, který vypadá jako tajný údaj. Malé požadavky zpracuje model v zařízení. Se zapnutým nastavením pro dlouhé logy (macOS 27) jdou dlouhé logy do Private Cloud Compute. Panel ukazuje, co bylo odesláno. Navržený příkaz se otevře v Terminálu, ale nespustí se, dokud nestisknete Return. Bez Apple Intelligence Gantry nabídne prompt ke zkopírování do jiného asistenta AI.

Mohu do Gantry vložit příkaz docker run?

Ano. V listu Nový kontejner zvolte Vložit příkaz…. Gantry přečte docker run, docker create, podman run a container run, vyplní formulář a vypíše každý příznak, který nemůže použít, i s důvodem. Viz Kontejner z příkazu docker run.

Umí Gantry spravovat builder, registry a jádro apple/container?

Ano. Sekce Systém hostitele apple/container spouští, zastavuje a maže builder imagů s možnostmi CPU, paměti a DNS; vypisuje, přidává a odebírá přihlášení k registrům (heslo jde do CLI výhradně přes stdin); instaluje doporučené jádro, soubor jádra nebo archiv tar; streamuje logy služeb a upravuje systémové vlastnosti v config.toml.

Je Gantry alternativa k Docker Desktop, OrbStack nebo Podman Desktop?

Jako GUI ano. Gantry je bezplatná nativní aplikace pro macOS ke správě kontejnerů, imagů, svazků, sítí, logů a statistik. Je to klient, ne engine: používá démona Dockeru, kterého už provozujete (Docker Desktop, OrbStack, Colima), nebo nástroj container od Applu, a přidává pohled na více hostitelů, hostitele SSH a server MCP. Viz srovnání.

Je Gantry zdarma?

Ano. Gantry je zdarma a open source pod licencí MIT. Žádné předplatné, žádný účet a žádný limit počtu hostitelů ani kontejnerů.

Co potřebuji ke spuštění Gantry?

macOS 26 nebo novější na Apple silicon nebo Intelu a k tomu démona Dockeru (Docker Desktop, OrbStack, Colima nebo podobný) nebo nástroj container od Applu. Samotný apple/container vyžaduje Apple silicon, takže na Macu s Intelem Gantry spravuje jen hostitele Docker.

Funguje Gantry s OrbStack, Colima a Docker Desktop?

Ano. Gantry komunikuje přímo s Docker Engine API přes unixový socket, takže funguje s každým démonem, který ho zpřístupňuje, včetně OrbStack, Colima a Docker Desktop.

Umí Gantry spravovat vzdálené hostitele Docker?

Ano. Gantry se ke vzdáleným démonům připojuje přes SSH stejně jako docker -H ssh://, s bastiony ProxyJump, ověřováním více klíči a automatickým opětovným připojením. Na server nemusíte nic instalovat a tajné údaje zůstávají v Klíčence macOS.

Upozorní mě Gantry, když kontejner selže?

Ano. Gantry pošle nativní oznámení macOS, když kontejner na kterémkoli hostiteli – místním, SSH nebo apple/container – spadne, vyčerpá paměť nebo neprojde kontrolou stavu. Kliknutím na oznámení přejdete ke kontejneru. Zastavení a restarty spuštěné z Gantry se nehlásí a oznámení můžete vypnout v Nastavení.

Umí Gantry stahovat ze soukromých registrů?

Ano. Na hostitelích Docker čte Gantry přihlašovací údaje z vašeho ~/.docker/config.json (tedy z docker login, který jste už spustili), včetně vložených údajů, credential helperů a Klíčenky macOS. Na hostitelích apple/container spravuje přihlášení container registry.

Umí Gantry zpřístupnit místní kontejner na internetu?

Ano. Jedno kliknutí na publikovaný port ho zpřístupní přes Cloudflare Tunnel. Gantry v případě potřeby nainstaluje cloudflared a pak spustí rychlý tunel (bez účtu Cloudflare, s dočasnou URL na trycloudflare.com) nebo pojmenovaný tunel s vaším vlastním názvem hostitele. Veřejná URL se zobrazí pod portem s ovládáním pro otevření, zkopírování a zastavení.

Je Gantry aplikace v Electronu?

Ne. Gantry je nativní aplikace postavená na SwiftUI a Swift 6. Rozhraní je k dispozici v 28 jazycích: v angličtině, zjednodušené čínštině a 26 evropských jazycích, například v srbštině v cyrilici i latince. Řídí se jazykem systému macOS.

Jak nainstalovat Gantry?

Spusťte brew install --cask getgantry/tap/gantry nebo stáhněte nejnovější vydání z GitHubu a přetáhněte Gantry.app do složky Aplikace.

Mohou Gantry ovládat AI agenti?

Ano. Gantry obsahuje server MCP a App Intents pro macOS, takže Claude, Zkratky, Siri a skripty mají na každém hostiteli, včetně hostitelů SSH, stejné možnosti jako GUI: kontejnery, image, svazky, sítě, Compose, stroje apple/container, clustery Kubernetes, systémové nástroje apple_* (služby, builder, registry, vlastnosti, logy, jádro) a sdílení portů. V macOS 26 a novějším se Vysvětlit selhání… navíc ptá Apple Intelligence, proč kontejner selhal. Server MCP přidáte příkazem claude mcp add gantry -- /Applications/Gantry.app/Contents/Resources/gantry-mcp.

Nainstalováno za minutu

Žádný App Store, žádný účet. Stáhněte a přetáhněte – nebo jeden řádek v Homebrew.

Stáhnout pro macOS
$ brew install --cask getgantry/tap/gantry

Instalace

Spusťte cask z Homebrew, nebo stáhněte .zip z Vydání a přetáhněte Gantry.app do složky Aplikace.

První spuštění

Zatím není notarizovaná – klikněte pravým tlačítkem a zvolte Otevřít, nebo odstraňte karanténu příkazem xattr -dr com.apple.quarantine /Applications/Gantry.app

3
Přidání hostitele

Místní Docker se objeví sám. Pro Apple container přidejte hostitele Apple Container; Gantry nabídne instalaci CLI container. Agenti: claude mcp add gantry.
