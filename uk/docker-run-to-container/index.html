Gantry/З docker run

Створення контейнера з команди docker run

Більшість README містять рядок docker run. Gantry читає цей рядок і заповнює форму нового контейнера — для хоста Docker або для інструмента container від Apple. Цей посібник показує, як це працює і як перетворити команду вручну.

Коротко. У Gantry відкрийте Новий контейнер, виберіть Вставити команду…, вставте рядок docker run і натисніть Заповнити форму. Gantry перелічує прапорці, які не може використати, з причиною для кожного. Для CLI більшість прапорців збігаються: замініть docker run на container run і приберіть --restart.

Вставлення команди в Gantry

  1. Виберіть хост: хост Docker або хост apple/container.
  2. Відкрийте Контейнери й натисніть Новий контейнер.
  3. Натисніть Вставити команду… і вставте рядок. Перенесення рядків із \, лапки, запрошення $ і sudo не заважають.
  4. Перегляньте попередній перегляд: образ, прапорці, які Gantry не може використати, примітки й попередження для цього хоста.
  5. Натисніть Заповнити форму, перевірте значення й створіть контейнер.

Gantry розпізнає docker run, docker container run, docker create, podman run і container run. Текст після &&, ||, ; або | пропускається, і Gantry додає про це примітку.

Gantry знає ще близько 80 прапорців Docker: він правильно пропускає їхні значення й показує їх як невикористані, тож нічого не губиться без примітки.

    Попередження для хостів apple/container

Деяких параметрів Docker в apple/container немає. Gantry попереджає про них і не включає їх у запит на створення:

  • політики перезапуску (--restart);
  • дробові CPU, наприклад --cpus 0.5;
  • мережеві режими host, none і container:;
  • порти без порту хоста, наприклад -p 80.

На хості Docker Gantry попереджає про параметри apple/container: DNS-домен і параметри ядра.

    Як вручну перетворити docker run на container run

Для CLI більшість прапорців лишаються такими самими. Приклад із Redis:

Термінал
docker run -d --name cache --restart unless-stopped -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

перетворюється на:

Термінал
container volume create redisdata
container run -d --name cache -p 6379:6379 \
  -v redisdata:/data redis:7 redis-server --appendonly yes

Спочатку створіть іменований том командою container volume create. Приберіть --restart і округліть --cpus до цілого числа. --platform працює так само, як у Docker.

    Копіювання контейнера як команди

Це працює й у зворотний бік. Клацніть контейнер правою кнопкою або відкрийте меню «Більше» й виберіть Скопіювати як команду: Gantry складе рядок docker run або container run. Типові значення з образу, наприклад його середовище й команду, він не включає, тож рядок лишається коротким. Це працює й для зупинених контейнерів.

    Збереження як шаблону

У вікні створення контейнера відкрийте Шаблони й виберіть Зберегти як шаблон…. Наступного разу Заповнити з шаблону дасть ту саму форму на будь-якому хості. Шаблони зберігаються в ~/Library/Application Support/Gantry/recipes.json, тож їх можна зберегти в резервну копію або передати колегам.

    Обмеження
  • Gantry зберігає шлях із --env-file, але не читає сам файл і не бере значення з вашої оболонки для -e KEY без значення.
  • Монтування tmpfs і анонімні томи з --mount показуються як непідтримувані.
  • Два порти для одного порту контейнера (-p 8080:80 -p 8081:80) потрапляють у форму, але форма потім відхиляє дублікат.

Запитання й відповіді

Як перетворити docker run на container run?

Замініть docker run на container run. -d, -p, -e, -v, --name, --rm, -it, -w і --entrypoint лишаються такими самими. Приберіть --restart і використовуйте цілі CPU. Або вставте рядок у Gantry, і він заповнить форму.

Чи може Gantry імпортувати команду docker run?

Так. Вставити команду… у вікні створення контейнера розпізнає docker run, docker create, podman run і container run та заповнює форму.

Що відбувається з прапорцями, які Gantry не підтримує?

Їх перелічено в попередньому перегляді з причиною, і вони лишаються у формі в розділі «Зі вставленої команди», щоб ви могли перевірити їх пізніше.

Чи можна перетворити запущений контейнер назад на команду docker run?

Так. Скопіювати як команду в меню контейнера складає рядок docker run або container run для цього контейнера.
